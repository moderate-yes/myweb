# Optional: Why W Cannot Always Be Computed in One Step

## 학습 목표

공식으로 $W$를 구하려면 역행렬이 존재해야 하고 데이터가 메모리에 들어가야 한다. 실제 데이터에서는 두 조건이 자주 깨지므로, 이 장은 공식이 실패하는 상황을 확인하고 반복 계산으로 넘어가는 이유를 정리한다.

이 장을 마치면 다음을 할 수 있다.

- rank 부족과 역행렬 부재의 관계를 설명한다.
- pseudoinverse가 선형 최소제곱에서 하는 역할을 말한다.
- Gradient Descent를 단순히 ‘역행렬이 없을 때의 대안’으로 오해하지 않는다.

> **수식 선택 학습**: rank와 pseudoinverse 계산은 AI Math 3–4장으로 연결한다.

## 1. 질문: 역행렬이 없으면 학습도 불가능할까?

정규방정식의 역행렬이 존재하지 않는 문제와, 복잡한 AI 모델에 closed-form solution이 없는 문제는 서로 다르다. 이 차이를 놓치면 “역행렬이 없어서 Gradient Descent를 쓴다”는 잘못된 결론에 도달한다.

## 2. 가장 단순한 예: 같은 정보를 두 번 넣기

두 번째 특성이 첫 번째 특성의 정확히 두 배인 입력을 보자.

$$
X=
\begin{bmatrix}
1&2\\
2&4\\
3&6
\end{bmatrix}
$$

두 열은 독립적인 방향이 아니다. 따라서 $X$의 rank는 2가 아니라 1이고,

$$
X^TX=
\begin{bmatrix}
14&28\\
28&56
\end{bmatrix}
$$

의 determinant는 0이다. 이런 행렬을 <strong>singular matrix</strong>라고 하며 역행렬이 없다. 여러 $W$가 같은 예측을 만들 수 있어 해가 하나로 정해지지 않는다.

## 3. 수식: rank와 pseudoinverse

$X$의 열 수가 $d$일 때 정규방정식의 역행렬을 쓰려면 일반적으로 다음 조건이 필요하다.

$$
\operatorname{rank}(X)=d
$$

그러나 역행렬이 없다고 선형회귀를 포기할 필요는 없다. Moore–Penrose **pseudoinverse(의사역행렬)** $X^+$를 사용하면 최소제곱해 중 norm이 가장 작은 해를 구할 수 있다.

$$
\boxed{W=X^+Y}
$$

실제 수치 계산에서는 역행렬을 명시적으로 만드는 대신 QR 분해나 SVD 같은 더 안정적인 방법도 사용한다. 즉, <strong>역행렬 부재는 대안이 있는 선형대수 문제</strong>다.

### Python으로 rank와 pseudoinverse 확인하기

두 입력 열이 완전히 같으면 독립적인 정보는 하나뿐이다. 역행렬 계산은 실패하지만 pseudoinverse는 가능한 해 가운데 하나를 반환한다.

```python
import numpy as np

X = np.array([[1, 1], [2, 2], [3, 3]], dtype=float)
y = np.array([2, 4, 6], dtype=float)

print("rank =", np.linalg.matrix_rank(X))
print("W =", np.linalg.pinv(X) @ y)
print("prediction =", X @ (np.linalg.pinv(X) @ y))
```

```output
rank = 1
W = [1. 1.]
prediction = [2. 4. 6.]
```

## 4. 문제 발생: 더 본질적인 한계는 비선형 모델이다

신경망의 예측은 보통 다음처럼 여러 Parameter와 비선형 연산이 얽힌 함수다.

$$
\hat Y=f(X;W_1,W_2,\ldots,W_m)
$$

ReLU, sigmoid, attention, normalization 등이 결합되면 $\nabla_W L=0$을 만족하는 최적 $W$를 간단한 행렬 공식으로 분리해 내기 어렵다. Parameter 수가 매우 크고 데이터도 계속 바뀌므로 전체 해를 한 번에 계산하는 방식은 현실적이지 않다.

정리하면 다음 두 문장은 다르다.

| 오해 | 정확한 설명 |
| --- | --- |
| 역행렬이 없어서 Gradient Descent를 쓴다 | singular한 선형 문제는 pseudoinverse 등으로도 풀 수 있다 |
| 복잡한 AI는 왜 반복 최적화를 쓰는가 | 비선형 모델의 최적 Parameter에 대한 closed-form solution이 일반적으로 없고 규모도 크기 때문이다 |

## 핵심 정리

- rank는 행렬이 담은 독립적인 정보 방향의 수다.
- rank가 부족하면 $X^TX$는 singular하여 역행렬이 없다.
- pseudoinverse는 이런 선형 최소제곱 문제의 대안이다.
- Gradient Descent의 본질적 필요성은 복잡한 비선형 모델에 일반적인 closed-form solution이 없다는 데 있다.
