# 패션 빅데이터 2 과정 안내

> **소비자 데이터 분석과 AI 활용**  
> 패션 쇼핑몰의 데이터를 정제·분석하고, 결과를 검증 가능한 의사결정과 안전한 자동화로 연결한다.

## 선수 지식

[패션 빅데이터 1](templates/fashion_bigdata_1/lectures_korean/00_ch0_과정_안내.md)의 데이터 의미·구조·비교·인과 개념을 이해한 학습자를 대상으로 한다. 실습 코드를 직접 실행하려면 [Python Basic](templates/python_basic/lectures_korean/00_ch0_과정_안내.md)의 pandas 필터·`groupby`·`merge`까지 먼저 익히는 것을 권장한다.

웹 수집은 별도의 필수 기술 장으로 두지 않는다. 1장에서 공식 내보내기·API·제공 파일을 우선하는 원칙을 배우고, 권한이 확인된 연습 페이지의 노코드 수집을 선택 실습으로 수행한다.

## 12개 장의 순서

| 장 | 주제 | 산출물 |
|---:|---|---|
| 1 | 프로젝트 시작·안전한 수집 | 데이터 수집·품질 점검표 |
| 2 | 상품 텍스트 마이닝 | 정제 규칙과 용어 분석 |
| 3 | 판매량 급변과 이상치 | 기준선과 이상 후보 목록 |
| 4 | RFM 고객 분석 | 고객 세그먼트 기준선 |
| 5 | 이미지 유사도 검색 | 임베딩 검색 평가안 |
| 6 | 검색 의도와 SEO | 상품 페이지 검색 진단 |
| 7 | 고객 경험과 행동 분석 | 퍼널·코호트·실험 설계 |
| 8 | 콘텐츠와 성과 지표 | 허영 지표를 제외한 평가안 |
| 9 | BCG·UGC·AIGC | 콘텐츠 출처·책임 지도 |
| 10 | 패션 이미지 생성과 검증 | 통제된 생성·검수 기록 |
| 11 | 자동화와 의사결정 | 도구선정 RFP와 운영 규칙 |
| 12 | 생성형 AI와 최종 프로젝트 | 검증 가능한 AI 업무 카드 |

## 공통 실습 데이터

실습은 `templates/consumer_data_utilization/data/`의 가상 패션몰 데이터를 계속 사용한다. 실제 개인정보는 포함하지 않으며, 상품·고객·주문·행동 Event의 공통 식별자를 여러 장에서 이어서 사용한다.

- [실습 데이터 설명](templates/consumer_data_utilization/data/README.md)
- [Python 시작 노트북](templates/consumer_data_utilization/notebooks/consumer_data_starter.ipynb)

## 학습 원칙

- 실행되는 코드와 믿을 수 있는 분석을 구분한다.
- 기간·분모·취소·반품·결측·JOIN 결과를 기록한다.
- 모델 성능뿐 아니라 비용·지연·프라이버시·편향과 중단 조건을 함께 평가한다.
- 자동화 전에는 사람의 승인 범위와 되돌리기 방법을 정한다.

## 완료 기준

마지막 장에서 하나의 패션 업무를 골라 입력 데이터, 근거, 처리 규칙, 평가 사례, 사람 승인, 자동 중단과 되돌리기를 포함한 프로젝트를 완성한다.
