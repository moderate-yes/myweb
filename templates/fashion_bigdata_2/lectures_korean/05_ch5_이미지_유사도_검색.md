# 사진으로 비슷한 옷 찾기: 임베딩과 유사도 검색

고객이 검정 재킷 사진을 보여주었을 때 비슷한 재킷을 찾아주려면 컴퓨터는 무엇을 비교해야 할까? 이 장에서는 사진의 의복 영역을 정하고, 딥러닝 인코더가 만든 **임베딩**을 비교해 가까운 상품을 검색하는 원리를 배운다.

## 생각해 보기: 왜 바지가 검색되었을까?

검정 재킷을 입은 모델의 전신 사진으로 “비슷한 재킷”을 찾았는데 검정 바지가 나왔다고 하자. 모델이 사진 전체를 비교했다면 사람, 배경, 바지와 포즈가 재킷보다 더 강한 신호가 되었을 수 있다.

> **핵심 관찰**
> “닮음”은 사진 안에 자동으로 존재하는 정답이 아니다. 같은 상품, 비슷한 대체품, 어울리는 코디 중 **무엇을 찾을지 먼저 정의**해야 한다.

## 학습 목표

- 픽셀과 임베딩의 역할을 구분할 수 있다.
- 바운딩 박스·분할 마스크가 필요한 상황과 필요하지 않은 상황을 설명할 수 있다.
- 같은 상품 검색, 유사 상품 검색과 코디 추천을 구분할 수 있다.
- 코사인 유사도와 Top-K 검색의 흐름을 설명할 수 있다.
- anchor·positive·negative와 triplet loss의 수식을 직관적으로 설명할 수 있다.
- 데이터셋의 라벨 정의, 도메인 차이와 지름길 학습의 위험을 점검할 수 있다.
- 오프라인 검색 품질과 온라인 서비스 성과를 구분해 평가할 수 있다.

## 핵심 용어

- **바운딩 박스(bounding box)**: 대상이 있는 범위를 사각형 좌표로 표시한 주석.
- **분할 마스크(segmentation mask)**: 대상에 속하는 픽셀을 윤곽에 맞게 표시한 주석.
- **임베딩(embedding)**: 이미지의 특징을 비교하기 쉽도록 인코더가 만든 D차원 숫자 벡터.
- **코사인 유사도(cosine similarity)**: 두 벡터의 방향이 얼마나 비슷한지 나타내는 값.
- **Top-K 검색**: 질의와 가장 가까운 결과 K개를 반환하는 방식.
- **triplet loss**: 기준과 positive는 가깝게, 기준과 negative는 일정 간격 이상 멀게 학습하는 손실함수.

## 1. 먼저 ‘어떤 비슷함인가’를 정의하기

| 과제 | 질의 | 원하는 결과 | 정답 관계 |
|---|---|---|---|
| 동일 상품 검색 | 거리 사진 속 재킷 | 쇼핑몰의 같은 SKU | 같은 의복 인스턴스 |
| 유사 상품 검색 | 품절된 검정 재킷 | 대체 가능한 비슷한 재킷 | 카테고리·실루엣·색·소재 유사 |
| 코디 추천 | 검정 재킷 | 함께 입을 바지·신발 | 시각적 유사성이 아닌 호환성 |
| 텍스트-이미지 검색 | “남색 오버사이즈 코트” | 문장 의미에 맞는 상품 | 언어와 이미지의 의미 정렬 |

이 장의 중심 과제는 두 번째인 **시각적 유사 상품 검색**이다. 유사한 재킷을 찾는 시스템이 어울리는 바지를 내놓는다면 코디로는 좋을 수 있어도 유사도 검색으로는 오답이다.

상품 수가 많고 같은 카테고리 안에 대체품이 충분할수록 유사 검색의 선택 가치가 커질 수 있다. 하지만 플랫폼에서 언제나 효과적이고 자체 브랜드에서 언제나 불필요하다는 보편 법칙은 아니다. 카탈로그 구성과 고객 과제로 판단한다.

## 2. 픽셀에서 임베딩으로

RGB 이미지는 높이×너비×3의 픽셀 숫자 배열이다. 그러나 원시 픽셀 차이는 밝기, 배경, 위치와 크기 변화에 매우 민감하다. 실무 검색은 보통 학습된 인코더 \(f(\cdot)\)가 만든 D차원 벡터를 비교한다.

\[
\mathbf{z}=f(\mathbf{x}), \qquad \mathbf{z}\in\mathbb{R}^{D}
\]

여기서 \(\mathbf{x}\)는 이미지, \(\mathbf{z}\)는 임베딩이다. D가 128, 512, 768처럼 클 수 있으며, 2차원 산점도는 설명을 위한 시각화일 뿐 실제 임베딩 공간이 아니다.

## 3. 무엇을 잘라서 비교할까?

사진 종류에 따라 필요한 전처리가 다르다.

| 입력 상황 | 의복 영역 처리 | 이유 |
|---|---|---|
| 흰 배경에 상품 하나인 카탈로그 컷 | 전체 이미지 또는 간단 crop | 대상이 이미 분리됨 |
| 사람이 여러 옷을 입은 전신 사진 | 검출 박스나 분할 마스크 | 재킷·바지·사람·배경을 구분 |
| 길거리 사진의 작은 의복 | 검출 후 확대·품질 검사 | 대상이 작고 가림이 많음 |
| 같은 템플릿으로 촬영된 자사 상품 | 전체 이미지도 가능하나 배경 의존 검사 | 촬영 템플릿을 외울 수 있음 |

바운딩 박스가 항상 필요한 것은 아니다. 다만 다중 의복 사진에서는 비교 대상을 지정하지 않으면 모델이 엉뚱한 영역을 사용할 수 있다. 분할 마스크는 박스보다 윤곽을 정확히 분리하지만 제작 비용이 더 든다.

### 라벨은 모델이 배울 ‘관계’를 정한다

- 동일 상품 검색: 서로 다른 사진의 같은 SKU를 positive로 둔다.
- 유사 대체품 검색: 카테고리·실루엣·색상과 사람의 유사 판단을 조합한다.
- 코디 추천: 함께 착용된 조합이나 호환성 판단을 positive로 둔다.

색상·카테고리는 비교적 합의하기 쉽지만 `스쿨룩`, `로맨틱` 같은 스타일은 사람마다 다르게 판단할 수 있다. 여러 평가자의 합의 수준과 의견 불일치를 함께 기록한다.

## 4. 임베딩 사이의 거리 계산하기

두 임베딩 \(\mathbf{a}, \mathbf{b}\)의 코사인 유사도는 다음과 같다.

\[
\operatorname{cos}(\mathbf{a},\mathbf{b})
=\frac{\mathbf{a}\cdot\mathbf{b}}
{\lVert\mathbf{a}\rVert\lVert\mathbf{b}\rVert}
\]

방향이 같을수록 1에 가깝다. [`sklearn.metrics.pairwise.cosine_similarity`](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.pairwise.cosine_similarity.html)로 질의와 카탈로그의 점수를 계산할 수 있다.

```python
from sklearn.metrics.pairwise import cosine_similarity

# query_embedding: (1, D), catalog_embeddings: (N, D)
scores = cosine_similarity(query_embedding, catalog_embeddings)[0]
top_k = scores.argsort()[::-1][:10]

results = catalog.iloc[top_k].copy()
results["cosine_similarity"] = scores[top_k]
```

대규모 카탈로그에서는 모든 벡터를 매번 전수 비교하기보다 [FAISS](https://faiss.ai/) 같은 벡터 검색 도구로 가까운 후보를 빠르게 찾는다. 그 뒤 품절 상품 제외, 같은 카테고리 유지, 가격 범위와 다양성 같은 업무 규칙으로 재정렬할 수 있다.

> **즉시 해석**
> 코사인 점수 0.91은 현재 임베딩 공간에서 두 벡터 방향이 가깝다는 뜻이다. 소비자가 91% 확률로 비슷하다고 판단한다는 뜻은 아니다.

## 5. 선택 심화: Triplet loss의 학습 관계

triplet은 세 이미지로 구성된다.

| 역할 | 예시 | 학습 목표 |
|---|---|---|
| Anchor \(a\) | 기준 검정 크루넥 니트 | 비교 기준 |
| Positive \(p\) | 같은 상품의 다른 촬영 또는 유사 니트 | anchor와 거리 축소 |
| Negative \(n\) | 다른 실루엣의 셔츠 | anchor와 거리 확대 |

\[
L=max\left(d(f(a),f(p))-d(f(a),f(n))+m,\;0\right)
\]

\(m\)은 margin이다. negative가 positive보다 충분히 멀면 손실은 0이 된다. [PyTorch의 `TripletMarginLoss`](https://pytorch.org/docs/stable/generated/torch.nn.TripletMarginLoss.html)는 이 원리를 구현한다. 이 아이디어는 얼굴 임베딩을 학습한 [FaceNet](https://openaccess.thecvf.com/content_cvpr_2015/html/Schroff_FaceNet_A_Unified_2015_CVPR_paper.html)에서 널리 알려졌다.

<div class="operations-flow" aria-label="Triplet loss의 거리 관계">
  <div><strong>Anchor</strong><span>검정 크루넥 니트</span><i>↔ 가까워지게 ↔</i><strong>Positive</strong><span>같은·유사 니트</span></div>
  <b>↕</b>
  <div class="flow-highlight"><strong>Negative는 margin 이상 멀어지게: 셔츠·바지·다른 실루엣</strong></div>
</div>

너무 쉬운 negative만 쓰면 학습할 것이 적다. 반대로 라벨이 애매한 hard negative를 잘못 고르면 실제로 비슷한 상품을 억지로 멀게 만들 수 있다. triplet의 정의가 곧 검색 품질의 정의다.

## 6. 참고: 패션 연구 데이터셋은 무엇을 제공할까?

[DeepFashion](https://openaccess.thecvf.com/content_cvpr_2016/html/Liu_DeepFashion_Powering_Robust_CVPR_2016_paper.html)은 80만 장이 넘는 패션 이미지에 카테고리·속성·랜드마크와 상업 사진-소비자 사진 대응 관계를 제공해 의복 인식과 검색 연구를 지원했다. 단순히 “triplet 사진 모음”은 아니다.

[DeepFashion2](https://openaccess.thecvf.com/content_CVPR_2019/html/Ge_DeepFashion2_A_Versatile_Benchmark_for_Detection_Pose_Estimation_Segmentation_and_CVPR_2019_paper.html)는 여러 의복이 한 사진에 있는 상황, 가림, 박스·마스크·조밀한 랜드마크와 같은 더 복잡한 과제를 포함한다.

### DeepFashion

카테고리·속성·랜드마크 주석과 매장 사진-소비자 사진의 대응 관계를 제공한다. 이를 통해 의복 인식, 랜드마크 추정과 동일 의복 검색 과제를 배울 수 있다. 자사 서비스에 적용하기 전에는 라이선스, 카테고리 체계와 촬영 환경이 자사 데이터와 맞는지 확인한다.

### DeepFashion2

박스·마스크·랜드마크와 상업 사진-소비자 사진의 대응 관계를 제공한다. 검출·분할·포즈와 검색 과제를 함께 다룰 수 있다. 적용 전에는 자사 상품의 스타일·이미지 품질·촬영 조건과 연구 데이터의 차이를 평가한다.

연구용 성능이 좋아도 자사 카탈로그의 촬영, 체형, 국가, 카테고리와 다르면 성능이 떨어질 수 있다. 사용 조건과 라이선스도 공식 배포 페이지에서 확인한다.

## 8. 검색 품질을 어떻게 평가할까?

평가용 질의마다 관련 상품 정답을 만들고, 학습에 쓰지 않은 이미지로 측정한다.

| 단계 | 지표 | 질문 |
|---|---|---|
| 오프라인 | Recall@K | 관련 상품 중 상위 K개 안에 얼마나 찾았는가? |
| 오프라인 | mAP | 관련 상품의 순위가 전체적으로 얼마나 높은가? |
| 사람 평가 | 유사성 적합도 | MD·고객이 목적에 맞게 비슷하다고 보는가? |
| 시스템 | 검색 지연 시간 | 결과가 서비스 가능한 속도로 나오는가? |
| 온라인 | 클릭률·전환율 | 검색 결과가 탐색과 구매를 돕는가? |
| 보호 지표 | 반품률·다양성 | 부적합 추천이나 편중이 늘지 않는가? |

동일 상품 검색과 유사 대체품 검색은 정답 정의가 다르므로 같은 평가 세트를 쓰지 않는다. 클릭률만 높이고 반품이 늘면 좋은 검색이라고 보기 어렵다.

### 텍스트와 이미지를 함께 찾는 확장

[CLIP](https://proceedings.mlr.press/v139/radford21a.html)은 이미지와 문장을 같은 임베딩 공간에 가깝게 학습해 “남색 오버사이즈 코트” 같은 문장으로 이미지를 찾는 출발점이 된다. 다만 일반 웹 데이터로 학습한 모델의 패션 속성 이해와 편향은 자사 평가셋으로 다시 검증한다.

## 짧은 활동: 라벨링 기준과 positive 관계 정하기

상품 이미지 A·B·C를 고르고 기존의 카테고리·색상·스타일 라벨 활동을 확장한다.

| 기준 | 상품 A | 상품 B | 상품 C |
|---|---|---|---|
| 카테고리 |  |  |  |
| 색상 |  |  |  |
| 실루엣 |  |  |  |
| 스타일(자유 서술) |  |  |  |

표를 작성한 뒤 기준마다 사람 사이의 합의가 어려웠던 이유를 문장으로 기록한다.

검색 목적별로 positive인지 표시한다.

| 이미지 쌍 | 동일 상품 | 유사 대체품 | 코디 추천 |
|---|---|---|---|
| A–B |  |  |  |
| A–C |  |  |  |
| B–C |  |  |  |

각 판단의 근거는 표 밖에 문장으로 적는다. 같은 쌍을 서로 다른 과제에서 다르게 판단했다면 그 이유도 함께 설명한다.

같은 쌍도 과제에 따라 정답이 달라지는 이유를 한 문장으로 설명한다.

## 이 장의 핵심

- 원시 RGB 픽셀을 직접 비교하면 배경·위치·조명 변화에 민감하므로 학습된 D차원 임베딩을 비교한다.
- 동일 상품, 유사 대체품, 코디와 텍스트-이미지 검색은 서로 다른 과제와 정답 관계를 갖는다.
- 다중 의복 사진에서는 박스·마스크가 비교 영역을 지정하지만 상품 단독 사진에 항상 필요한 것은 아니다.
- 코사인 유사도는 임베딩 방향의 가까움을 나타낼 뿐 소비자 판단 확률이 아니다.
- triplet loss는 anchor-positive 거리를 줄이고 anchor-negative 거리를 margin 이상 벌린다.
- DeepFashion과 DeepFashion2는 카테고리·속성·랜드마크·박스·마스크와 사진 대응 관계를 제공한 연구 데이터셋이다.
- 배경 지름길, 도메인 차이, 대표성·라이선스와 디자인 권리를 점검하고 사람이 중요한 결정을 검토한다.
- Recall@K·mAP·사람 평가·지연 시간과 온라인 전환·반품·다양성을 함께 평가한다.

## 학습 점검

1. 픽셀 배열과 임베딩의 차이를 설명하시오.
2. 유사 상품 검색과 코디 추천은 어떻게 다른가?
3. 바운딩 박스가 필요한 상황과 없어도 되는 상황을 하나씩 쓰시오.
4. 코사인 유사도 0.9를 “90% 확률로 비슷하다”고 말하면 안 되는 이유는 무엇인가?
5. triplet loss에서 anchor·positive·negative의 역할을 설명하시오.
6. 오프라인 검색 지표와 온라인 서비스 지표를 하나씩 쓰시오.
