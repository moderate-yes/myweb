# 말로 원하는 옷을 찾을 수 있는가

1장에서 컴퓨터는 P501 코트의 위치와 특징을 찾아 숫자 벡터로 표현했다. 하지만 실제 사용자는 상품의 정확한 이름이나 속성 용어를 모를 수 있다. “이것과 비슷한데 조금 더 짧고 밝은 코트”처럼 기준 이미지와 수정 요청을 함께 제시하는 편이 더 자연스러울 때가 있다.

> **이 장의 중심 질문**<br>
> 기준 상품의 시각적 특징은 유지하면서 자연어로 요청한 변화까지 만족하는 상품을 어떻게 찾을까?

## 학습 목표

이 장을 마치면 다음을 설명할 수 있다.

- 키워드 검색, 이미지 검색, 이미지와 문장을 결합한 검색의 차이
- 이미지와 문장을 Embedding Vector로 표현하고 비교하는 원리
- FashionIQ·FashionVLP·SyncMask가 각각 해결하려는 문제
- 자연어의 모호함과 이미지·설명 불일치가 검색 평가에 미치는 영향

## 핵심 용어

- **멀티모달(multimodal)**: 이미지·문장처럼 서로 다른 형태의 정보를 함께 사용하는 방식.
- **임베딩(embedding)**: 이미지나 문장의 의미를 비교할 수 있도록 바꾼 숫자 벡터.
- **결합 이미지 검색(composed image retrieval)**: 기준 이미지와 수정 문장을 하나의 질의로 결합해 목표 이미지를 찾는 과제.
- **자연어 피드백(natural language feedback)**: 현재 결과에서 원하는 변화를 사용자의 말로 설명한 것.
- **비전-언어 사전학습(vision-language pretraining)**: 이미지와 문장의 대응 관계를 대규모 데이터로 먼저 학습하는 과정.
- **마스킹(masking)**: 이미지 패치나 문장 토큰 일부를 가리고 주변 정보로 복원하도록 학습하는 방법.

## 1. 연구 질문: 검색창에 무엇을 입력할 것인가

패션 상품을 찾는 방법은 입력 형태에 따라 달라진다.

| 검색 방식 | 입력 예 | 잘하는 것 | 놓치기 쉬운 것 |
| --- | --- | --- | --- |
| 키워드 검색 | `남색 오버사이즈 코트` | 명시된 속성 찾기 | 사용자가 용어를 알아야 함 |
| 이미지 검색 | P501 사진 | 전체적으로 닮은 상품 찾기 | 어떤 부분을 바꾸려는지 표현하기 어려움 |
| 문장 검색 | `짧고 밝은 더블 코트` | 언어로 조건 지정 | 기준 디자인의 미세한 형태를 전달하기 어려움 |
| 이미지+문장 검색 | P501 사진 + `더 짧고 밝게` | 유지할 특징과 바꿀 특징을 함께 전달 | 두 입력의 의미를 정확히 결합해야 함 |

이미지와 문장을 결합한 검색은 새 이미지를 그리는 작업과 다르다. 목표는 생성된 그림이 아니라 **실제 상품 Catalog에 이미 존재하는 후보를 순서대로 찾는 것**이다.

## 2. 가장 단순한 예: P501에서 두 가지만 바꾸기

기준 이미지는 `P501 Navy Oversized Coat`이고 사용자의 피드백은 다음과 같다고 하자.

> “전체적인 오버사이즈 실루엣은 비슷하지만 길이는 더 짧고, 색은 더 밝은 코트.”

좋은 검색 결과는 세 가지 조건을 동시에 고려해야 한다.

1. **유지 조건**: 오버사이즈 실루엣과 코트의 전체 디자인은 P501과 비슷하다.
2. **변경 조건**: 기장은 더 짧고 색상은 더 밝다.
3. **Catalog 조건**: 검색 결과는 실제로 판매 가능한 후보 상품 중에서 선택된다.

이미지만 강하게 반영하면 남색 롱 코트가 계속 검색될 수 있다. 반대로 문장만 강하게 반영하면 P501과 전혀 다른 밝은 숏 코트가 나올 수 있다. 핵심은 “비슷하게 유지할 부분”과 “말에 따라 바꿀 부분”을 하나의 질의로 조합하는 것이다.

## 3. 입력·표현·출력: 이미지와 문장을 하나의 질의로 만들기

기준 이미지 $I_r$와 수정 문장 $T_m$을 각각 Encoder로 숫자 벡터로 바꾼다.

$$
v_r=f_I(I_r), \qquad t_m=f_T(T_m)
$$

두 벡터를 조합하는 함수 $g$가 검색 질의 $q$를 만든다.

$$
q=g(v_r,t_m)
$$

Catalog의 후보 이미지 $I_j$도 벡터 $z_j=f_I(I_j)$로 바꾸고, 질의와 각 후보의 유사도를 계산한다. 간단한 비교 방법은 Cosine Similarity다.

$$
s(q,z_j)=\frac{q\cdot z_j}{\lVert q\rVert\lVert z_j\rVert}
$$

점수 $s$가 큰 후보부터 정렬하면 Top-$K$ 검색 결과가 된다.

학습할 때는 기준 이미지와 수정 문장에 맞는 목표 상품을 가까이 두고, 맞지 않는 상품은 멀리 두도록 Parameter를 조정한다. 이때 어떤 상품을 “틀린 후보”로 선택하는지도 중요하다. 매우 다른 신발만 틀린 예로 보여주면, 모델은 비슷한 코트 사이의 미세한 차이를 배우기 어렵다.

## 4. 대표 연구는 어떻게 발전했는가

### FashionIQ: 사람이 직접 비교 문장을 쓰다

[Fashion IQ](https://openaccess.thecvf.com/content/CVPR2021/html/Wu_Fashion_IQ_A_New_Dataset_Towards_Retrieving_Images_by_Natural_CVPR_2021_paper.html)는 서로 비슷한 두 의복 이미지를 구별하는 사람이 작성한 문장을 제공했다. 기준 상품과 목표 상품 사이의 차이를 “소매가 더 길다”, “더 밝은 색이다”처럼 자연어 피드백으로 기록해 대화형 패션 검색을 연구할 수 있게 했다.

중요한 변화는 미리 정한 속성 목록만 고르는 대신, **사람이 실제로 차이를 설명하는 문장**을 검색 조건으로 사용한 것이다.

### FashionVLP: 이미지와 문장을 Transformer 안에서 결합하다

[FashionVLP](https://openaccess.thecvf.com/content/CVPR2022/html/Goenka_FashionVLP_Vision_Language_Transformer_for_Fashion_Retrieval_With_Feedback_CVPR_2022_paper.html)는 대규모 이미지-문장 데이터에서 얻은 사전 지식을 패션 검색에 활용하고, 전체 이미지와 패션 관련 세부 영역 등 여러 수준의 시각 정보를 결합했다. 기준 이미지와 피드백 문장은 Transformer를 통해 함께 표현하고, 많은 목표 후보를 효율적으로 비교할 수 있도록 비대칭 구조를 사용했다.

이 단계에서 문제는 단순히 이미지 벡터와 문장 벡터를 더하는 것을 넘어, **어느 시각 정보가 어느 단어와 관련 있는지**를 학습하는 방향으로 발전했다.

### SyncMask: 한 상품의 사진과 설명이 항상 일치하지 않는 문제

패션 Catalog에는 한 상품의 정면·측면·뒷면 사진이 여러 장 있고, 모든 사진에 같은 상품 설명이 붙는 경우가 많다. “뒷면 리본”이라는 문장은 맞는 설명이지만 정면 사진에는 리본이 보이지 않을 수 있다.

[SyncMask](https://openaccess.thecvf.com/content/CVPR2024/html/Song_SyncMask_Synchronized_Attentional_Masking_for_Fashion-centric_Vision-Language_Pretraining_CVPR_2024_paper.html)는 이미지와 문장에 실제로 함께 나타나는 부분을 중심으로 Mask를 동기화하는 사전학습 방법을 제안했다. 또한 같은 상품의 다른 사진처럼 매우 비슷한 예를 무조건 틀린 쌍으로 취급하는 문제를 줄이기 위한 Batch 구성도 다뤘다.

| 연구 | 연구가 만든 변화 | 남아 있는 질문 |
| --- | --- | --- |
| FashionIQ, 2021 | 사람이 쓴 상대적 수정 문장으로 검색 | 한 문장이 여러 정답을 가질 수 있음 |
| FashionVLP, 2022 | 사전학습과 다층 시각 정보를 결합 | 세부 이미지와 문장의 정렬이 필요 |
| SyncMask, 2024 | 실제로 함께 보이는 이미지 패치와 단어를 중심으로 학습 | 보이지 않는 상품 정보는 사진만으로 확인 불가 |

세 연구는 서로 같은 문제를 반복한 것이 아니다. FashionIQ는 평가할 데이터와 과제를 만들고, FashionVLP는 검색 모델의 표현 방식을 발전시키며, SyncMask는 패션 이미지-문장 데이터 자체의 불일치를 학습 단계에서 다룬다.

## 5. 문제 발생: 자연어에는 정답이 하나만 있지 않다

“더 밝게”라는 요청은 연한 파랑, 회색, 베이지 중 무엇을 뜻할 수 있을까? “조금 더 격식 있게”는 색상·소재·칼라·길이 가운데 어떤 변화를 요구할까? 자연어는 풍부하지만 그만큼 해석이 여러 개다.

- **여러 개의 타당한 정답**: Dataset에 지정된 목표 상품 외에도 조건을 만족하는 상품이 있을 수 있다.
- **관찰 불가능한 설명**: 정면 사진에서 뒷면 리본, 안감, 촉감을 확인할 수 없다.
- **충돌하는 조건**: “같은 색을 유지하되 더 밝게”처럼 요청 내부에 긴장이 있을 수 있다.
- **Catalog의 한계**: 사용자가 원하는 조합의 상품이 실제 후보군에 없을 수 있다.
- **언어와 문화**: `formal`, `street`, `feminine` 같은 표현은 사람·지역·시점에 따라 달라진다.
- **다국어 문제**: 한국어 패션 표현과 영문 상품 설명의 대응이 충분히 학습되지 않았을 수 있다.
- **평가의 한계**: 정답 하나의 순위만 재면 다른 적절한 결과를 실패로 처리할 수 있다.

따라서 검색 결과가 낮은 순위에 있다고 모델만 탓할 수는 없다. 질의가 모호한지, Catalog에 답이 있는지, 평가 정답이 충분한지도 함께 점검해야 한다.

## 짧은 활동: 검색 가능한 문장으로 바꾸기

P501에 다음 피드백을 붙였다고 하자.

> “비슷하지만 더 세련되고 편안한 코트.”

1. `세련된`, `편안한`이 모호한 이유를 적는다.
2. 사진으로 확인 가능한 변화 세 가지로 문장을 다시 쓴다.
3. 사진만으로 확인할 수 없는 조건 한 가지를 추가한다.
4. 정답 후보가 여러 개일 때 어떤 평가 방법이 더 공정할지 토론한다.

## 이 장의 핵심

- 결합 이미지 검색은 기준 이미지에서 유지할 특징과 자연어로 바꿀 특징을 함께 표현한다.
- 이미지와 문장은 Embedding Vector로 바뀌고, 결합된 질의와 Catalog 후보의 유사도를 비교한다.
- FashionIQ는 사람이 작성한 수정 문장과 목표 의복 쌍을 제공했다.
- FashionVLP는 사전학습된 비전-언어 Transformer와 여러 수준의 패션 시각 정보를 검색에 활용했다.
- SyncMask는 패션 Catalog에서 이미지에 보이는 정보와 상품 설명이 어긋날 수 있다는 문제를 학습 과정에서 다뤘다.
- 검색 결과는 생성 이미지가 아니라 실제 후보 상품이며, 자연어의 모호함 때문에 정답이 여러 개일 수 있다.
