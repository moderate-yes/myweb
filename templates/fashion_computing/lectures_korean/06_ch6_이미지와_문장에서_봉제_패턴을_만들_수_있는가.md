# 이미지와 문장에서 봉제 패턴을 만들 수 있는가

> **이 장의 중심 질문**<br>
> “남색 오버사이즈 코트”라는 문장이나 착용 사진을 실제로 자르고 봉제할 수 있는 패턴으로 바꿀 수 있을까?

## 학습 목표

이 단원을 마치면 다음을 할 수 있다.

- 봉제 패턴을 Panel과 Edge, Seam의 구조로 설명할 수 있다.
- NeuralTailor와 SewFormer가 서로 다른 입력에서 패턴을 복원하는 방식을 비교할 수 있다.
- GarmentCode가 패턴을 실행 가능한 Program으로 표현하는 이유를 설명할 수 있다.
- GarmentCodeData가 학습 범위와 모델의 한계를 함께 결정하는 이유를 설명할 수 있다.
- Design2GarmentCode와 AIpparel의 멀티모달 패턴 생성 방식을 비교할 수 있다.
- Simulation-ready 패턴과 Production-ready 패턴을 구분할 수 있다.

## 핵심 용어

- **Panel**: 원단에서 재단되는 앞판·뒤판·소매 같은 2D 조각.
- **Edge**: Panel 경계를 이루는 직선 또는 곡선 구간.
- **Seam / Stitch relation**: 서로 봉제될 두 Edge의 대응 관계.
- **Rest shape**: 중력과 신체 접촉으로 변형되기 전 의복의 기준 형상.
- **Parametric pattern**: 신체 치수와 디자인 Parameter를 바꾸면 규칙에 따라 형태가 달라지는 패턴.
- **DSL(Domain-Specific Language)**: 봉제 패턴 설계처럼 특정 분야의 구조와 명령을 표현하는 언어.
- **Program synthesis**: 자연어·이미지 같은 요구에서 실행 가능한 Program을 생성하는 방법.
- **Draping simulation**: 2D 패널을 봉제하고 중력·충돌·원단 물성을 적용해 3D 착의 형상을 계산하는 과정.

## 1. 연구 질문: 옷의 겉모양을 어떻게 평면 조각으로 되돌릴까?

완성된 코트는 몸 위에서 중력과 접촉의 영향을 받아 3D로 변형되어 있다. 반면 생산 현장에서 필요한 패턴은 원단을 자르기 위한 2D Panel과 어떤 Edge끼리 봉제할지 나타내는 관계다.

3D 의복을 만드는 순방향 과정은 다음과 같다.

```text
2D Panels + Seam 관계 + 원단 물성 + Body
                        ↓ 봉제·물리 시뮬레이션
                   3D Garment
```

패턴 복원은 이 과정을 거꾸로 풀어 3D Point Cloud나 RGB 사진에서 원래 구조를 추정한다. 하지만 비슷한 3D 실루엣을 만드는 패턴이 여러 개일 수 있어 정답이 유일하지 않다.

패턴 생성은 방향이 조금 다르다. 이미지·문장·스케치·신체 치수를 조건으로 새 Panel과 Seam 구조를 만든다. 복원과 생성은 입력과 평가 기준이 다르므로 구분해야 한다.

## 2. 가장 단순한 예: P501 남색 오버사이즈 코트의 설계 구조

P501 상품 사진과 다음 문장이 있다고 하자.

> “종아리 중간 길이의 남색 오버사이즈 더블브레스트 코트. 넓은 라펠, 긴 소매, 뒤 중심 트임.”

모델이 만들어야 할 결과는 완성된 코트 그림 한 장이 아니라 다음처럼 연결 가능한 구조다.

구조는 `앞판 ↔ 뒤판의 옆선`, `소매 위·아래 Edge`, `칼라·라펠 ↔ 목둘레`, `뒤 중심과 트임`처럼 Panel과 Seam의 관계로 표현되어야 한다.

상품 사진은 색상과 외관을 보여 주지만 패턴에 필요한 모든 정보를 보여 주지 않는다. 라펠 안쪽, 안감, 어깨 패드, 주머니감, 시접과 봉제 순서는 사진에서 보이지 않을 수 있다.

P501의 상품 DB에는 기존 `color=Navy`, `fit=Oversized` 외에 Panel 목록, Edge의 2D 좌표, Seam pair, 신체 치수, 코트 길이·여유분·라펠 너비 같은 설계 Parameter가 추가될 수 있다.

## 3. 입력·표현·수식·출력

봉제 패턴을 다음 구조로 단순화할 수 있다.

$$
S=\{P,E,M\}
$$

$P$는 가변 개수의 Panel 집합, $E$는 각 Panel의 경계 곡선, $M$은 서로 봉제될 Edge의 matching 관계다. 한 Panel의 경계는 여러 선분과 Bézier curve 등으로 표현할 수 있다.

사진 기반 복원은 다음처럼 쓸 수 있다.

$$
\hat S=F(I,\hat B)
$$

$I$는 착용 이미지이고 $\hat B$는 추정 Body다. Program 기반 생성에서는 디자인 조건 $d$와 신체 치수 $m$으로 Code $c$를 만들고 실행기가 패턴을 생성한다.

$$
c=G(d,m),\qquad S=Execute(c,m)
$$

이 표현의 장점은 “소매 길이를 3cm 늘려라” 같은 수정이 픽셀 편집이 아니라 의미 있는 Parameter 변경이 될 수 있다는 점이다.

3D Point Cloud에서는 원래 패턴의 비유일성, RGB 사진에서는 가림과 sim-to-real, Text·Image·Sketch에서는 언어의 모호성과 설계 공간, Body measurement에서는 치수와 실제 착용감의 차이가 핵심 불확실성이다.

## 4. 대표 연구는 어떻게 발전했는가?

### NeuralTailor: 3D Point Cloud에서 패턴 구조 복원

[NeuralTailor](https://korosteleva.com/publication/neuraltailor/)는 드레이프된 3D 의복 Point Cloud에서 가변 개수의 2D Panel과 Stitch 관계를 복원한다. Point-level attention으로 의복 형상을 읽고, Panel을 순차적으로 예측한 뒤 서로 봉제될 경계를 연결한다.
입력이 이미 분리된 3D 의복이라는 점이 중요하다. 일상 사진에서 사람과 옷을 분리하고 깊이를 추정하는 문제는 앞 단계에서 해결되었다고 가정한다. 합성 데이터와 제한된 자세·물성에서 학습한 모델이 모든 실물 코트 구조를 복원한다고 볼 수는 없다.

### SewFormer: 한 장의 착용 사진에서 패턴 복원

[SewFormer](https://sewformer.github.io/)는 입력을 한 장의 RGB 착용 사진으로 옮겼다. Visual encoder, Panel과 Edge를 계층적으로 생성하는 two-level Transformer decoder, Stitch prediction module로 패턴을 복원한다.
학습을 위해 약 100만 장의 합성 이미지와 정답 패턴으로 이루어진 SewFactory를 구축했다. 합성 데이터는 이미지·Body·패턴의 정확한 대응을 대규모로 만들 수 있지만, 실제 사진의 조명·주름·레이어링과의 domain gap이 남는다.

### GarmentCode: 패턴을 좌표가 아니라 Program으로 표현

[GarmentCode](https://igl.ethz.ch/projects/garmentcode/)는 Panel 좌표를 하나씩 직접 수정하는 대신 몸판·소매·칼라 같은 Component와 Interface를 조합하는 parametric pattern Program을 제안했다. 신체 치수와 디자인 Parameter를 바꾸면서도 연결 관계를 유지하는 편집이 가능하다.
Program 표현은 사람이 의미를 읽고 재사용하기 쉽지만, DSL이 표현할 수 없는 구조는 생성할 수 없다. 복잡한 다층 의복, 특정 주름과 부착 장식, 다양한 여밈 방식은 원 논문의 설계 범위 밖이거나 제한적일 수 있다.

### GarmentCodeData: 115,000개 made-to-measure 학습 데이터

[GarmentCodeData](https://igl.ethz.ch/projects/GarmentCodeData/)는 GarmentCode와 자동 치수 측정·패턴 Sampling·XPBD Draping pipeline을 사용해 115,000개의 3D made-to-measure 의복과 대응 봉제 패턴을 제공한다. 상의·셔츠·드레스·점프슈트·스커트·팬츠 등과 여러 Body shape, 세 가지 원단 물성이 포함된다.
이 데이터는 패턴과 3D 결과가 정확히 연결된 대규모 학습을 가능하게 한다. 동시에 데이터 생성기가 허용한 Component, Parameter 범위와 물성 종류가 모델이 배우는 세계의 경계가 된다.

### Design2GarmentCode: 멀티모달 입력을 Pattern Program으로

[Design2GarmentCode](https://openaccess.thecvf.com/content/CVPR2025/html/Zhou_Design2GarmentCode_Turning_Design_Concepts_to_Tangible_Garments_Through_Program_Synthesis_CVPR_2025_paper.html)는 텍스트·이미지·스케치 또는 그 조합을 해석해 GarmentCode 기반 parametric pattern-making Program과 설정을 생성한다. 생성한 Code를 실행하고 규칙과 Rendering 결과를 검사하는 validation loop를 둔다.
구조가 명시된 Code를 만들기 때문에 편집과 검증에 유리하다. 그러나 halter neck의 가는 strap, 비정형 bodice처럼 기존 DSL의 설계 공간을 벗어나는 의복은 표현하기 어렵다.

### AIpparel: 패턴을 Token으로 학습하는 멀티모달 모델

[AIpparel](https://openaccess.thecvf.com/content/CVPR2025/html/Nakayama_AIpparel_A_Multimodal_Foundation_Model_for_Digital_Garments_CVPR_2025_paper.html)은 120,000개가 넘는 의복의 Text·Image·Sewing pattern 주석으로 large multimodal model을 미세 조정한다. 복잡한 패턴을 효율적으로 예측하기 위한 tokenization을 제안하고, Text-to-garment·Image-to-garment와 언어 지시 기반 편집을 다룬다.
큰 모델과 많은 데이터가 있어도 결과는 학습 패턴의 표현과 데이터 분포에 의존한다. “패턴을 출력했다”는 사실과 전문 Pattern maker가 생산에 승인했다는 사실은 동일하지 않다.

## 5. 문제 발생: 시뮬레이션되면 공장에서 만들 수 있는가?

반드시 그렇지는 않다. Panel과 Seam이 닫혀 있고 3D Draping이 성공하면 **simulation-ready**에 가까울 수 있다. 그러나 **production-ready** 패턴에는 더 많은 정보와 검증이 필요하다.

Production-ready 결과에는 봉제 여분인 Seam allowance, 맞춤 기준인 Notch, 원단 방향을 정하는 Grainline, 안감·심지, 지퍼·단추 같은 Hardware, Size 전개를 위한 Grading rule, Stitch·순서·허용오차를 담은 Sewing specification과 실제 원단 시험값이 더 필요하다.

Panel 거리 오차, Stitch accuracy와 simulation success rate가 좋아도 실물 봉제 가능성, 내구성, 착용 쾌적성은 별도의 문제다. `body-suited`라는 표현도 특정 합성 Body에서 관통 없이 Draping되었다는 뜻인지, 실제 사람에게 움직임과 압력까지 검증했다는 뜻인지 확인해야 한다.

또 생성 모델이 기존 디자인 데이터에서 학습했다면 출처·라이선스·유사 디자인 문제도 검토해야 한다. 기술적 생성 가능성은 사용 권리나 독창성을 자동으로 보장하지 않는다.

> **Simulation-ready는 Production-ready와 다르며, 생성된 패턴은 전문 Pattern maker와 실물 Sample 검증을 대체하지 않는다.**

## 짧은 활동: AI 패턴 인수 검사표 만들기

AI가 P501 패턴 JSON과 3D 시뮬레이션 이미지를 출력했다고 가정하자. 다음 네 단계의 검사표를 작성해 보자.

1. **구조·기하 검사**: Panel 수, 열린 Edge, Seam pair 누락, 봉제될 두 Edge 길이와 겹침
2. **시뮬레이션 검사**: Body 관통, 비정상적인 늘어남, 중력 하의 실루엣
3. **생산 검사**: 시접·노치·식서·안감·여밈·봉제 순서·실물 Sample

각 단계가 통과되었을 때 어떤 수준의 주장만 할 수 있는지 한 문장으로 적는다.

## 이 장의 핵심

- 봉제 패턴은 2D Panel의 기하와 Edge, Seam 연결 관계를 함께 가진 구조 데이터다.
- NeuralTailor는 3D Point Cloud에서, SewFormer는 한 장의 RGB 사진에서 패턴 복원을 시도한다.
- GarmentCode는 패턴을 재사용·편집 가능한 Program으로 표현하고, GarmentCodeData는 대규모 학습용 패턴·3D 쌍을 제공한다.
- Design2GarmentCode는 Pattern Program을 생성하고, AIpparel은 멀티모달 모델이 tokenized pattern을 생성·편집하게 한다.
- 모델은 학습 데이터와 DSL이 표현하는 설계 공간을 자동으로 넘어설 수 없다.
- **3D 표면은 패턴이 아니며, simulation-ready 패턴은 production-ready 패턴이 아니다.**
