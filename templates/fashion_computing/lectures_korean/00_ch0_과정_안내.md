# Fashion Computing 과정 안내

> **문헌 검토 기준일: 2026-09-09**  
> 각 장은 논문·학회·공식 프로젝트 링크를 우선하며, 출판 논문과 preprint를 구분해 읽는다. 수치가 있으면 그 논문의 데이터셋·장비·평가 정의 안에서만 해석한다.

> **이 과정의 목표**  
> 패션 AI 논문을 모델 이름이 아니라 입력 데이터, 사람이 붙인 정답, 출력, 평가 지표와 실패 조건으로 읽는다.

## 선수 지식

- Data Literacy: 데이터가 측정과 선택의 결과라는 관점
- AI Basic: Prediction, Loss, Parameter, Embedding의 기본 개념
- AI Math: 벡터 유사도와 평가 수식은 필요할 때 선택적으로 참고

전체 과정에서의 위치는 [전체 과정 지도](templates/00_start_here/lectures_korean/00_ch0_전체_과정_지도.md)를 참고한다.

## 코어 트랙과 심화 장

이 과정은 서로 다른 8개 하위 분야를 다루며 난이도 차이가 크다. 처음 읽을 때는 **코어 트랙(1~4·8장)**을 먼저 완주하고, 3D·봉제 패턴·천 물리에 관심이 있으면 심화 장을 추가한다.

| 구분 | 장 | 성격 |
|---|---|---|
| 코어 | 1~4장 | 이미지 이해·검색·코디·가상 착의. 패션 서비스와 직접 연결 |
| 코어 | 8장 | 평가와 책임. 모든 장의 공통 관점 |
| 심화 · 선택 | 5장 | 사진에서 몸·옷의 3D 표면 복원 |
| 심화 · 선택 | 6장 | 이미지·문장에서 봉제 패턴 생성 |
| 심화 · 선택 | 7장 | 천의 움직임 예측과 로봇의 실물 조작 |

## 과정의 연속 사례

모든 장에서 `P501 남색 오버사이즈 코트`를 사용한다. 같은 상품을 픽셀, 라벨, 검색 벡터, 가상 착의, 3D 표면, 봉제 패턴과 실물 조작으로 바꾸며 표현의 차이를 비교한다.

## 논문 읽기 공통 질문

| 항목 | 반드시 확인할 질문 |
|---|---|
| 문제 | 어떤 패션 업무를 계산 문제로 바꾸었는가? |
| 입력 | 이미지·문장·몸·패턴·센서 중 무엇을 사용하는가? |
| 정답 | 누가 어떤 기준으로 라벨을 만들었는가? |
| 출력 | Box, Mask, Vector, Image, Mesh, Pattern 중 무엇인가? |
| 평가 | 지표가 실제 사용 목적의 어느 부분만 측정하는가? |
| 실패 | 새로운 몸·문화·소재·촬영 환경에서 무엇이 무너지는가? |
