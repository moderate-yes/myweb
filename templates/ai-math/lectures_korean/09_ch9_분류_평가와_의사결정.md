# 분류 평가에서 의사결정까지

> **이 장의 중심 질문**  
> 모델의 확률을 어떻게 행동으로 바꾸고, 서로 다른 오류의 비용을 어떻게 비교할까?

> **AI Basic 연계**: AI Basic 7~8장을 읽었다면 이 장을 함께 본다. 확률을 임계값·비용·하위 집단까지 포함한 평가 설계로 연결한다.

## 학습 목표

- Threshold를 바꿀 때 FP와 FN이 어떻게 달라지는지 설명한다.
- Accuracy·Precision·Recall·F1·PR curve를 목적에 맞게 선택한다.
- Calibration과 업무 비용을 포함한 평가표를 설계한다.

## 1. 확률과 결정은 다르다

모델이 반품 확률 0.63을 냈다는 사실은 아직 행동이 아니다. 상담 안내를 보낼지, 추가 확인을 요청할지 정하려면 Threshold가 필요하다. Threshold를 낮추면 더 많은 Positive를 찾지만 오경보도 늘 수 있다.

|  | 실제 Positive | 실제 Negative |
|---|---:|---:|
| 예측 Positive | TP | FP |
| 예측 Negative | FN | TN |

$$
\operatorname{Precision}=\frac{TP}{TP+FP},\qquad
\operatorname{Recall}=\frac{TP}{TP+FN}
$$

$$
F1=2\frac{\operatorname{Precision}\times\operatorname{Recall}}{\operatorname{Precision}+\operatorname{Recall}}
$$

## 2. 불균형 데이터와 PR curve

반품률이 2%라면 모두 정상이라고 예측해도 Accuracy는 98%다. 이때 Accuracy만으로 모델을 고를 수 없다. 여러 Threshold에서 Precision과 Recall의 교환을 보는 PR curve와, 아무 모델도 쓰지 않았을 때의 기준선을 함께 본다.

| 업무 | 더 비싼 오류 | 우선 확인할 지표 |
| --- | --- | --- |
| 위험 불량품 탐지 | FN: 놓침 | Recall, FN rate |
| 정상 고객 자동 차단 | FP: 오경보 | Precision, FP rate |
| 희귀 반품 위험 선별 | FP와 FN 모두 | PR curve, 비용 함수 |

## 3. Calibration: 0.7은 정말 70%인가

확률 0.7을 받은 사례 100개 중 실제 Positive가 약 70개라면 잘 calibration됐다고 말할 수 있다. 순위가 좋은 모델도 확률이 과신되어 있을 수 있으므로, 확률 자체로 인력·재고를 배분한다면 calibration curve와 Brier score를 함께 본다.

## 4. 선택 심화: Entropy와 Decision Tree

Binary class 비율이 $p$와 $1-p$일 때 entropy는 다음과 같다.

$$
H(Y)=-p\log_2p-(1-p)\log_2(1-p)
$$

한 class만 있으면 entropy는 0이고, 두 class가 반반이면 불확실성이 크다. Decision tree는 분할 전후 entropy 감소량인 information gain 등을 사용할 수 있다. 그러나 feature importance는 특정 데이터와 모델에서 나온 값이며 인과효과를 뜻하지 않는다.

## 5. 통합 평가 카드

P501 코트의 반품 위험 모델을 평가한다고 하자.

1. 시간 순서대로 Train·Validation·Test를 나눈다.
2. Test 전에 Validation set에서 Threshold 후보를 고른다.
3. 전체와 사이즈·국가·신규 고객별 confusion matrix를 계산한다.
4. FN 한 건과 FP 한 건의 실제 비용을 추정한다.
5. Calibration과 분포 변화 감시 기준을 기록한다.

## 짧은 활동

TP=40, FP=10, FN=20, TN=930일 때 Precision과 Recall을 계산한다. 놓침 비용이 오경보의 다섯 배라면 Threshold를 낮추는 실험이 왜 합리적인지, 동시에 무엇을 감시해야 하는지 쓰시오.

<details><summary>짧은 활동 풀이</summary>

Precision은 $40/(40+10)=0.8$, Recall은 $40/(40+20)\approx0.667$이다. Threshold를 낮추면 Recall이 올라갈 수 있지만 FP와 처리 비용도 늘 수 있으므로 비용 합계와 하위 집단별 오류를 함께 본다.

</details>

## 학습 점검

1. 반품률이 2%인 데이터에서 Accuracy만으로 모델을 고를 수 없는 이유는 무엇인가?
2. "확률 0.7이 잘 calibration됐다"는 것은 무엇을 뜻하는가?
3. Threshold를 낮추면 FP와 FN은 각각 어떻게 변하는가?

<details><summary>정답과 해설 보기</summary>

1. 모두 정상이라고 예측해도 Accuracy가 98%가 되므로, 여러 Threshold에서의 Precision·Recall 교환(PR curve)과 아무 모델도 쓰지 않은 기준선을 함께 봐야 한다.
2. 확률 0.7을 받은 사례 100개 중 실제 Positive가 약 70개라는 뜻이다.
3. 더 많은 사례를 Positive로 예측하므로 FN(놓침)은 줄고 FP(오경보)는 늘어난다.

</details>
