# Consumer Data Utilization 과정 안내

> **이 과정의 목표**  
> 패션 쇼핑몰의 운영 기록을 분석 가능한 데이터로 바꾸고, 결과를 검증 가능한 의사결정으로 연결한다.

## 선수 지식과 대상

Data Literacy의 표·지표·상관과 인과 개념을 이해한 학습자를 권장한다. 1~4장은 코딩 없이 읽을 수 있지만, **5장부터는 코드를 직접 실행**한다. 파이썬이 처음이라면 [Python Basic](templates/python_basic/lectures_korean/00_ch0_과정_안내.md) 과정을 먼저 마치는 것을 권장한다. 최소한 pandas의 `read_csv`, 필터, `groupby`, `merge`(Python Basic 4장)까지는 익힌 상태로 5장에 들어와야 한다. 전체 과정에서의 위치는 [전체 과정 지도](templates/00_start_here/lectures_korean/00_ch0_전체_과정_지도.md)를 참고한다.

## 세 개의 모듈

| 모듈 | 장 | 최종 산출물 |
|---|---|---|
| 문제와 데이터 설계 | 1~4장 | Business Question과 Data Audit |
| 재현 가능한 분석 | 5~9장 | 수집·정제·텍스트·이상치·RFM·검색 결과 |
| 서비스와 의사결정 | 10~14장 | SEO·UX 실험·생성 콘텐츠·도구 선택·Evidence Brief |

## 공통 실습 데이터

이 과정의 실습은 `templates/consumer_data_utilization/data/`의 작은 가상 패션몰 데이터를 기준으로 진행한다. 실제 고객 개인정보가 포함되지 않으며, 각 장에서 같은 `product_id`, `customer_id`, `order_id`를 이어서 사용한다.

| 파일 | 역할 |
|---|---|
| `products.csv` | 상품·카테고리·가격·상품명 |
| `orders.csv` | 주문·고객·상품·수량·날짜 |
| `customers.csv` | 가입일·유입경로·동의 상태 |
| `events.csv` | 조회·장바구니·구매 이벤트 |

- [실습 데이터 설명과 스키마](templates/consumer_data_utilization/data/README.md)
- [Python 시작 노트북](templates/consumer_data_utilization/notebooks/consumer_data_starter.ipynb)

노트북은 저장소를 내려받은 뒤 Jupyter 또는 Colab에 업로드해 실행한다. 각 결과에는 사용한 행 수, 제외 규칙과 기준 기간을 함께 기록한다.

## 과정 완료 기준

14장의 Evidence Brief에 앞 장에서 만든 표와 그래프를 근거로 연결하고, 다음 네 가지를 반드시 포함한다.

- 재현 가능한 입력 데이터와 처리 규칙
- 기준선과 비교 대상
- 결과가 말하지 못하는 것
- 실행·중단·재검토 조건
