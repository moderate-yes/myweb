# 온라인 소비자 행동 데이터란 무엇인가

소비자가 제품을 인지하고, 탐색하고, 구매하고, 사용한 뒤 평가하는 전 과정에서 남기는 의사결정과 행동의 흔적을 **소비자 행동 데이터**라고 한다. 기업은 이 흔적을 기록하고 분석해 최대한 빠르게 의사결정에 반영하려 한다. 오프라인 매장에서도 소비자는 흔적을 남기지만, 온라인 환경은 기록의 용이성과 실시간 처리 가능성 덕분에 그 깊이와 종류가 오프라인과 비교할 수 없을 만큼 다양해진다.

> **생각해 보기**
> 온라인 쇼핑몰에서 상품을 클릭만 하고 사지 않은 고객과, 매장에서 옷을 입어만 보고 나간 고객이 있다. 두 고객에 대해 기업이 알 수 있는 정보의 양과 질은 얼마나 다를까?

## 학습 목표

이 단원을 마치면 다음을 할 수 있다.

- 온라인 소비자 행동 데이터를 형태와 수집 난도에 따라 구분해 설명할 수 있다.
- 거래·행동 로그·리뷰·UGC·위치·아이트래킹 데이터 각각의 특징과 활용 사례를 들 수 있다.
- 데이터 유형에 따라 필요한 수집·분석 도구가 달라지는 이유를 설명할 수 있다.
- 특정 브랜드가 어떤 유형의 소비자 데이터를 수집하고 있는지 스스로 분류할 수 있다.

## 핵심 용어

- **정형 데이터(structured data)**: 거래 기록, 인구통계 정보처럼 표 형태로 정리하기 쉬운 데이터.
- **행동 로그 데이터(behavioral log data)**: 웹사이트·앱에 심은 태그를 통해 수집되는 클릭, 체류 시간, 이동 경로 등의 기록.
- **UGC(User Generated Content)**: 리뷰, SNS 착용샷처럼 소비자가 자발적으로 만들어내는 콘텐츠.
- **지오펜싱(geofencing)**: GPS·Wi-Fi·셀룰러 데이터로 지도 위에 가상의 울타리를 설정하고, 기기가 이 영역을 드나들 때 자동으로 메시지를 보내는 위치 기반 기술.

## 데이터 유형 개요

온라인 소비자 데이터는 형태와 수집 난도에 따라 넓은 스펙트럼에 분포한다. 한쪽 끝에는 거래·인구통계처럼 이미 표 형태로 정리되어 있는 정형 데이터가 있고, 다른 쪽 끝에는 텍스트·이미지처럼 가공이 필요한 데이터, 더 나아가 생체 리듬이나 감정처럼 특수한 장비 없이는 수집조차 어려운 데이터가 있다. 같은 소비자라도 이렇게 다른 층위의 데이터를 겹쳐 보아야 온전한 그림이 그려진다.

## 인구통계 및 거래 데이터

가장 기본이 되는 데이터는 회원 가입 정보, 구매 이력, 장바구니 데이터처럼 쇼핑몰을 운영하는 과정에서 자연스럽게 쌓이는 정형 데이터다. 이 데이터만으로도 놀라운 예측이 가능하다는 것을 보여주는 사례가 있다.

> **사실 확인 필요**
> 아래 사례는 미국 유통업체 Target의 내부 직원 인터뷰를 통해 알려진 내용으로, 공식적으로 확인된 바는 없다. 정확한 수치와 절차는 원문 보도를 통해 재확인해야 한다.

미국의 대형 유통업체 Target은 구매 데이터와 고객 인구통계 데이터를 결합해 임신 가능성이 높은 고객을 예측하고, 관련 쿠폰을 발송해 매출을 크게 끌어올렸다고 알려져 있다. 무향 로션, 미네랄 보충제처럼 임신 초기 소비자들이 함께 구매하는 경향이 있는 상품 조합을 찾아낸 것이 핵심이었다. 이 사례는 정형 데이터라도 여러 항목을 결합하면 개별 항목만으로는 보이지 않던 패턴이 드러난다는 점을 보여준다.

## 온라인 행동 로그 데이터

웹사이트와 앱에 태그를 심으면 방문 고객의 위치, 체류 시간, 클릭 등 의사결정 및 행동 패턴을 수집할 수 있다. 이런 로그 데이터는 주로 UX 개선에 활용되며, 국내 스타트업 와이즐리는 메인 페이지·스토어 페이지·제품상세페이지·랜딩페이지별로 로그 데이터를 나누어 분석한 사례로 알려져 있다.

로그 데이터 수집·분석에는 여러 도구가 쓰이는데, 대표격인 GA4(Google Analytics 4)와 Amplitude는 성격이 꽤 다르다.

| 항목 | Amplitude | GA4 |
| --- | --- | --- |
| 데이터 샘플링 | 샘플링 없는 전수 분석 | 50만 세션 초과 시 샘플링 발생 |
| 리텐션 분석 | D1·D7·D30 코호트별 정밀 비교 | 단순 재방문율 수준 |
| 퍼널 분석 | 순서 유연, 이탈 후 경로 추적 | 순서 고정, 이탈 후 추적 어려움 |
| 세션 리플레이 | 사용자 행동 영상 녹화·재생 지원 | 미지원 |

D1·D7·D30은 각각 가입 다음 날, 7일 후, 30일 후 다시 접속한 비율을 뜻하는 리텐션 지표다. 무료로 시작할 수 있는 GA4는 폭넓게 쓰이지만, 정밀한 코호트 비교나 세션 리플레이가 필요하면 Amplitude 같은 유료 도구로 넘어가는 경우가 많다.

## 댓글·리뷰·UGC 데이터

상품에 달리는 댓글과 리뷰는 소비자가 자발적으로 남기는 텍스트 데이터다. AI 기술이 상용화되면서 리뷰 속 사이즈, 만족도, 배송처럼 핵심 주제를 자동으로 추출·분류하는 기술의 진입 장벽이 낮아졌고, 그 결과 패션 기업들의 데이터 기반 서비스 적용이 빠르게 보편화되고 있다. 애슬레저 브랜드 안다르는 고객이 남긴 사이즈 관련 댓글을 모아 다음 구매자에게 사이즈를 제안하는 데 활용하는 것으로 알려져 있다.

리뷰뿐 아니라 SNS 착용샷처럼 고객이 자발적으로 만들어내는 콘텐츠 전체를 UGC라 부른다. 해외 플랫폼과 국내 플랫폼은 콘텐츠 작성 방식과 표현이 다르기 때문에, 국내 소셜 데이터를 수집·분석할 때는 썸트렌드나 크리마리뷰처럼 국내 환경에 특화된 도구가 주로 쓰인다.

## 위치·아이트래킹 데이터

위치 데이터를 활용하면 오프라인 매장과 온라인 프로모션을 연결할 수 있다. 2018년 진행된 버거킹의 'Whopper Detour' 캠페인이 대표적인 사례로 소개된다. 맥도날드 매장 반경 180m 안에 있는 고객이 버거킹 앱으로 와퍼를 주문하면 1센트에 구매할 수 있게 한 프로모션으로, 지오펜싱 기술을 마케팅에 적용한 예시로 자주 인용된다.

아이트래킹 데이터는 고객의 무의식적 관심사를 파악하기 위한 기술로, 온라인 UX 분석을 넘어 오프라인 매장의 진열과 동선 최적화까지 적용 범위를 넓혀가고 있다. 다만 장비와 실험 설계 비용이 크기 때문에 아직은 대규모 실무보다 리서치 목적으로 더 많이 쓰인다.

## 데이터가 쌓일 때 벌어지는 일: 자체 분석 스택

고객 수가 많은 기업은 상용 분석 툴만으로는 한계를 느끼고 자체 데이터 웨어하우스와 분석 스택(Raw DB → SQL → Python → Dashboard)을 구축하는 방향으로 나아간다. 의사결정 속도를 높이고 심화 분석을 구현할 수 있다는 장점이 있지만, 파편화된 데이터를 통합하는 비용과 데이터 주권(어디에, 어떤 형태로 데이터를 둘 것인가) 문제도 함께 따라온다. 이 판단은 이 장 뒷부분에서 다룰 "비용 효율 검토"와도 이어진다.

## 짧은 활동: 우리가 아는 쇼핑몰의 데이터 지도 그리기

자신이 자주 이용하는 온라인 쇼핑몰이나 앱 하나를 떠올리고, 아래 표를 채워보자.

| 데이터 유형 | 이 쇼핑몰이 수집하고 있을 것 같은 항목 | 확인 방법 |
|---|---|---|
| 예: 행동 로그 | 클릭 순서, 체류 시간 | 개인정보처리방침의 '수집 항목' 확인 |
| 정형(거래·인구통계) |  |  |
| 리뷰·UGC |  |  |
| 위치 |  |  |

작성 후, 표에 없는 유형의 데이터를 이 쇼핑몰이 수집한다면 어떤 새로운 서비스가 가능할지 한 문장으로 적어보자.

## 이 장의 핵심

- 소비자 행동 데이터는 인지·탐색·구매·사용평가 전 과정에서 남는 의사결정과 행동의 기록이다.
- 온라인 환경은 기록 용이성과 실시간 처리 가능성 덕분에 오프라인보다 훨씬 다양한 데이터를 만들어낸다.
- 데이터는 정형 거래 데이터부터 행동 로그, 리뷰·UGC, 위치, 아이트래킹까지 형태와 수집 난도가 다른 여러 층위로 존재한다.
- 같은 목적(예: UX 개선)이라도 데이터 유형에 따라 GA4·Amplitude·썸트렌드·크리마리뷰처럼 서로 다른 도구가 필요하다.
- 고객 규모가 커지면 상용 툴을 넘어 자체 분석 스택을 구축하는 선택지가 생기지만, 그만큼 비용과 데이터 주권 문제도 커진다.

## 알아볼 것: 생성형 AI로 풀어보는 과제

1. **데이터 유형 매칭하기**: 관심 있는 패션 브랜드 앱을 하나 골라, 생성형 AI에게 "이 브랜드가 온라인에서 수집할 것으로 추정되는 데이터 유형을 이 장에서 배운 6가지(정형·행동로그·리뷰UGC·위치·아이트래킹·자체스택) 기준으로 분류해줘"라고 요청해보자. AI의 답변 중 실제로 앱 개인정보처리방침에서 확인 가능한 부분과 추측에 불과한 부분을 구분해본다.
2. **도구 비교표 만들기**: 생성형 AI에게 "GA4와 Amplitude 중 소규모 패션 쇼핑몰에 더 적합한 쪽을 비용과 기능 측면에서 비교해줘"라고 요청하고, 이 장의 비교표와 다른 점이 있는지 검토한다.

> **알아두기**
> 생성형 AI의 답변은 참고 자료이지 출처가 아니다. 특정 기업의 데이터 활용 사례나 도구의 가격 정책은 반드시 공식 자료로 다시 확인한다.
