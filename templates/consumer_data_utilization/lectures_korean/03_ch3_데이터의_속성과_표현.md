# 데이터의 모양: 속성과 표현

분석가가 되기 위해 알아야 할 것은 분석 기법 이전에 **데이터가 컴퓨터 안에서 어떤 모양으로 존재하는가**이다. 사람은 "일"이라는 이름과 "1개"라는 수량을 문맥만으로 구별하지만, 컴퓨터는 그 둘의 차이를 미리 알려주지 않으면 계산할 수 없다. 이 장에서는 수치형 데이터의 기본 구조와 여섯 가지 속성, 그리고 텍스트·이미지 데이터가 결국 숫자로 어떻게 바뀌는지를 살펴본다.

> **생각해 보기**
> 이름 "일"과 구매 수량 "1"은 둘 다 화면에는 똑같이 "1"로 보일 수 있다. 컴퓨터가 이 둘을 구별하지 못한다면 어떤 문제가 생길까?

## 학습 목표

이 단원을 마치면 다음을 할 수 있다.

- 수치형 데이터를 인덱스·컬럼·값·속성의 구조로 설명할 수 있다.
- 명목·이진·순서·숫자·날짜·시계열 속성의 차이를 예시와 함께 구분할 수 있다.
- 텍스트와 이미지 데이터가 각각 몇 차원의 숫자로 표현되는지 설명할 수 있다.
- 데이터 표현 방식이 감성분석·추천·객체인식 같은 서비스와 어떻게 연결되는지 설명할 수 있다.

## 핵심 용어

- **속성(attribute)**: 값이 어떻게 연산되고 비교될 수 있는지를 결정하는, 데이터 뒤에 숨어 있는 성격.
- **명목 속성(nominal attribute)**: 사물의 기호나 이름을 나타내며 순서나 연산이 의미 없는 속성.
- **순서 속성(ordinal attribute)**: 유의미한 순위는 있지만 값 사이의 거리는 알 수 없는 속성.
- **시계열 속성(time-series attribute)**: 시간의 흐름이 값의 배열에 영향을 준다고 가정하는 속성.

## 수치형 데이터의 구조: 인덱스, 컬럼, 값, 속성

수치형 데이터는 인덱스와 컬럼으로 이루어지고, 컬럼은 다시 값과 속성의 결합으로 구성된다. 예를 들어 고객 "일"이 22세 남성이고 22일에 상품 1개를 구매했다면, 아래처럼 하나의 행(인덱스 1)이 만들어진다.

| 인덱스 | name | age | gender | date | amount |
|---|---|---|---|---|---|
| 1 | 일 | 22 | M | 22 | 1 |
| 2 | 민수 | 19 | F | 21 | 2 |

여기서 name, age, gender, date, amount가 컬럼이고, 각 칸에 들어간 값이 값(value)이다. 문제는 이 표만 보고는 **속성**을 알 수 없다는 점이다. name 컬럼의 "일"은 연산이 되지 않는 이름이고, amount 컬럼의 "1"은 더하고 뺄 수 있는 수량이라는 것을 사람은 문맥으로 알아채지만, 컴퓨터에게는 이 정보를 명시적으로 전달해야 한다. 데이터 분석은 결국 컴퓨터를 통해 이루어지기 때문에, 분석가는 속성을 이해하고 컴퓨터에 전달할 수 있어야 한다.

## 데이터의 여섯 가지 속성

| 속성 | 정의 | 특징 |
|---|---|---|
| 명목 속성 | 사물의 기호나 이름 | 유의미한 순서가 없고 연산이 불가능하다. 숫자로 기호화해도 더하면 의미가 사라진다. 최빈값 계산에는 쓸 수 있다 |
| 이진 속성 | 두 범주를 True/False로 표현 | 조건 만족 여부를 나타낼 때 자주 쓰인다. 다만 현실에서 정확히 두 범주로만 나뉘는 경우는 생각보다 적다 |
| 순서 속성 | 유의미한 순위를 값으로 가짐 | VVIP와 VIP 사이의 '거리'는 알 수 없지만 순위는 비교할 수 있다. 연속값을 유한 개의 순서 범주로 나눌 때도 쓴다 |
| 숫자 속성 | 정수·실수로 표현되는 측정 가능한 양 | 값 사이의 차이를 비교할 수 있고, 0이라는 기준점이 존재한다 |
| 날짜 속성 | 연·월·일·시간·요일을 값으로 가짐 | 숫자 속성과는 다른 연산 방식을 가진다(1월 31일 + 1일 = 2월 1일). 시간대 차이에 주의해야 한다 |
| 시계열 속성 | 순차적으로 정해진 값의 집합 | 시간의 흐름이 값 배열에 영향을 준다고 가정한다. 텍스트도 순차적 특징이 있어 시계열 분석의 대상이 될 수 있다 |

이 여섯 속성은 데이터를 다루는 도구를 효율적으로 쓰기 위한 최소한의 어휘다. 예를 들어 고객 등급(VVIP·VIP·NORMAL)은 순서 속성이므로 평균을 구하는 것은 의미가 없지만, 등급별 인원수(최빈값에 가까운 개념)를 세는 것은 의미가 있다.

## 텍스트 데이터는 어떻게 숫자가 되는가

상품 설명처럼 문장으로 이루어진 텍스트 데이터는 일반적으로 **문장 × 단어 × 문서**의 3차원으로 다뤄진다. 우선 등장하는 모든 단어를 모아 사전을 만들고, 각 단어에 번호를 매긴다. 그 다음 문장 하나하나를 "이 사전의 어떤 단어가 몇 번 등장했는가"를 나타내는 숫자 배열로 바꾼다.

```
1번째 문장: 허벅지부터 발목까지 자연스럽게 좁아지는 슬림 핏...
   →  [11, 22, 33, ……… 0, 0]
2번째 문장: 취향에 따라 밑단을 커팅해서 착용할 수 있도록...
   →  [34, 23, 50, ……… 0, 0]
```

이렇게 숫자로 바뀐 텍스트는 상품 댓글의 감성분석, 패션 리테일러의 챗봇, 객체명 인식 기반의 상품 분류, 토픽모델링을 활용한 패션 이슈 분석 등에 활용된다.

## 이미지 데이터는 어떻게 숫자가 되는가

이미지 데이터는 일반적으로 **높이 × 너비 × 색상 채널 × 이미지 수**의 4차원으로 표현된다. 분석가는 사진 한 장을 R·G·B 세 가지 채널로 나누고, 각 채널의 밝기를 0과 1 사이의 숫자로 표현한다. 예를 들어 어두운 부분은 낮은 숫자로, 원색에 가까운 빨간 부분은 높은 숫자로 표현된다. RGB 외에도 명도·채도를 강조하는 HSV 같은 표현 방식이 쓰이기도 한다.

이렇게 숫자로 바뀐 이미지는 상품 추천(비슷하게 생긴 상품 찾기)이나, 상품 이미지에서 트렌드를 읽어내기 위한 객체 인식 등에 쓰인다. 다음 장(이미지 유사도 기반 추천)에서 이 원리를 더 깊이 다룬다.

## 데이터를 이해할 때 놓치기 쉬운 두 가지

첫째, **기록되지 않은 것은 데이터가 될 수 없다.** 삼성동에 사는 고객이 필드 재킷을 사려고 노트북을 켜고 쇼핑을 시작했다는 상황을 아무리 생생하게 상상해도, 클릭 로그가 기록되어 있지 않다면 그 상황은 분석 대상이 될 수 없다. 둘째, **데이터를 기록하기 위한 우선순위가 필요하다.** 모든 행동을 다 기록할 수는 없으므로, 분석 목적에 맞춰 무엇을 먼저 기록할지 판단하는 것도 분석가의 일이다.

## 짧은 활동: 속성 분류하기

아래 쇼핑몰 데이터의 각 컬럼이 어떤 속성에 해당하는지 표에 적어보자.

| 컬럼 | 예시 값 | 속성(명목/이진/순서/숫자/날짜/시계열) |
|---|---|---|
| 고객 등급 | VIP, VVIP, NORMAL |  |
| 구매 금액 | 39,800 |  |
| 성별 | M, F |  |
| 구매 일시 | 2022-01-02 19:35 |  |
| 회원 동의 여부 | True, False |  |

## 이 장의 핵심

- 수치형 데이터는 인덱스·컬럼·값으로 보이지만, 그 뒤에는 반드시 속성이라는 숨은 정보가 있다.
- 데이터의 속성은 명목·이진·순서·숫자·날짜·시계열 여섯 가지로 나눌 수 있고, 각각 가능한 연산과 비교 방식이 다르다.
- 텍스트 데이터는 문장×단어×문서의 3차원으로, 이미지 데이터는 높이×너비×색상채널×이미지수의 4차원으로 숫자화된다.
- 데이터로 표현되지 않은 사건은 아무리 생생해도 분석의 대상이 될 수 없으므로, 무엇을 기록할지 우선순위를 정하는 것도 분석가의 역할이다.

## 학습 점검

1. 명목 속성과 순서 속성의 차이를 예를 들어 설명하시오.
2. 날짜 속성이 숫자 속성과 다른 연산 방식을 가진다는 것이 무슨 뜻인지 예를 들어 설명하시오.
3. 텍스트 데이터가 숫자로 바뀌는 과정을 간단히 설명하시오.
4. 이미지 데이터가 표현되는 4차원은 각각 무엇인가?

<details>
<summary>정답과 해설 보기</summary>

1. 명목 속성(예: 성별)은 순서가 없고 연산이 불가능한 기호이며, 순서 속성(예: 고객 등급)은 순위는 있지만 등급 간 거리는 알 수 없는 값이다.
2. 숫자 속성은 39,800과 39,801처럼 일정한 간격으로 더하고 뺄 수 있지만, 날짜는 1월 31일에 하루를 더하면 32일이 아니라 2월 1일이 되는 것처럼 일반적인 덧셈과 다른 방식으로 계산된다.
3. 등장하는 모든 단어를 모아 사전을 만들고 각 단어에 번호를 매긴 뒤, 문장마다 어떤 단어가 몇 번 등장했는지를 숫자 배열로 바꾼다.
4. 높이, 너비, 색상 채널(RGB 등), 이미지 수(장 수)이다.

## 알아볼 것: 생성형 AI로 풀어보는 과제

1. **속성 판별 연습**: 자신이 최근 사용한 쇼핑 앱을 하나 떠올리고, 생성형 AI에게 "이 앱에서 볼 수 있는 데이터 컬럼 10개를 나열하고, 각각을 명목·이진·순서·숫자·날짜·시계열 속성으로 분류해줘"라고 요청한 뒤 이 장의 기준으로 직접 검토한다.
2. **텍스트 벡터화 이해하기**: 생성형 AI에게 "상품 설명 문장 3개를 예로 들어, 이 문장들이 숫자 벡터로 바뀌는 과정을 단계별로 보여줘"라고 요청하고, 이 장에서 설명한 사전 생성·숫자 매핑 방식과 비교해본다.

> **알아두기**
> 생성형 AI가 제시하는 속성 분류는 데이터의 실제 수집 방식에 따라 달라질 수 있다. 실무에서는 데이터베이스 스키마나 API 문서를 직접 확인하는 것이 가장 정확하다.
