# 파이썬 실습 I: 코랩과 크롤링

지금까지는 데이터가 무엇이고 어떤 모양을 가지며 어떤 패턴으로 분석되는지 개념을 다졌다. 이제부터는 실제로 손을 움직여 데이터를 모으고 분석하는 실습으로 들어간다. 이 장에서는 별도의 설치 없이 파이썬을 쓸 수 있는 구글 코랩(Colab)과, 코딩 없이 웹 데이터를 모을 수 있는 크롤링 툴 리스틀리(Listly)를 다룬다.

> **생각해 보기**
> 무신사 랭킹 페이지에 있는 상위 180개 상품의 이름과 가격을 손으로 하나하나 복사해서 엑셀에 옮긴다면 얼마나 걸릴까? 이 작업을 자동화한다면 그 시간을 어디에 쓸 수 있을까?

## 학습 목표

이 단원을 마치면 다음을 할 수 있다.

- 구글 코랩이 무엇이고 왜 데이터 분석 입문에 적합한지 설명할 수 있다.
- 코랩에서 새 노트를 만들고 셀에 코드를 작성해 실행할 수 있다.
- 크롬 확장 프로그램 리스틀리로 웹페이지의 상품 목록을 크롤링해 엑셀 파일로 내려받을 수 있다.
- 구글 드라이브에 업로드한 데이터를 코랩 노트에 연결할 수 있다.

## 핵심 용어

- **코랩(Colab)**: 구글이 제공하는 클라우드 기반 파이썬 개발 환경으로, 별도 설치 없이 브라우저에서 바로 코드를 실행할 수 있다.
- **셀(cell)**: 코랩에서 파이썬 코드를 입력하고 실행하는 단위.
- **크롤링(crawling)**: 웹페이지의 구조를 활용해 데이터를 자동으로 수집하는 작업.

## 왜 코랩인가

코랩은 구글에서 제공하는 클라우드 기반 파이썬 개발 환경이다. 일반적으로 파이썬을 쓰려면 가상환경 생성 → 파이썬 설치 → 주피터 노트북 설치 → 실행이라는 여러 단계를 거쳐야 하지만, 코랩은 구글 계정으로 로그인만 하면 바로 코드를 실행할 수 있어 설치 과정이 사실상 사라진다. 게다가 Tensorflow, Keras, matplotlib, scikit-learn, pandas처럼 데이터 분석에 자주 쓰이는 패키지가 미리 설치되어 있고, GPU도 무료로 쓸 수 있으며, 코드 공유도 링크 하나로 간단하다. 이런 이유로 입문자가 파이썬을 처음 접하기에 특히 적합하다.

## 코랩 시작하기

1. 구글 계정에 로그인한 상태에서 `colab.research.google.com`에 접속하거나, 크롬에서 "구글 코랩"을 검색해 접속한다.
2. 새 노트를 생성한다.
3. 화살표 옆의 빈 입력 공간이 **셀**이다. 셀에 파이썬 코드를 입력하고 실행 버튼을 누르면 바로 결과를 볼 수 있다.
4. `Ctrl+S`로 저장하면 구글 드라이브의 "Colab Notebooks" 폴더에서 노트 파일을 확인할 수 있다.

내 컴퓨터에 있는 데이터를 코랩에서 쓰려면, 먼저 구글 드라이브에 파일을 업로드한 뒤 아래 코드로 드라이브를 연결한다.

```python
from google.colab import drive
drive.mount('/content/drive/')
```

연결이 끝나면 왼쪽 폴더 아이콘에서 `content > drive > MyDrive` 경로를 통해 업로드한 파일이 잘 연동되었는지 확인할 수 있다. GPU가 필요한 작업(이미지·텍스트 데이터를 활용한 AI 훈련 등)이라면 런타임 설정에서 GPU를 켤 수 있다.

## 크롤링 툴 리스틀리 소개

리스틀리(Listly)는 크롬 웹 브라우저의 확장 프로그램으로, 웹페이지의 구조를 활용해 데이터를 코드 없이 수집할 수 있는 크롤링 툴이다. `listly.io`에 접속해 "크롬 확장 프로그램 추가"를 누르면 브라우저 우측 상단에 리스틀리 아이콘이 나타난다.

## 리스틀리로 랭킹 페이지 수집하기

1. 크롤링하고 싶은 페이지(예: 무신사 랭킹 1위~180위)를 연다.
2. 우측 상단의 리스틀리 아이콘을 클릭하고 "LISTLY 전체"를 선택한다.
3. 추출된 탭에서 스크롤을 내리며 크롤링 상태를 확인한 뒤, "엑셀" 버튼을 눌러 파일을 내려받는다.
4. 페이지가 여러 장으로 나뉘어 있다면(예: 2페이지), 페이지를 바꾼 뒤 같은 과정을 반복해 두 번째 엑셀 파일을 받는다.

이렇게 만들어진 엑셀 파일 하나에는 상품명, 가격, 할인율, 이미지 링크 등 페이지에 보이는 정보가 열(컬럼)로 정리되어 담긴다. 이 파일이 다음 장에서 다룰 텍스트 마이닝 실습의 원재료가 된다.

## 수집한 데이터를 코랩으로 가져오기

리스틀리로 받은 엑셀 파일을 구글 드라이브에 업로드하면, 앞서 배운 `drive.mount()` 코드로 코랩 노트에서 곧바로 불러올 수 있다.

```python
import pandas
df_1 = pandas.read_excel('/content/drive/MyDrive/musinsa_1.xlsx')
df_1.head()
```

`head()` 함수는 데이터의 앞부분 5개 행만 보여주는 함수로, 데이터를 다 열어보지 않고도 구조를 빠르게 확인할 수 있어 자주 쓰인다. 반대로 `tail()`은 마지막 부분을 보여준다.

## 실제 사례: 왜 하필 파이썬인가

크롤링만 놓고 보면 리스틀리 같은 코드 없는(no-code) 도구로도 충분해 보일 수 있다. 실제로 데이터 수집에는 웹스크래퍼, 소셜네트워크 분석에는 노드엑셀, 머신러닝에는 래피드마이너, 텍스트 분석에는 텍스톰·UCINET, 대시보드 제작에는 구글 데이터 스튜디오처럼 목적별 GUI 도구가 이미 존재한다. 하지만 이 도구들을 하나씩 배우는 데 걸리는 총 시간은 파이썬 하나를 배우는 시간과 비슷하다고 알려져 있다.

파이썬이 추천되는 이유는 세 가지로 요약된다. 첫째, 온라인 데이터 수집(스크래피, 뷰티풀숩, 셀레니움)부터 이미지·텍스트 처리, numpy·scipy·scikit-learn·tensorflow·pytorch 같은 분석 패키지까지 한 언어로 이어진다. 둘째, 엑셀로 감당하기 어려운 대용량 데이터도 상대적으로 빠르게 처리할 수 있다. 셋째, sqlalchemy로 데이터베이스에 연결하거나 장고·플라스크 같은 프레임워크로 실제 서비스를 만드는 것까지 같은 언어로 확장된다. 이 사이트의 "Data Literacy" 과목에 있는 Flask 실습 장들이 바로 이 마지막 지점, 즉 분석에서 서비스로 이어지는 과정을 보여준다.

## 짧은 활동: 나만의 크롤링 계획 세우기

관심 있는 온라인 쇼핑몰이나 브랜드를 하나 정하고, 아래 질문에 답해보자.

1. 어떤 페이지(랭킹, 신상품, 리뷰 등)를 수집하고 싶은가?
2. 그 페이지에서 얻고 싶은 컬럼은 무엇인가? (상품명, 가격, 리뷰 수 등)
3. 이 데이터로 어떤 질문에 답하고 싶은가?

## 이 장의 핵심

- 코랩은 설치 없이 브라우저에서 바로 파이썬을 실행할 수 있는 클라우드 개발 환경으로, 데이터 분석에 필요한 패키지가 미리 설치되어 있다.
- 코랩에 로컬 데이터를 쓰려면 구글 드라이브에 업로드한 뒤 `drive.mount()`로 연결한다.
- 리스틀리 같은 크롬 확장 프로그램은 코드 없이도 웹페이지 데이터를 엑셀로 수집할 수 있게 해준다.
- 목적별 GUI 도구가 많지만, 수집부터 분석·서비스까지 이어서 다루려면 파이썬 하나를 배우는 편이 총 학습 시간 면에서 유리하다.
