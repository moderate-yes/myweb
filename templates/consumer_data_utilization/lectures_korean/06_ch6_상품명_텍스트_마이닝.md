# 파이썬 실습 II: 상품명 텍스트 마이닝

앞 장에서 크롤링으로 모은 무신사 랭킹 상품 데이터(상품명, 가격)가 두 개의 엑셀 파일로 준비되어 있다고 하자. 이 장에서는 이 데이터를 코랩에서 불러와, 상품명에 가장 많이 쓰인 단어를 찾고, 가격대를 눈으로 확인하는 과정을 코드와 함께 끝까지 따라간다. 실제 강의에서 쓰인 예시는 니트 카테고리 180개 상품이었다.

> **생각해 보기**
> "요즘 잘 팔리는 상품 이름에는 공통점이 있을까?"라는 질문에 감으로 답하는 것과, 180개 상품명을 실제로 세어서 답하는 것은 결과가 얼마나 다를 수 있을까?

## 학습 목표

이 단원을 마치면 다음을 할 수 있다.

- pandas로 두 개의 엑셀 데이터를 불러와 필요한 컬럼만 고르고 하나로 합칠 수 있다.
- 한국어 형태소 분석기로 상품명에서 명사만 추출할 수 있다.
- Counter로 단어 빈도를 세고, 결과를 막대그래프와 워드클라우드로 시각화할 수 있다.
- 가격 데이터를 정제하고 분포를 상자그림(boxplot)으로 확인할 수 있다.

## 핵심 용어

- **형태소 분석(morphological analysis)**: 문장을 의미를 가진 최소 단위(형태소)로 쪼개고 품사를 판별하는 자연어 처리 기법.
- **불용어(stopword)**: 분석 목적상 의미가 크지 않다고 판단해 제거하는 단어나 기호.
- **토큰화(tokenization)**: 문장이나 문단을 분석의 최소 단위(여기서는 단어)로 자르는 과정.

## 데이터 불러오고 합치기

먼저 구글 드라이브에 올려둔 두 개의 크롤링 결과를 불러온다.

```python
from google.colab import drive
drive.mount('/content/drive')

import pandas
df_1 = pandas.read_excel('/content/drive/MyDrive/musinsa_1.xlsx')
df_2 = pandas.read_excel('/content/drive/MyDrive/musinsa_2.xlsx')
```

리스틀리로 수집한 원본 데이터는 컬럼 이름이 `LABEL-8`, `LABEL-9`처럼 자동으로 붙어 있어 그대로는 알아보기 어렵다. 상품명과 가격에 해당하는 컬럼만 골라 이름을 바꿔준다.

```python
df_1_select = df_1[["LABEL-8", "LABEL-9"]]
df_1_rename = df_1_select.rename(columns={"LABEL-8": "product_name", "LABEL-9": "price"})

df_2_select = df_2[["LABEL-7", "LABEL-8"]]
df_2_rename = df_2_select.rename(columns={"LABEL-7": "product_name", "LABEL-8": "price"})
```

두 페이지에서 각각 받은 데이터를 하나로 합친다.

```python
df = pandas.concat([df_1_rename, df_2_rename])
len(df)   # 180
```

## 형태소 분석으로 명사 추출하기

상품명은 "워셔블 하프 집업 카라넥 하찌 니트"처럼 여러 단어가 붙어 있는 문장이다. 단어 단위로 세려면 먼저 이 문장을 쪼개야 하는데, 한국어는 조사·어미가 붙기 때문에 공백만으로 자르면 정확하지 않다. 이때 쓰는 것이 **형태소 분석기**다. 이 실습에서는 `konlpy`의 `Okt` 분석기를 사용한다.

```python
!pip install konlpy
from konlpy.tag import Okt

okt = Okt()
df["name_noun"] = df["product_name"].apply(lambda x: okt.nouns(str(x)))
```

`nouns()` 함수는 문장에서 명사만 골라 리스트로 반환한다. 예를 들어 "워셔블 하프 집업 카라넥 하찌 니트 (GREEN EARTH...)"는 `['워셔블', '하프', '집업', '카라', '넥', '하찌', '니트']`로 바뀐다. 이 과정이 곧 **토큰화**다.

## 가격 데이터 정제하기

가격 컬럼은 "49,000원\n39,800원"처럼 할인 전후 가격이 줄바꿈으로 함께 들어있는 텍스트다. "원" 앞부분만 잘라내고 콤마를 제거해 숫자로 쓸 수 있게 정제한다.

```python
df["price_origin"] = df["price"].apply(lambda x: str(x).split("원")[0])
df["price_origin"] = df["price_origin"].apply(lambda x: x.replace(",", ""))
df["price_origin"] = df["price_origin"].apply(int)
```

이 세 줄이 하는 일은 각각 "원 앞부분만 남기기", "천 단위 콤마 제거하기", "문자열을 정수로 바꾸기"다. 실무에서 마주치는 전처리 코드 대부분이 이렇게 짧은 문자열 처리 함수를 여러 번 이어붙인 형태를 띤다.

## 워드카운트: 가장 많이 쓰인 단어 찾기

180개 상품명에서 추출한 명사를 하나의 리스트로 모은 뒤, 파이썬 내장 함수 `Counter`로 등장 횟수를 센다.

```python
big_list = []
for name in df["name_noun"]:
    for word in name:
        big_list.append(word)

from collections import Counter
result = Counter(big_list)
result.most_common(10)
```

실제 실습 결과 상위 10개 단어는 다음과 같았다.

| 순위 | 단어 | 등장 횟수 |
|---|---|---|
| 1 | 니트 | 142 |
| 2 | 넥 | 49 |
| 3 | 오버 | 38 |
| 4 | 크루 | 36 |
| 5 | 블랙 | 29 |
| 6 | 집업 | 27 |
| 7 | 카라 | 23 |
| 8 | 라운드 | 21 |
| 9 | 하프 | 19 |
| 10 | 배송 | 18 |

"니트" 카테고리를 크롤링했으니 "니트"가 1위인 것은 당연하지만, "크루넥", "오버핏", "카라" 같은 세부 스타일 단어가 상위권에 있다는 사실은 최근 트렌드를 짐작하게 해준다. "배송"처럼 상품 스타일과 무관한 단어가 섞여 있는 것도 실제 크롤링 데이터의 특징이다.

## 시각화: 막대그래프와 워드클라우드

빈도 상위 20개 단어를 x축(단어)과 y축(빈도)으로 나누어 막대그래프를 그린다.

```python
x, y = [], []
for (word, count) in result.most_common(20):
    x.append(word)
    y.append(count)

import matplotlib.pyplot as plt
plt.rc('font', family='NanumBarunGothic')   # 한글 폰트 설정
plt.bar(x, y)
plt.xticks(rotation=60)
plt.show()
```

코랩 환경에는 한글 폰트가 기본으로 없기 때문에, 아래 코드로 나눔 폰트를 설치한 뒤 그래프를 그려야 글자가 깨지지 않는다.


## 가격 분포 확인하기: 상자그림

가격 데이터가 정리되었으니 상자그림(boxplot)으로 최소·최대·중간값의 분포를 확인한다.

```python
fig, ax = plt.subplots()
ax.boxplot([df["price_origin"].to_list()])
plt.show()
```

상자그림은 중앙값, 사분위 범위, 이상치를 한 번에 보여주기 때문에 "이 카테고리의 가격대가 대략 어디에 몰려 있는가"를 파악하는 데 막대그래프보다 유리하다.

## 이 결과를 어디에 쓸 수 있을까

여기서 뽑은 상위 단어는 그 자체로 끝나지 않는다. "크루넥", "오버핏"처럼 자주 등장하는 조합을 검색 광고 키워드 후보로 쓸 수도 있고, 최근 데이터와 과거 데이터의 워드카운트를 비교해 새롭게 떠오르는 단어만 걸러낼 수도 있다. 이 활용은 뒤에서 다룰 "검색엔진과 SEO" 장에서 이어서 다룬다.

## 이 장의 핵심

- pandas의 `read_excel`, 컬럼 선택, `rename`, `concat`으로 여러 크롤링 결과를 하나의 표로 합칠 수 있다.
- 한국어 상품명은 형태소 분석기(Okt)의 `nouns()`로 명사만 추출해야 정확한 단어 단위 분석이 가능하다.
