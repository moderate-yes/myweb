## Key Terms

- **Prompt engineering**: The practice of designing better prompts to draw out better answers from a model, based on the premise that the same model can produce different-quality answers depending on how the question is framed.
- **Few-shot prompting**: A method that improves response quality by including examples of the desired answer directly in the prompt.
- **Chain of Thought**: A prompting approach that guides a model through intermediate reasoning steps sequentially, rather than demanding a complex inference all at once.

## Why Prompt Engineering Emerged

In its 2020 GPT-3 research, OpenAI showed that response performance can change based purely on how a question is asked — without any additional training of the model. The same is true in human conversation: someone who says specifically "my eyesight is poor, I need glasses" gets a different response than someone who only vaguely complains of discomfort. Language models behave the same way — how clearly and how richly the desired question pattern is presented changes the quality of the response. OpenAI's officially shared principle can be summarized as follows.

> Good prompt performance = clear structure + step-by-step instruction + examples provided

## A Tour of Prompting Techniques

**One/few-shot prompting** includes examples of the desired answer directly within the prompt. One example is called one-shot; several examples, few-shot. Simply showing examples can produce a noticeably higher-quality response.

**Chain of Thought** guides a model through intermediate reasoning steps sequentially for tasks that require complex inference. Asking a model to "think step by step before answering" instead of "just give me the answer" often reduces errors.

As prompting techniques grow more sophisticated and multiple techniques get combined, prompts themselves tend to become quite long. Because of this, practitioners widely turn repeated portions — role setup, output format, and so on — into fixed templates, swapping out only the part of the question that changes each time. Features like Custom GPTs, which turn a fixed prompt into a program multiple users can run within the same framework, extend this same idea.

## How Does a Computer Draw a Picture?

The easiest way to understand the logic behind image generation is to imagine drawing the digit "1" on a tiny 3×3 pixel canvas.

1. Shading positions 2, 5, and 8 (the middle vertical column) out of the 3×3 grid produces the digit "1." If this layout is recorded as a numeric array like `[[0,1,0],[0,1,0],[0,1,0]]`, a computer can recall this array at any time and redraw the exact same "1." This is **reconstructing a stored image**.
2. Now imagine collecting many different "1"s written by different people. Some write only the middle column, some tilt it slightly, some add a small serif at the top. Converting all of these into numeric arrays lets you count how often each position (cell) gets shaded — the **frequency**.
3. Graphing frequency by position shows the middle vertical column with high frequency and other positions with low frequency. When asked to "draw a 1," an AI preferentially fills in the positions with higher frequency (probability).
4. Taking this one step further: if you slightly alter the learned probability distribution and then draw using that new distribution, you get a new image that isn't identical to the original but still "looks like a 1."

In summary, three steps — **① collect real data → ② train a probability model on that data → ③ apply a slightly modified version of the model** — are enough to build an AI that produces images that are "plausible but new." AI face generation and fashion image generation that we see today can be understood as performing this exact same logic, just at a vastly larger scale and in a far more complex pixel space.

## Working With Image Generative AI

Image prompting often demands more sophisticated skill than text prompting. Because it's genuinely difficult to describe the composition, texture, or lighting you want purely in words, providing a **reference image** alongside the prompt is a common approach. The emergence of Google's image generation models (recent models known informally by codenames like "Nano Banana") has greatly expanded what's possible with image generative AI, but carefully refining the prompt still matters for getting good results.

## Applications in Fashion Marketing

Image generative AI is already used practically for producing AI-generated lookbooks reflecting a brand's identity and for beauty/fashion product detail pages. Academic research in this space continues as well, with the following studies frequently cited.

- **Fashion Synthesis (Be Your Own Prada)**: Research on synthesizing clothing images while preserving structural consistency.
- **TailorGAN**: Research on generating fashion designs conditioned on user-specified attributes.
- **pix2pix / Text-to-Image**: Technology that converts sketches or text descriptions into images (popularized by tools like DALL-E).
- **Style Transfer / Attribute Transfer (CycleGAN)**: Technology that applies the style or attributes of one image onto another.

Domestic fashion AI companies apply these technologies across several distinct practical areas: selecting input images for product trend analysis, generating final images, automatically classifying product attributes based on images, and image-search-based recommendation. Within the apparel production process (trend research → design → sample production → product production), image generative AI is increasingly used especially at the trend research and design stages.

## Chapter Summary

- Prompt engineering began with the discovery that response quality can change based purely on how a question is asked, without retraining the model.
- Techniques like one/few-shot and chain of thought can improve response quality, and in practice, repeated portions get turned into reusable templates.
- The logic of generative image AI can be summarized in three steps: collect data → train a probability model → generate a new image by modifying the model.
- Image prompting requires more sophisticated skill than text prompting, so reference images are often used alongside the prompt.
- Generative AI is used widely, from AI lookbooks and detail page production to academic research such as Fashion Synthesis and TailorGAN.
