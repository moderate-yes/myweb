## Key Terms

- **Morphological analysis**: An NLP technique that splits a sentence into its smallest meaningful units (morphemes) and identifies their part of speech.
- **Stopword**: A word or symbol removed because it's judged to carry little meaning for the analysis at hand.
- **Tokenization**: The process of cutting a sentence or paragraph into the smallest unit used for analysis — here, individual words.

## Extracting Nouns With Morphological Analysis

A product name like "Washable Half-Zip Collar Neck Haggi Knit" is a sentence made up of several words strung together. To count by word, that sentence has to be split first — but Korean attaches particles and endings directly to words, so splitting on whitespace alone isn't accurate. This is where a **morphological analyzer** comes in. This practicum uses the `Okt` analyzer from `konlpy`.

```python
!pip install konlpy
from konlpy.tag import Okt

okt = Okt()
df["name_noun"] = df["product_name"].apply(lambda x: okt.nouns(str(x)))
```

The `nouns()` function pulls out only the nouns in a sentence and returns them as a list. For example, "Washable Half-Zip Collar Neck Haggi Knit (GREEN EARTH...)" becomes `['워셔블', '하프', '집업', '카라', '넥', '하찌', '니트']` — washable, half, zip, collar, neck, haggi, knit. This process is exactly what **tokenization** means.

## Cleaning the Price Data

The price column is text like "49,000 won\n39,800 won," with the pre- and post-discount price joined by a line break. Cut off everything after "won," strip the commas, and the result is usable as a number.

```python
df["price_origin"] = df["price"].apply(lambda x: str(x).split("원")[0])
df["price_origin"] = df["price_origin"].apply(lambda x: x.replace(",", ""))
df["price_origin"] = df["price_origin"].apply(int)
```

Each of these three lines does one job: keep only what's before "won," strip the thousands-place comma, and convert the string to an integer. Most preprocessing code you'll run into in practice is exactly this — a chain of short string-handling steps like these.

## Word Count: Finding the Most Common Words

Gather the nouns extracted from all 180 product names into a single list, then count how often each appears using Python's built-in `Counter`.

```python
big_list = []
for name in df["name_noun"]:
    for word in name:
        big_list.append(word)

from collections import Counter
result = Counter(big_list)
result.most_common(10)
```

## Visualization: Bar Chart and Word Cloud

Split the top 20 words by frequency into an x-axis (word) and a y-axis (count), and draw a bar chart.

```python
x, y = [], []
for (word, count) in result.most_common(20):
    x.append(word)
    y.append(count)

import matplotlib.pyplot as plt
plt.rc('font', family='NanumBarunGothic')   # Korean font setting
plt.bar(x, y)
plt.xticks(rotation=60)
plt.show()
```

## Checking the Price Distribution: Boxplot

With the price data cleaned, a boxplot shows the distribution of minimum, maximum, and median values.

```python
fig, ax = plt.subplots()
ax.boxplot([df["price_origin"].to_list()])
plt.show()
```

A boxplot shows the median, interquartile range, and outliers all at once, which makes it better than a bar chart for answering "roughly where does this category's pricing cluster?"

## What Can This Result Be Used For

Frequently occurring combinations like "crew neck" or "oversized fit" can become candidate keywords for search ads, and comparing word counts between recent and older data can filter out only the words that are newly trending.
