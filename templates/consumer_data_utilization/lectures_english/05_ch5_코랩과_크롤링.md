## Key Terms

- **Colab**: A cloud-based Python development environment from Google that runs code directly in the browser with no installation required.
- **Cell**: The unit in Colab where Python code is entered and run.
- **Crawling**: Automatically collecting data by making use of a web page's structure.

## Why Colab

Colab is a cloud-based Python environment provided by Google. Setting up Python normally involves several steps — creating a virtual environment, installing Python, installing Jupyter Notebook, then finally running it — but Colab removes that setup almost entirely: sign in with a Google account and you can run code immediately. On top of that, packages commonly used in data analysis — TensorFlow, Keras, matplotlib, scikit-learn, pandas — come pre-installed, GPU access is free, and sharing code is as simple as sharing a link. These are the reasons Colab suits beginners encountering Python for the first time so well.

## Getting Started With Colab

1. While signed into a Google account, go to `colab.research.google.com`, or search "Google Colab" in Chrome and open it that way.
2. Create a new notebook.
3. The empty input box next to the arrow icon is a **cell**. Type Python code into a cell and press run to see the result immediately.
4. Press `Ctrl+S` to save, and the notebook file will appear in the "Colab Notebooks" folder of your Google Drive.

To use data from your own computer inside Colab, first upload the file to Google Drive, then connect the drive with the code below.

```python
from google.colab import drive
drive.mount('/content/drive/')
```

Once connected, you can confirm the uploaded file linked correctly by checking the folder icon on the left and navigating `content > drive > MyDrive`. For work that needs a GPU — training an AI model on image or text data, for example — you can turn one on in the runtime settings.

## Introducing the Crawling Tool Listly

Listly is a Chrome browser extension — a crawling tool that collects data by making use of a web page's structure, with no code required. Go to `listly.io`, click "Add to Chrome," and a Listly icon appears in the top right of the browser.

## Crawling a Ranking Page With Listly

1. Open the page you want to crawl (for example, ranks 1–180 on a store's ranking page).
2. Click the Listly icon in the top right and select "LISTLY entire page."
3. Scroll through the extracted tab to check the crawl's progress, then click the "Excel" button to download the file.
4. If the listing spans multiple pages (page 2, for example), switch pages and repeat the same steps to download a second Excel file.

Each resulting Excel file organizes what's visible on the page — product name, price, discount rate, image link — into columns. This file becomes the raw material for the text-mining practicum in the next chapter.

## Bringing Collected Data Into Colab

Once the Excel file from Listly is uploaded to Google Drive, the `drive.mount()` code from earlier lets you load it directly into a Colab notebook.

```python
import pandas
df_1 = pandas.read_excel('/content/drive/MyDrive/musinsa_1.xlsx')
df_1.head()
```

The `head()` function shows only the first five rows of a dataset — a quick way to check its structure without opening the whole thing, and one of the most frequently used functions in practice. `tail()` does the same for the last rows.

## Case Study: Why Python, of All Things

Looking at crawling alone, a no-code tool like Listly might seem like enough. And purpose-built GUI tools do exist for each job — a web scraper for data collection, NodeXL for social network analysis, RapidMiner for machine learning, TEXTOM or UCINET for text analysis, Google Data Studio for dashboards. But the total time it takes to learn all these tools one by one is reportedly about the same as the time it takes to learn Python alone.

Python is recommended for three reasons. First, it carries a single language all the way from online data collection (Scrapy, BeautifulSoup, Selenium) through image and text processing to analysis packages like numpy, scipy, scikit-learn, TensorFlow, and PyTorch. Second, it handles large volumes of data — the kind Excel struggles with — relatively quickly. Third, it extends into connecting to a database with SQLAlchemy or building an actual service with a framework like Django or Flask, all in the same language. The Flask practicum chapters in this site's "Data Literacy" subject show exactly this last leg of the journey — going from analysis to a working service.
