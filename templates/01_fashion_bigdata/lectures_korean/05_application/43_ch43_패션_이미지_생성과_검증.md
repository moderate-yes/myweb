# Fashion Image Generation and Verification

## 학습 목표

패션 이미지 생성은 좋은 문장을 한 번 입력하는 일이 아니라, 제품 사실과 창작 범위를 고정하고 여러 후보를 통제된 조건에서 비교하는 실험이다.

이 장을 마치면 다음을 할 수 있다.

- 확산모델의 노이즈 추가 학습과 반복적 노이즈 제거 생성을 구분한다.
- 프롬프트·참조이미지·마스크·seed·모델 버전이 출력에 미치는 역할을 설명한다.
- 대표적인 이미지 변환·패션 생성 연구가 해결한 과업과 한계를 구분한다.
- 생성 이미지를 제품 충실도·시각 품질·권리·소비자 오인 관점에서 평가한다.

> **학습 우선순위**
> 모든 학습자의 핵심은 diffusion 수식을 유도하거나 과거 모델 이름을 외우는 것이 아니라, 실제 상품 사실과 생성 후보를 대조하고 출처·권리·표시·승인·재작업 비용을 관리하는 것이다. 생성 원리의 수식과 연구 연대기는 모델 개발·논문 읽기가 필요한 학습자를 위한 선택 심화다.


## 개념부터 시작하기

생성 결과를 (y=G(p,r,m,s,	heta))로 생각할 수 있다. (p)는 텍스트, (r)은 참조 이미지, (m)은 마스크, (s)는 seed, (	heta)는 모델·생성 설정이다. 프롬프트 효과를 비교하려면 나머지 변수를 가능한 한 고정한다.

기존 촬영 이미지나 짧은 프롬프트를 기준선으로 둔다. 제품 충실도·금지 오류·브랜드 적합성·권리·출처 이력을 분리해 평가하고, 평균 점수보다 치명적 실패 한 건을 우선 차단한다.

- 실제 판매 상품에는 없는 소매나 단추가 생겼다면 그 이미지를 광고에 써도 될까?

## 1. 분석 파트의 프롬프트 명세를 이미지 제작에 적용한다

프롬프트의 구조화·few-shot·통제 비교·평가 원칙은 [Prompt Analysis and Evaluation](templates/01_fashion_bigdata/lectures_korean/03_analysis/15_supplement_프롬프트_분석과_평가.md)에서 배웠다. 이 장에서는 그 원칙을 반복 설명하지 않고, 제품 사실·창작 허용 범위·참조 이미지·생성 설정을 패션 이미지 제작에 적용한다.

## 2. 선택 심화: 확산모델은 어떻게 후보를 만드는가

이미지는 픽셀 값의 배열로 표현할 수 있다. 그러나 현대 이미지 확산모델을 ‘각 위치에서 자주 나온 색을 골라 칠한다’고 설명하면 공간 구조와 반복적 노이즈 제거 학습을 놓치게 된다.

확산모델의 핵심은 두 방향을 구분하는 것이다.

### 학습: 깨끗한 이미지에 노이즈를 더한다

단순화하면 시점 \(t\)의 noisy image \(x_t\)는 깨끗한 이미지 \(x_0\)와 무작위 노이즈 \(\epsilon\)의 조합으로 표현할 수 있다.

\[
x_t=\sqrt{\bar{\alpha}_t}x_0+\sqrt{1-\bar{\alpha}_t}\epsilon
\]

모델은 여러 노이즈 단계에서 어떤 노이즈가 더해졌는지 또는 더 깨끗한 표현이 무엇인지 예측하도록 학습한다. 실제 구현과 목적함수는 모델마다 다르지만, 중요한 직관은 **노이즈가 낀 전체 이미지 구조에서 되돌리는 법을 배운다**는 점이다.

### 생성: 무작위 노이즈에서 반복적으로 제거한다

새 이미지를 만들 때는 학습된 분포를 ‘살짝 변형’하는 것이 아니라, 무작위 노이즈에서 시작해 모델이 여러 단계를 거쳐 노이즈를 줄인다. 텍스트 ‘네이비 린넨 원피스’와 참조이미지 같은 조건은 각 단계의 생성 방향에 영향을 준다.

DDPM은 이 반복적 확률 과정을 현대 이미지 생성의 핵심 틀로 정리했다. Latent Diffusion은 고해상도 픽셀 공간 전체가 아니라 압축된 **latent space**에서 확산 과정을 수행해 계산 효율을 높이고 텍스트 같은 조건을 결합했다.

> **한계**
> ‘노이즈를 제거한다’는 말이 사진 속 실제 원피스를 복원한다는 뜻은 아니다. 모델은 조건과 학습된 패턴에 맞는 후보를 생성하므로, 실제 제품에 없는 구조를 그럴듯하게 만들어낼 수 있다.

## 3. 결과는 프롬프트 외의 통제 변수에도 달려 있다

텍스트 프롬프트뿐 아니라 참조 이미지, 마스크, 포즈처럼 생성 방향을 제어하는 정보를 모델에 주는 것을 **conditioning(조건 부여)**이라고 한다. 아래의 통제 변수는 조건 부여의 수단이거나 그 결과에 영향을 주는 설정이다.

<div class="purpose-flow" aria-label="Image generation controls">
  <section><b>Inputs</b><p>Text · Reference · Mask · Pose</p></section><i>→</i>
  <section><b>Generation Settings</b><p>Model · Version · Seed · Steps</p></section><i>→</i>
  <section><b>Candidate Set</b><p>Compare · Reject · Revise · Document</p></section>
</div>

| 통제 변수 | 하는 일 | 기록해야 하는 이유 |
|---|---|---|
| 텍스트 프롬프트 | 장면·상품·제약을 언어로 조건화 | 요구사항 변경 이력 확인 |
| 참조이미지 | 색·구조·스타일·정체성의 시각적 조건 제공 | 참조 권리와 실제 상품 대조 |
| 마스크 | 편집할 영역과 보존할 영역 구분 | 상품 영역이 의도치 않게 바뀌었는지 확인 |
| 포즈·배치 조건 | 인체 자세와 공간 구성을 유도 | 구도 차이를 줄여 비교 |
| seed | 시작 노이즈를 정함 | 같은 설정의 재현과 한 변수 비교 |
| 모델·버전 | 학습 데이터와 생성 능력에 큰 영향 | 업데이트 전후 결과가 달라질 수 있음 |
| sampler·steps 등 | 반복 노이즈 제거 경로·횟수에 영향 | 품질·속도·재현 조건 기록 |

같은 seed라도 모델 버전, 구현, 하드웨어·연산 방식이 달라지면 완전히 동일한 결과가 보장되지 않을 수 있다. 반대로 seed를 고정하지 않고 프롬프트 A와 B를 한 장씩만 비교하면 프롬프트 차이와 무작위 변동이 섞인다.

## 4. 참고: 패션 생성 연구가 정의한 서로 다른 과업

‘패션 AI’라는 이름 아래 이미지 변환, 속성 편집, 사람 재착장, 텍스트 생성이 섞여 있다. 논문의 입력과 출력부터 구분해야 한다.

| 연구 | 입력·과업 | 핵심 | 강의 포인트 | 한계 |
|---|---|---|---|---|
| pix2pix, 2017 | 짝지어진 입력→출력 이미지 변환 | 조건부 GAN과 paired data | 스케치→사진 등 지도 변환 | 정확히 짝지어진 학습쌍 필요 |
| CycleGAN, 2017 | 짝 없는 두 이미지 영역 변환 | cycle consistency | 속성·도메인 변환의 출발점 | 원하는 부분만 바뀐다는 보장 없음 |
| Be Your Own Prada, 2017 | 사람 이미지+의복 디자인 코딩→재착장 이미지 | 사람·의복 표현을 조건으로 합성 | 패션 전용 조건부 생성 | 자유로운 모든 의복·포즈를 해결한 것은 아님 |
| TailorGAN, 2020 | 기준 의복 이미지+목표 속성→편집 의복 | collar·sleeve 등 속성 제어 | 사용자 지정 디자인 편집 | 학습 속성·데이터 범위 밖 일반화 한계 |
| DDPM, 2020 | 노이즈→이미지 | 반복적 확률 노이즈 제거 | 현대 확산 생성의 기본 원리 | 반복 생성의 계산비용 |
| Latent Diffusion, 2022 | latent noise+텍스트 등→고해상도 이미지 | 압축된 잠재공간의 조건부 확산 | 효율적인 text-to-image 기반 | 학습 데이터·조건·평가의 편향과 오류 |

이 발전표는 ‘이전 연구가 틀리고 최신 연구가 모든 문제를 해결했다’는 순위가 아니다. paired data 없이 변환하기, 속성을 더 세밀하게 제어하기, 계산 효율을 높이기처럼 **문제 정의가 달라진 과정**이다.

## 5. 패션 이미지 평가를 사용 목적까지 확장하기

상세페이지 후보가 매우 사실적으로 보여도 실제 상품과 다르면 나쁜 결과다. 반대로 연구 벤치마크 점수가 좋아도 브랜드의 실제 제품·고객·채널에서 유용하다는 보장은 없다.

| 영역 | 질문 | 실패 예 | 검증 |
|---|---|---|---|
| 제품 충실도 | 실제 소재·색·봉제·핏·옵션과 일치하는가? | 없는 주머니·단추 생성 | 승인 원본과 항목별 대조 |
| 인체·의복 구조 | 손·관절·주름·가림이 물리적으로 가능한가? | 소매와 손이 합쳐짐 | 확대 검수·실물 착장 비교 |
| 장면 품질 | 구도·조명·해상도가 채널 목적에 맞는가? | 그림자 방향 불일치 | 채널별 품질 기준표 |
| 텍스트·로고 | 글자·상표·라벨이 정확하고 허용되었는가? | 가짜 로고·깨진 글자 | 별도 원본 합성·법무 검토 |
| 대표성 | 체형·피부톤·성별 표현이 편향되지 않았는가? | 특정 체형에서만 자연스러움 | 다양한 승인 테스트셋 |
| 권리 | 참조·모델·소재를 사용할 권리가 있는가? | 무단 인물·작품 참조 | 라이선스·동의·계약 기록 |
| 소비자 오인 | 실제 판매 상품과 장면을 과장하지 않는가? | 방수 아닌 상품을 폭우 장면에서 무결점 표현 | 광고 주장과 실물 검증·고지 |
| 출처 이력 | 생성·편집 과정과 승인본을 추적할 수 있는가? | 어떤 모델로 만든 최종본인지 모름 | 파일·프롬프트·설정·승인 로그 |

C2PA 같은 콘텐츠 자격증명은 생성·편집 이력의 신호를 전달할 수 있다. 하지만 프로비넌스가 있다고 이미지 내용이 참이거나 저작권이 자동으로 해결되는 것은 아니다.

```python
candidates = {
    "seed_101": {"product_fidelity": 5, "visual_quality": 4, "safety": 5},
    "seed_202": {"product_fidelity": 2, "visual_quality": 5, "safety": 5},
    "seed_303": {"product_fidelity": 4, "visual_quality": 4, "safety": 4},
}

for seed, scores in candidates.items():
    average = sum(scores.values()) / len(scores)
    eligible = scores["product_fidelity"] >= 4 and scores["safety"] >= 4
    print(f"{seed}: average={average:.2f}, eligible={eligible}")
```

```output
seed_101: average=4.67, eligible=True
seed_202: average=4.00, eligible=False
seed_303: average=4.00, eligible=True
```

- 확산모델은 위치별 빈도에서 픽셀을 독립적으로 뽑는 것이 아니라, 노이즈가 더해진 표현에서 반복적인 노이즈 제거를 학습한다.

## 핵심 용어

- **conditioning(조건 부여)**: 텍스트, 참조이미지, 마스크, 포즈 같은 정보를 사용해 생성 방향을 제어하는 것.
- **확산모델(diffusion model)**: 학습 시 데이터에 노이즈가 더해지는 과정을 이용해 노이즈 제거를 배우고, 생성 시 노이즈에서 시작해 반복적으로 이미지를 복원하는 생성모델 계열.
- **seed**: 의사난수의 시작값. 같은 구현·모델·설정을 고정했을 때 결과 재현과 비교에 도움을 준다.
- **프로비넌스(provenance)**: 콘텐츠가 어디에서 어떤 도구와 편집 과정을 거쳐 왔는지에 관한 출처·이력 정보.
