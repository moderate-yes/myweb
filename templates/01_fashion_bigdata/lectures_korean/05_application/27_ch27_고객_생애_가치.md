# Customer Lifetime Value

## 학습 목표

고객 생애 가치는 고객의 고정된 가격표가 아니라 관찰 기간과 가정에 따른 미래 공헌이익의 추정치다. 매출이 아니라 마진, 유지율, 할인율과 획득비용을 분리해 계산한다.

이 장을 마치면 다음을 할 수 있다.

- CLV의 단순 공식과 마진·유지율을 반영한 공식을 구분하고 각 항의 데이터 출처를 말한다.
- 주문 기록에서 고객별 AOV·구매 빈도·마진율을 계산한다.
- 월별 재구매율로 유지율을 추정하고 기대 유지 기간으로 바꾼다.
- 획득 채널별 CLV와 CAC를 비교해 마케팅 예산 배분의 근거를 만든다.
- 앞 기간의 CLV 추정치를 뒤 기간의 실제 매출로 검증하고 시스템에 연결한다.


## 개념부터 시작하기

기간 \(t\)의 기대 공헌이익을 \(m_t\), 유지 확률을 \(s_t\), 할인율을 \(d\)라 하면 \(CLV=\sum_t m_ts_t/(1+d)^t\)로 표현할 수 있다. 데이터가 적을 때는 평균 주문액×구매 빈도×기대 유지기간의 단순식을 기준선으로 쓴다.

앞 기간으로 CLV를 계산하고 뒤 기간의 실제 공헌이익과 비교한다. 채널별 CLV:CAC는 평균만 보지 말고 분포와 회수 기간을 함께 보며, 신규 고객의 짧은 관찰 기간이 낮은 가치로 오해되지 않도록 코호트별로 평가한다.

## 문제 설정: 획득 비용보다 가치가 큰 고객인가

광고비 100만 원으로 고객 40명을 얻었다면 CAC는 2만 5천 원이다. 이 고객들이 평균 1만 원짜리 상품을 한 번 사고 떠난다면 손해이고, 반년마다 8만 원씩 2년을 산다면 이익이다. CLV는 이 판단을 숫자로 만든다. 라플라스 같은 도구는 매출 데이터를 연동해 이 값을 계산해 주지만, 공식의 각 항이 어디서 오는지 알아야 결과를 믿을 수 있다.

## 1. 데이터를 표로 표현하기

| 데이터 | 파일 | 역할 | 데이터 특징 |
|---|---|---|---|
| 주문 기록 | `orders.csv` | AOV·빈도·매출 | 비율 척도, 날짜 속성, 상태(취소·반품) |
| 상품 마스터 | `products.csv` | 원가(`cost_price`)로 마진 계산 | 비율 척도 |
| 고객 마스터 | `customers.csv` | 가입일·획득 채널 | 명목 속성, 날짜 속성 |
| CAC 가정 | 코드 안 | 채널별 획득 비용 | 회계 자료에서 가져와야 하는 값 |

<div class="concept-box">
  <b>개념 상자: CLV의 세 가지 공식</b>
  <p><strong>단순 공식</strong>: CLV = 평균 주문액(AOV) × 연간 구매 빈도 × 평균 유지 기간(년). 이해하기 쉽지만 매출 기준이라 마진이 낮은 고객을 과대평가한다.</p>
  <p><strong>마진·유지율 공식</strong>: CLV = 기간당 마진 × 유지율 ÷ (1 − 유지율) (할인율을 넣으면 분모가 1 + 할인율 − 유지율). 연 유지율이 0.6이면 기대 유지 기간은 1 ÷ (1 − 0.6) = 2.5년, 월 유지율이 0.74이면 3.8개월이다. 매 기간 같은 확률로 이탈한다는 가정이 들어 있고, 마진과 유지율의 기간 단위(월·년)를 맞춰야 한다.</p>
  <p><strong>확률 모델</strong>: BG/NBD·Gamma-Gamma처럼 고객마다 구매 빈도와 이탈 확률을 확률 분포로 추정한다. `lifetimes` 라이브러리가 구현하며, 비계약형(구독이 아닌) 쇼핑몰에 맞다. 이 장은 앞 두 공식을 다루고 확률 모델은 7절에서 가리킨다.</p>
  <p><strong>CAC</strong>(고객 획득 비용) = 총 마케팅·영업 비용 ÷ 신규 고객 수. CLV : CAC가 3 : 1을 넘으면 건전하다는 경험칙이 널리 쓰이지만 업종·마진에 따라 다르다.</p>
</div>

## 4. Python으로 확인하기

### 1단계: 데이터 확인과 순매출 규칙

```python
import numpy as np
import pandas as pd

pd.set_option("display.width", 120)
pd.set_option("display.max_columns", 14)
DATA = "templates/01_fashion_bigdata/data/fashion_mall"
orders = pd.read_csv(f"{DATA}/orders.csv", parse_dates=["order_time"])
products = pd.read_csv(f"{DATA}/products.csv")
customers = pd.read_csv(f"{DATA}/customers.csv", parse_dates=["signup_date"])

lines = (orders[orders["status"] == "completed"]
         .merge(products[["product_id", "cost_price"]], on="product_id"))
lines["revenue"] = lines["quantity"] * lines["unit_price"]
lines["margin"] = lines["quantity"] * (lines["unit_price"] - lines["cost_price"])
lines["month"] = lines["order_time"].dt.to_period("M")
print("결제 완료 줄 수:", len(lines), "/ 매출 합계:", f"{lines['revenue'].sum():,.0f}원",
      "/ 평균 마진율:", round(lines["margin"].sum() / lines["revenue"].sum(), 3))
```

```output
결제 완료 줄 수: 11334 / 매출 합계: 1,436,586,410원 / 평균 마진율: 0.536
```

반품·취소를 제외한 이유와 원가의 출처(상품 마스터의 `cost_price`)를 기록한다. 실제 회사에서는 배송비·결제 수수료·쿠폰도 마진에서 빼야 한다.

### 2단계: 고객별 AOV·빈도·마진

```python
per_order = lines.groupby(["customer_id", "order_id"]).agg(revenue=("revenue", "sum"), margin=("margin", "sum"),
                                                          order_time=("order_time", "min")).reset_index()
cust = per_order.groupby("customer_id").agg(
    orders=("order_id", "nunique"), revenue=("revenue", "sum"), margin=("margin", "sum"),
    first=("order_time", "min"), last=("order_time", "max"))
cust["aov"] = cust["revenue"] / cust["orders"]
cust["margin_rate"] = cust["margin"] / cust["revenue"]
cust["active_months"] = ((cust["last"] - cust["first"]).dt.days / 30.4).clip(lower=1)     # 최소 1개월
cust["orders_per_month"] = cust["orders"] / 6                # 관찰 기간 6개월 → 월 환산
print(cust[["orders", "revenue", "aov", "margin_rate", "active_months", "orders_per_month"]].describe().round(2))
```

### 3단계: 월별 재구매율로 유지율 추정

유지율은 "이번 달에 산 고객 가운데 다음 달에도 산 비율"의 평균으로 잡는다. 31장 7절의 코호트 분석을 한 숫자로 압축한 것이다.

```python
monthly_buyers = lines.groupby("month")["customer_id"].apply(set)
months = list(monthly_buyers.index)
rates = []
for m1, m2 in zip(months[:-1], months[1:]):
    a, b = monthly_buyers[m1], monthly_buyers[m2]
    rates.append({"from": str(m1), "to": str(m2), "buyers": len(a), "retained": len(a & b), "rate": round(len(a & b) / len(a), 3)})
retention = pd.DataFrame(rates)
print(retention.to_string(index=False))
r_month = retention["rate"].mean()
expected_months = 1 / (1 - r_month)
print(f"월 유지율 평균 {r_month:.3f} → 기대 유지 기간 {expected_months:.1f}개월 (연 유지율로 환산하면 {r_month ** 12:.3f})")
```

```output

```

월 유지율이 0.74이면 기대 유지 기간은 1 ÷ (1 − 0.74) ≈ 3.8개월이다. 매달 같은 확률로 남는다는 가정이 들어 있으며, 실제로는 오래 남은 고객일수록 더 잘 남는다(생존 편향). 그래서 이 값은 보수적인 추정이고, 확률 모델(7절)에서 이 가정을 완화한다. 유지율의 기간 단위(월)와 아래 마진의 기간 단위를 반드시 맞춘다. 월 유지율을 12제곱해 연 유지율로 바꾸면 0.03 정도로 작아져 연간 마진과 곱할 때 CLV가 지나치게 작아진다.

### 4단계: CLV 계산

```python
cust["clv_simple"] = cust["aov"] * cust["orders_per_month"] * expected_months            # 매출 기준
monthly_margin = cust["margin"] / 6
cust["clv_margin"] = monthly_margin * r_month / (1 - r_month)                          # 마진 기준, 앞으로 남을 기간
print(cust[["aov", "orders_per_month", "clv_simple", "clv_margin"]].describe().round(0))
print("상위 20% 고객의 CLV 합 비중:",
      round(cust["clv_margin"].sort_values(ascending=False).head(int(len(cust) * 0.2)).sum() / cust["clv_margin"].sum(), 3))
```

두 CLV의 크기가 다르다. 단순 공식은 매출 기준이고, 마진 공식은 마진(매출의 절반 남짓) 기준이므로 당연히 작다. 어느 쪽을 쓰든 **같은 정의를 계속 쓰는 것**이 비교의 조건이다. 상위 20% 고객이 CLV의 대부분을 차지하는 집중은 Pareto 원칙의 예다.

### 5단계: 획득 채널별 CLV와 CAC

```python
CAC = {"paid_search": 25_000, "sns": 15_000, "referral": 5_000, "organic": 2_000}   # 채널별 획득 비용 가정(원)
by_channel = (cust.merge(customers[["customer_id", "acquisition_channel"]], on="customer_id")
              .groupby("acquisition_channel").agg(customers=("clv_margin", "size"),
                                                 clv_margin_median=("clv_margin", "median"),
                                                 clv_margin_mean=("clv_margin", "mean")))
by_channel["cac"] = by_channel.index.map(CAC)
by_channel["clv_to_cac"] = (by_channel["clv_margin_mean"] / by_channel["cac"]).round(1)
print(by_channel.round(0))
```

### 6단계: 검증 — 앞 기간의 CLV가 뒤 기간의 매출을 설명하는가

```python
first_half = lines[lines["month"] <= "2026-03"]
second_half = lines[lines["month"] >= "2026-04"]

est = first_half.groupby("customer_id").agg(orders=("order_id", "nunique"), margin=("margin", "sum"))
est["monthly_margin"] = est["margin"] / 3
est["clv_est"] = est["monthly_margin"] * r_month / (1 - r_month)
actual = second_half.groupby("customer_id")["revenue"].sum().rename("actual_next_3m")
check = est.join(actual, how="left").fillna({"actual_next_3m": 0})

print("Spearman 상관:", round(check["clv_est"].corr(check["actual_next_3m"], method="spearman"), 3))
check["decile"] = pd.qcut(check["clv_est"].rank(method="first"), 5, labels=["Q1 low", "Q2", "Q3", "Q4", "Q5 high"])
calib = check.groupby("decile", observed=True)["actual_next_3m"].agg(["mean", "median", "size"]).round(0)
print(calib)
```

## 5. 결과를 평가하는 법

- **순위 정확도**: 앞 기간 추정치와 뒤 기간 실제값의 순위 상관, 분위별 실제값의 단조 증가.
- **보정(calibration)**: 추정 CLV 합계가 실제 매출 합계와 크게 다르면 유지율·빈도 가정을 조정한다.
- **정의의 일관성**: 매출 기준인지 마진 기준인지, 관찰 기간과 환산 방법이 무엇인지 보고서에 고정한다.
- **Goodhart의 법칙**: CLV를 목표 지표로 삼으면 단기 매출을 부풀리는 행동(과도한 쿠폰)이 CLV를 왜곡한다([41장](templates/01_fashion_bigdata/lectures_korean/05_application/41_ch41_콘텐츠와_성과지표.md)).

## 7. 다른 데이터로 확장하기

19장의 **Online Retail II**는 고객 ID와 2년치 거래가 있어 확률 모델(BG/NBD, Gamma-Gamma)까지 적용할 수 있고, **Olist**는 획득 채널은 없지만 주(state)별 CLV 비교가 가능하다. `lifetimes` 라이브러리 문서의 CDNOW 데이터셋은 CLV 확률 모델의 고전 예제다.

ggf = GammaGammaFitter(penalizer_coef=0.01).fit(summary.query("frequency > 0")["frequency"], summary.query("frequency > 0")["monetary_value"])

1. `CAC`의 값을 회사 상황에 맞게 바꾸고(예: paid_search 40,000원) CLV : CAC 표가 어떻게 달라지는지 본다.
2. 3단계의 유지율을 월 유지율 평균 대신 최근 2개월 평균으로 바꾸어 기대 유지 기간과 CLV가 얼마나 민감한지 확인한다.
3. 21장의 세그먼트 표와 이 장의 CLV 표를 결합해 세그먼트별 CLV 중앙값을 구하고, VIP 정의를 바꿔야 하는지 판단한다.

<div class="lesson-section-box lesson-summary-box"><strong>이 장의 핵심</strong></div>

- CLV는 AOV × 빈도 × 유지 기간(단순) 또는 연간 마진 × 유지율 ÷ (1 − 유지율)(마진)로 계산하며, 정의를 고정하고 계속 같은 정의를 써야 한다.
- 유지율은 월별 재구매율에서 추정하고, 기대 유지 기간은 1 ÷ (1 − 유지율)이다. 매달 같은 확률로 남는다는 가정이 들어 있으며 마진과 기간 단위를 맞춘다.
- 획득 채널별 CLV : CAC가 예산 배분의 근거이며, CAC는 회계 자료에서 가져온다.
- 추정치는 앞 기간으로 계산해 뒤 기간의 실제 매출과 순위·분위로 검증하고, 절대 금액보다 순위와 비율로 쓴다.

## 핵심 용어

- **고객 생애 가치(CLV)**: 한 고객이 관계를 유지하는 동안 만들 총 가치의 추정치. 예: 월 마진 5만 원, 월 유지율 0.74이면 약 14만 원.
- **평균 주문액(AOV)**: 매출 ÷ 주문 수. 예: 96만 원 ÷ 12회 = 8만 원.
- **유지율(retention rate)**: 한 기간의 구매 고객 가운데 다음 기간에도 구매한 비율.
- **기대 유지 기간(expected lifetime)**: 1 ÷ (1 − 유지율). 예: 월 유지율 0.74이면 3.8개월.
- **고객 획득 비용(CAC)**: 마케팅·영업 비용 ÷ 신규 고객 수. 예: 100만 원 ÷ 40명 = 2만 5천 원.
- **CLV : CAC**: 획득 비용 대비 생애 가치의 비율. 3 : 1 이상을 건전한 기준으로 보는 경험칙이 있다.
