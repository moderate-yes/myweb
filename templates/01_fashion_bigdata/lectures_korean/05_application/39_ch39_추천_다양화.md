# Recommendation Diversification

## 학습 목표

추천 다양화는 정확도를 포기하고 무작위 상품을 섞는 일이 아니다. 관련성을 유지하면서 목록 전체가 더 넓은 상품·카테고리·신상품을 보여주도록 재정렬하는 문제다.

이 장을 마치면 다음을 할 수 있다.

- 추천 목록의 커버리지·목록 내 다양성·신선도·적중률을 정의하고 계산한다.
- 인기순·협업 필터링·카테고리 선호 세 방식이 지표마다 어떻게 다른지 비교한다.
- 슬롯 규칙과 MMR 재정렬로 여러 방식을 결합해 다양성과 적중률의 균형을 맞춘다.
- 홈 화면의 추천 모듈 구성(목적·방식·데이터)을 표로 설계하고 실험으로 검증한다.
- 필터 버블과 인기 편향을 설명하고 이를 완화하는 운영 규칙을 만든다.


## 개념부터 시작하기

후보 상품의 관련성 점수를 \(rel(i)\), 이미 선택된 목록과의 최대 유사도를 \(sim(i,S)\)라 하면 MMR은 \(\lambda rel(i)-(1-\lambda)sim(i,S)\)가 큰 상품을 차례로 선택한다. \(\lambda\)는 정확성과 다양성의 균형을 나타낸다.

인기순과 단일 추천 모델을 기준선으로 둔다. Recall@K뿐 아니라 catalog coverage, 목록 내 다양성, 신선도와 품절률을 함께 보고, 오프라인 지표의 개선은 실제 홈 화면 실험에서 장기 만족과 재방문으로 확인한다.

## 문제 설정: 적중률이 전부가 아니다

협업 필터링만 쓰면 "이미 산 것과 비슷한 것"만 계속 보이고, 인기순만 쓰면 모두에게 같은 상품이 보인다. 두 경우 모두 고객은 새 것을 발견하지 못하고 쇼핑몰은 카탈로그의 일부만 판다. 추천의 목표에는 적중률 외에 **발견**(고객이 몰랐던 상품)과 **카탈로그 활용**(롱테일 판매)이 있고, 강의가 말한 체류 시간도 여기서 나온다. 여러 방식을 나란히 두는 것은 이 목표들을 한 화면에서 함께 좇는 방법이다.

<div class="concept-box">
  <b>개념 상자: 다양성·신선도·의외성과 필터 버블</b>
  <p><strong>목록 내 다양성</strong>(intra-list diversity)은 한 추천 목록 안의 상품들이 서로 얼마나 다른가이다. 여기서는 "서로 다른 카테고리인 상품 쌍의 비율"로 잰다. <strong>신선도</strong>(novelty)는 고객이 이미 알 법한 인기 상품이 아닌 정도이며, 상품 인기도의 역수로 근사한다. <strong>의외성</strong>(serendipity)은 예상 밖이면서 마음에 드는 추천으로, 실험 없이는 재기 어렵다. 한 방식만 계속 쓰면 고객이 보는 세계가 좁아지는 <strong>필터 버블</strong>과, 인기 상품이 더 추천되어 더 인기해지는 <strong>인기 편향</strong>이 생긴다. <strong>MMR</strong>(maximal marginal relevance)은 다음에 넣을 상품을 고를 때 "관련성 − λ × 이미 넣은 상품과의 유사도"를 최대화해 목록을 재정렬하는 방법이다.</p>
</div>

## 4. Python으로 확인하기

### 1단계: 데이터 확인과 세 방식의 추천 목록

24장의 협업 필터링과 카테고리별 행동 가중치로 계산한 선호 점수를 간단히 다시 만든다.

```python
import numpy as np
import pandas as pd
from sklearn.metrics.pairwise import cosine_similarity

pd.set_option("display.width", 120)
DATA = "templates/01_fashion_bigdata/data/fashion_mall"
orders = pd.read_csv(f"{DATA}/orders.csv", parse_dates=["order_time"])
events = pd.read_csv(f"{DATA}/events.csv", parse_dates=["event_time"])
products = pd.read_csv(f"{DATA}/products.csv", parse_dates=["launch_date"]).set_index("product_id")

completed = orders[orders["status"] == "completed"]
train = completed[completed["order_time"] < "2026-06-01"]
test = completed[completed["order_time"] >= "2026-06-01"]
matrix = (train.groupby(["customer_id", "product_id"]).size().unstack(fill_value=0) > 0).astype(int)
matrix = matrix.reindex(columns=products.index, fill_value=0)
popular = train["product_id"].value_counts().reindex(products.index, fill_value=0)
sim = cosine_similarity(matrix.T); np.fill_diagonal(sim, 0)
item_sim = pd.DataFrame(sim, index=products.index, columns=products.index)

views = events[(events["event_time"] < "2026-06-01") & events["customer_id"].notna() & (events["event_type"] == "view_item")]
cat_pref = (pd.concat([views[["customer_id", "product_id"]], train[["customer_id", "product_id"]]])
            .assign(category=lambda d: d["product_id"].map(products["category"]))
            .pivot_table(index="customer_id", columns="category", values="product_id", aggfunc="count", fill_value=0))
cat_pref = cat_pref.div(cat_pref.sum(axis=1), axis=0)
print("학습 고객", len(matrix), "/ 상품", len(products), "/ 카테고리별 상품 수:", products["category"].value_counts().to_dict())
```

```output
학습 고객 547 / 상품 80 / 카테고리별 상품 수: {'top': 22, 'bottom': 20, 'outer': 18, 'dress': 12, 'bag': 8}
```

```python
K = 10

def rec_popular(cid):
    seen = matrix.loc[cid]
    return popular[seen == 0].sort_values(ascending=False).head(K).index.tolist()

def rec_cf(cid):
    seen = matrix.loc[cid]
    score = item_sim.loc[seen[seen == 1].index].sum(axis=0)
    return score[seen == 0].sort_values(ascending=False).head(K).index.tolist()

def rec_category(cid):
    seen = matrix.loc[cid]
    pref = cat_pref.loc[cid] if cid in cat_pref.index else cat_pref.mean()
    score = products["category"].map(pref).fillna(0) * (1 + popular / popular.max() * 0.2)
    return score[seen == 0].sort_values(ascending=False).head(K).index.tolist()

customers_eval = [c for c in matrix.index if c in set(test["customer_id"])]
lists = {"popular": {c: rec_popular(c) for c in customers_eval},
         "item_cf": {c: rec_cf(c) for c in customers_eval},
         "category": {c: rec_category(c) for c in customers_eval}}
print("평가 고객 수:", len(customers_eval))
print("고객 C0006의 세 목록:", {k: v["C0006"][:5] for k, v in lists.items()})
```

### 2단계: 네 가지 지표

```python
test_items = test.groupby("customer_id")["product_id"].apply(set)
pop_share = popular / popular.sum()
cat = products["category"]

def metrics(recs):
    hits, div, nov, cov = [], [], [], set()
    for c, items in recs.items():
        new_items = test_items[c] - set(matrix.columns[matrix.loc[c] == 1])
        if new_items:
            hits.append(bool(new_items & set(items)))
        pairs = [(a, b) for i, a in enumerate(items) for b in items[i + 1:]]
        div.append(np.mean([cat[a] != cat[b] for a, b in pairs]))
        nov.append(np.mean([-np.log2(pop_share[i] + 1e-9) for i in items]))
        cov.update(items)
    return {"hit_rate@10": round(np.mean(hits), 3), "intra_list_diversity": round(np.mean(div), 3),
            "novelty": round(np.mean(nov), 2), "coverage": round(len(cov) / len(products), 2)}

table = pd.DataFrame({name: metrics(recs) for name, recs in lists.items()}).T
print(table)
```

세 방식은 서로 다른 축에서 이긴다. 인기순은 커버리지와 신선도가 낮고, 협업 필터링은 적중률이 높지만 비슷한 것끼리 묶여 다양성이 낮을 수 있으며, 카테고리 선호는 한 카테고리에 몰려 다양성이 가장 낮다. 어느 하나가 정답이 아니라는 것이 다양화의 출발점이다.

### 3단계: 슬롯 결합

홈 화면의 열 칸을 방식별로 나눈다. 4칸은 협업 필터링, 3칸은 인기순, 3칸은 아직 사지 않은 카테고리의 탐색 상품이다.

```python
def rec_slots(cid, n_cf=4, n_pop=3, n_explore=3):
    seen_cats = set(cat[matrix.columns[matrix.loc[cid] == 1]])
    picked = []
    for item in rec_cf(cid):
        if len(picked) < n_cf and item not in picked:
            picked.append(item)
    for item in rec_popular(cid):
        if len([p for p in picked]) < n_cf + n_pop and item not in picked:
            picked.append(item)
    explore = popular[(~cat.isin(seen_cats)) & (matrix.loc[cid] == 0)].sort_values(ascending=False)
    for item in explore.index:
        if len(picked) < n_cf + n_pop + n_explore and item not in picked:
            picked.append(item)
    for item in rec_popular(cid):                      # 탐색 후보가 부족하면 인기순으로 채운다
        if len(picked) < K and item not in picked:
            picked.append(item)
    return picked

lists["slots"] = {c: rec_slots(c) for c in customers_eval}
print(pd.DataFrame({name: metrics(recs) for name, recs in lists.items()}).T)
```

### 4단계: MMR 재정렬

협업 필터링 후보 20개를 관련성과 다양성의 균형으로 다시 정렬한다. 유사도는 카테고리가 같으면 1, 다르면 0으로 단순화한다.

```python
def rec_mmr(cid, lam=0.6, pool=20):
    seen = matrix.loc[cid]
    score = item_sim.loc[seen[seen == 1].index].sum(axis=0)
    cand = score[seen == 0].sort_values(ascending=False).head(pool)
    if cand.max() > 0:
        cand = cand / cand.max()
    picked = []
    while len(picked) < K and len(cand):
        best, best_val = None, -1e9
        for item, rel in cand.items():
            redundancy = max([1.0 if cat[item] == cat[p] else 0.0 for p in picked], default=0.0)
            val = lam * rel - (1 - lam) * redundancy
            if val > best_val:
                best, best_val = item, val
        picked.append(best)
        cand = cand.drop(best)
    return picked

for lam in [1.0, 0.8, 0.6, 0.4]:
    lists[f"mmr_{lam}"] = {c: rec_mmr(c, lam) for c in customers_eval}
print(pd.DataFrame({name: metrics(recs) for name, recs in lists.items() if name.startswith("mmr")}).T)
```

## 5. 결과를 평가하는 법

- **지표 균형**: Hit rate·커버리지·다양성·신선도를 한 표에 놓고 모듈별 목표에 맞는 균형을 고른다. 한 지표만 최적화하지 않는다.

- **인기 편향**: 인기순 모듈이 판매를 더 집중시키면 탐색 슬롯 비중을 늘린다.

```python
# skip-run: H&M에서 상품 그룹 기준 목록 내 다양성 계산
articles = pd.read_csv("articles.csv", usecols=["article_id", "product_group_name"]).set_index("article_id")
def diversity(items):
    groups = articles.loc[items, "product_group_name"].tolist()
    pairs = [(a, b) for i, a in enumerate(groups) for b in groups[i + 1:]]
    return np.mean([a != b for a, b in pairs])
# 추천 목록(article_id 리스트)마다 diversity()를 적용해 방식별 평균을 비교한다
```

## 핵심 용어

- **목록 내 다양성(intra-list diversity)**: 한 추천 목록 안에서 서로 다른 상품 쌍의 비율.
- **신선도(novelty)**: 추천 상품이 이미 알려진 인기 상품이 아닌 정도.
- **커버리지(coverage)**: 추천에 한 번이라도 등장한 상품의 비율.
- **슬롯 규칙(slot rule)**: 화면의 칸을 방식별로 배분하는 규칙. 예: CF 4, 인기 3, 탐색 3.
- **MMR(maximal marginal relevance)**: 관련성에서 기존 목록과의 유사도를 뺀 값으로 재정렬하는 방법.
- **필터 버블(filter bubble)**: 한 방식의 추천만 반복되어 고객이 보는 범위가 좁아지는 현상.
