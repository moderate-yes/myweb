# Market Data Analysis

## 학습 목표

시장 데이터 분석은 외부 관심도와 자사 판매를 같은 척도로 맞춘 뒤 두 움직임의 차이를 찾는 작업이다. 상대 지수, 절대 규모, 경쟁 강도와 자사 침투율을 섞지 않는다.

이 장을 마치면 다음을 할 수 있다.

- 시장 데이터(검색량·상품 수·경쟁도)의 출처와 성격(상대 지수, 표본, 지연)을 설명한다.
- 시장 키워드를 자사 상품·카테고리에 매핑하는 표를 만들고 매핑의 한계를 기록한다.
- 키워드 모멘텀(최근 4주 대비 이전 4주 성장률)을 계산하고 자사 판매 추세와 비교해 갭을 찾는다.
- 시장 규모·성장·경쟁 강도·자사 침투율을 구분해 읽는다.
- 주간 시장 리포트와 카테고리·상품기획 의사결정으로 이어지는 시스템을 그린다.
- 시장 기회 점수의 구성 요소와 한계를 설명한다.


## 개념부터 시작하기

키워드 (k)의 최근 평균을 (a_k), 이전 평균을 (b_k)라 하면 모멘텀은 (m_k=a_k/b_k-1)로 정의할 수 있다. 시장 지수와 자사 판매 지수를 각각 0~100으로 정규화한 뒤 차이를 보면 시장은 커지지만 자사가 따라가지 못하는 영역을 찾을 수 있다.

단순 기준선은 최근 검색지수 순위다. 기회 점수에는 성장률뿐 아니라 검색 규모·경쟁도·마진·반품 위험을 포함하고, 상대 지수의 100을 절대 수요로 해석하지 않는다. 최종 판단은 소량 발주나 제한 캠페인으로 검증한다.

## 문제 설정: 시장은 커지는데 우리 카테고리가 없다

네이버 쇼핑에서 "아동 패딩"을 검색하면 경쟁사 상품은 꾸준히 노출되는데 우리 브랜드는 그 카테고리 자체가 없어 노출이 0건이라고 하자. 이것은 단순한 검색 순위 문제가 아니라 시장 수요와 자사 상품 구성 사이의 갭이다. 검색 규모와 성장률, 경쟁 상품 수, 예상 마진을 함께 보면 카테고리를 추가할지, 기존 상품의 명칭과 노출을 바꿀지, 아직 기다릴지를 구분할 수 있다.

## 2. 모형과 계산 원리

| 단계 | 분석 방법 | 이 과정의 장 |
|---|---|---|
| 키워드 모멘텀 | 특성화(시간 변화, 성장률) | 10장 4절 |
| 시장 vs 자사 갭 | 차별화(두 지수의 비교) | 10장 |
| 시장 기회 점수 | 성장·검색 규모·경쟁도·자사 갭의 가중합 | 8장 가설, 15장 평가 |
| 카테고리 확장 후보 | 특성화(수요는 있으나 공급이 없는 키워드) | 8장 가설 |
| 평가 | 다음 달 판매 증가와의 관계, 소량 테스트 성과 | 15장 |

시장 모멘텀은 최근 4주 평균을 이전 4주 평균으로 나눈 값에서 1을 뺀 성장률로 정의한다.

\[
\text{momentum}_k = \frac{\bar{v}_{k,\ \text{최근 4주}}}{\bar{v}_{k,\ \text{이전 4주}}} - 1
\]

### 2단계: 키워드를 자사 상품에 매핑

키워드와 상품을 잇는 규칙은 사람이 정한다. 여기서는 키워드의 단어가 상품의 소재·핏·하위 카테고리·색상 속성과 일치하면 매핑한다. 매핑되지 않는 키워드는 그 자체로 정보다(카탈로그에 없는 수요).

```python
ATTR_WORDS = {
    "린넨": ("material", "린넨"), "와이드": ("fit", "와이드"), "오버핏": ("fit", "오버핏"), "크롭": ("fit", "크롭"),
    "슬림": ("fit", "슬림핏"), "팬츠": ("subcategory", "팬츠"), "셔츠": ("subcategory", "셔츠"),
    "니트": ("subcategory", "니트"), "코트": ("subcategory", "코트"), "원피스": ("subcategory", "원피스"),
    "스커트": ("subcategory", "스커트"), "가디건": ("subcategory", "가디건"), "토트백": ("subcategory", "토트백"),
    "패딩": ("subcategory", "패딩"), "데님": ("material", "데님"),
}

def match_products(keyword):
    conds = [ATTR_WORDS[w] for w in keyword.split() if w in ATTR_WORDS]
    if not conds:
        return []
    mask = np.ones(len(products), dtype=bool)
    for col, val in conds:
        mask &= products[col] == val
    return products.loc[mask, "product_id"].tolist()

mapping = pd.DataFrame({"keyword": market["keyword"].unique()})
mapping["products"] = mapping["keyword"].apply(match_products)
mapping["n_products"] = mapping["products"].str.len()
print(mapping[["keyword", "n_products"]].to_string(index=False))
```

weekly = market.pivot_table(index="week_start", columns="keyword", values="search_volume")
recent4 = weekly.iloc[-4:].mean()
prior4 = weekly.iloc[-8:-4].mean()
momentum = (recent4 / prior4 - 1).rename("momentum").sort_values(ascending=False)
latest = market[market["week_start"] == market["week_start"].max()].set_index("keyword")
trend = pd.DataFrame({"momentum": momentum.round(2), "latest_volume": latest.loc[momentum.index, "search_volume"],

### 4단계: 시장 모멘텀과 자사 판매 추세의 갭

```python
completed = orders[orders["status"] == "completed"].copy()
completed["week_start"] = completed["order_time"].dt.to_period("W-SUN").dt.start_time
sales_weekly = completed.groupby(["week_start", "product_id"])["quantity"].sum().unstack(fill_value=0)

def own_momentum(product_ids):
    if not product_ids:
        return np.nan
    s = sales_weekly[product_ids].sum(axis=1)
    return s.iloc[-4:].mean() / max(s.iloc[-8:-4].mean(), 0.5) - 1

gap = mapping.merge(trend, left_on="keyword", right_index=True)
gap["own_momentum"] = gap["products"].apply(own_momentum).round(2)
gap["gap"] = (gap["momentum"] - gap["own_momentum"]).round(2)
print(gap[["keyword", "n_products", "momentum", "own_momentum", "gap", "competition"]]
      .sort_values("gap", ascending=False).to_string(index=False))
```

`gap`이 크게 양수이면 시장 관심은 오르는데 우리 판매는 따라가지 못하는 키워드다. 노출·재고·가격 문제인지 상품이 없는 문제인지 나누어 본다. `n_products`가 0이면 후자이고, 카테고리 확장 회의의 안건이 된다.

### 5단계: 시장 기회 점수 만들기

성장률 하나만으로 우선순위를 정하면 작은 키워드의 급등을 과대평가할 수 있다. 검색 규모, 성장률, 경쟁도와 자사 대응 갭을 0~1 범위로 표준화한 뒤 가중합으로 회의용 순위를 만든다.

```python
from sklearn.preprocessing import MinMaxScaler

features = gap[["momentum", "latest_volume", "competition", "gap"]].copy()
features["competition"] = -features["competition"]  # 낮은 경쟁도를 높은 기회로 변환
scaled = MinMaxScaler().fit_transform(features.fillna(0))
gap[["growth_s", "volume_s", "competition_s", "gap_s"]] = scaled

gap["opportunity_score"] = (
    gap["growth_s"] * 0.35
    + gap["volume_s"] * 0.25
    + gap["competition_s"] * 0.15
    + gap["gap_s"] * 0.25
)

print(gap.sort_values("opportunity_score", ascending=False)[
    ["keyword", "opportunity_score", "momentum", "latest_volume", "competition", "n_products"]
].head(10).to_string(index=False))
```

가중치는 객관적 진리가 아니라 현재 전략을 숫자로 표현한 규칙이다. MD가 성장 우선인지, 큰 시장 우선인지 합의하고 가중치를 바꿨을 때 순위가 얼마나 달라지는지 민감도 분석을 한다. 상위 후보는 곧바로 대량 발주하지 않고 공급 가능성·마진·브랜드 적합성·반품 위험을 검토한 뒤 소량 테스트로 확인한다.

### 6단계: 카테고리 확장 후보

```python
expansion = gap[(gap["n_products"] == 0) & (gap["momentum"] > 0)].sort_values("momentum", ascending=False)
print(expansion[["keyword", "momentum", "latest_volume", "competition"]].to_string(index=False))
```

이 표가 곧 "우리 카테고리가 검색 순위에 없다"는 강의 사례의 데이터 판이다. 검색량이 충분하고 경쟁도가 낮은 키워드부터 소량 테스트 생산이나 위탁 입점으로 검증한다([44장](templates/01_fashion_bigdata/lectures_korean/05_application/44_ch44_자동화와_의사결정.md)의 상품 기획 결정).

## 5. 결과를 평가하는 법

- **선행성**: 모멘텀이 다음 달 판매 증가를 앞서는지 본다. 관계가 없다면 시장 신호를 예측 변수로 과장하지 않고 탐색용 지표로만 쓴다.
- **순위 안정성**: 가중치와 관찰 기간을 조금 바꿔도 상위 후보가 유지되는지 본다. 작은 변경에 순위가 뒤집히면 단일 점수보다 원지표를 함께 제시한다.
- **매핑 품질**: 키워드 → 상품 매핑을 MD가 검토한다. 잘못된 매핑은 잘못된 모멘텀을 상품에 붙인다.
- **의사결정 성과**: 카테고리 확장 후보의 테스트 결과(판매·마진)를 기록해 다음 분기의 기준으로 삼는다.

## 핵심 용어

- **시장 데이터(market data)**: 검색량·상품 수·경쟁도·SNS 언급량처럼 자사 밖에서 관측한 수요 지표. 예: 아이템스카우트 월간 검색량.
- **상대 지수(relative index)**: 기간 내 최댓값을 100으로 둔 비율 값. 예: 구글 트렌드.
- **모멘텀(momentum)**: 최근 구간 평균을 이전 구간 평균으로 나눈 성장률. 예: 최근 4주 ÷ 이전 4주 − 1.
- **갭(gap)**: 시장 모멘텀과 자사 판매 모멘텀의 차이. 예: 시장 +30%, 자사 0%면 갭 0.3.
- **키워드-상품 매핑(keyword–product mapping)**: 시장 키워드를 자사 상품·카테고리에 잇는 규칙 표.
- **카테고리 확장 후보(category expansion candidate)**: 수요는 있으나 자사 상품이 없는 키워드.
