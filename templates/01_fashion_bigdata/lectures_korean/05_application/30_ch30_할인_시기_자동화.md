# Automated Discount Timing

## 학습 목표

할인 결정은 판매가 낮다는 이유만으로 가격을 내리는 규칙이 아니다. 재고 위험, 구매 망설임, 경쟁 상황과 마진을 함께 보고 할인하지 않았을 때의 결과와 비교해야 한다.

이 장을 마치면 다음을 할 수 있다.

- 판매 속도 둔화, 장바구니 이탈, 경쟁사 세일 겹침의 세 신호를 상품 × 주 표로 계산한다.
- 과거 할인 전후의 판매량·마진 변화를 비교하고, 그 비교가 인과 추정으로서 갖는 한계를 설명한다.
- 후보 점수와 규칙(최대 할인율·마진 하한·기간)으로 할인 후보 목록을 만든다.
- 할인 효과를 대조 상품과 비교해 평가하고 마진 총액으로 판단한다.
- 후보 생성 → 사람 승인 → 플랫폼 API 적용 → 효과 회수의 시스템을 그린다.


## 개념부터 시작하기

상품 (i)의 할인 후보 점수를 판매 속도 둔화, 장바구니 이탈, 재고 일수, 경쟁 할인으로 구성할 수 있다. 그러나 점수는 우선순위일 뿐 최적 할인율이나 인과효과가 아니다.

기준선은 재고 일수 하나로 만든 수동 규칙이다. 과거 할인 전후 비교에는 계절과 상품 수명주기가 섞이므로 유사 상품 대조군이나 실험을 사용한다. 평가는 매출보다 할인 후 공헌이익·재고 소진·정가 구매 잠식·반품률로 한다.

## 문제 설정: 담기는 하는데 팔리지 않는 상품

어떤 상품은 조회와 장바구니 담기가 많은데 결제가 적다. 가격이 망설임의 원인이라면 짧은 타임세일이 전환을 만든다. 반대로 시즌이 끝나가는데 재고가 남은 상품은 판매 속도가 떨어진 시점에 마크다운(가격 인하)을 시작해야 처분 비용을 줄인다. 경쟁사가 같은 카테고리에서 세일을 시작하면 우리 판매가 빠지기도 한다. 세 신호는 모두 데이터에 있지만 서로 다른 표에 있다. 할인 결정의 절반은 이 표들을 한 줄로 합치는 일이다.

  <b>개념 상자: 마크다운, 타임세일, 가드레일</b>
  <p><strong>마크다운(markdown)</strong>은 시즌이 끝나가는 재고를 처분하기 위해 가격을 단계적으로 내리는 것이고, <strong>타임세일</strong>은 짧은 기간 특정 상품의 전환을 만들기 위한 일시 할인이다. 목적이 다르므로 신호도 다르다. 마크다운은 판매 속도(sell-through)와 남은 시즌 길이를, 타임세일은 장바구니 이탈과 경쟁 상황을 본다.</p>
  <p>어느 쪽이든 자동화에는 <strong>가드레일</strong>이 필요하다. 최대 할인율, 판매가가 원가에 일정 마진을 더한 값 아래로 내려가지 않는 하한, 한 상품의 연속 할인 기간 상한, 그리고 사람의 승인. 가격은 되돌리기 어려운 조치(고객 신뢰, 브랜드 가치)라서 20장의 진열 위치 변경보다 훨씬 보수적으로 자동화한다.</p>

## 2. 모형과 계산 원리

| 단계 | 분석 방법 | 이 과정의 장 |
|---|---|---|
| 판매 속도·장바구니 이탈 | 특성화(상품 × 주 집계, 비율) | 10장 |
| 판매 둔화 감지 | 이동 기준선(최근 4주 vs 이전 4주) | 14장 5절, 20장 |
| 할인 전후 비교 | 차별화(전후 비교) + 대조 상품 | 10장, 15장 9절 |
| 후보 점수 | 규칙 기반 결합 | 12장 13절의 기대손익 |
| 평가 | 마진 총액, 대조군 대비 증가분 | 15장 |

할인 전후 비교는 인과가 아니다. 할인은 보통 판매가 둔화된 상품에 적용되므로, 할인 뒤 판매가 늘어도 일부는 평균으로의 회귀(14장 12절)와 계절 때문일 수 있다. 같은 시기에 할인하지 않은 비슷한 상품(대조 상품)과 비교해야 한다.

### 2단계: 상품 × 주 표 만들기

```python
completed = orders[orders["status"] == "completed"].copy()
completed["week"] = completed["order_time"].dt.to_period("W-SUN").dt.start_time
weekly = completed.groupby(["product_id", "week"]).agg(units=("quantity", "sum"),
                                                       discount=("discount_rate", "mean")).reset_index()

ev = events[events["event_type"].isin(["add_to_cart", "purchase"]) & events["product_id"].notna()].copy()
ev["week"] = ev["event_time"].dt.to_period("W-SUN").dt.start_time
carts = ev.pivot_table(index=["product_id", "week"], columns="event_type", values="event_id", aggfunc="count", fill_value=0).reset_index()

grid = pd.MultiIndex.from_product([products.index, sorted(weekly["week"].unique())], names=["product_id", "week"]).to_frame(index=False)
table = (grid.merge(weekly, how="left").merge(carts, how="left")
         .fillna({"units": 0, "discount": 0, "add_to_cart": 0, "purchase": 0}))
table = table[table["week"] + pd.Timedelta(days=6) <= completed["order_time"].max().normalize()]   # 7일이 안 되는 마지막 주 제외
table["category"] = table["product_id"].map(products["category"])
table["margin_per_unit"] = table["product_id"].map(products["list_price"]) * (1 - table["discount"]) - table["product_id"].map(products["cost_price"])

def competitor_sale(row):
    p = promos[(promos["category"] == row["category"]) & (promos["start_date"] <= row["week"] + pd.Timedelta(days=6)) & (promos["end_date"] >= row["week"])]
    return len(p) > 0
table["competitor_sale"] = table.apply(competitor_sale, axis=1)
print(table.shape)
print(table[table["product_id"] == "P017"].tail(5).to_string(index=False))
```

```python
SNAP_WEEK = table["week"].max()
recent = table[table["week"] > SNAP_WEEK - pd.Timedelta(weeks=4)]
prior = table[(table["week"] <= SNAP_WEEK - pd.Timedelta(weeks=4)) & (table["week"] > SNAP_WEEK - pd.Timedelta(weeks=8))]

signals = pd.DataFrame({
    "units_recent4": recent.groupby("product_id")["units"].sum(),
    "units_prior4": prior.groupby("product_id")["units"].sum(),
    "carts_recent4": recent.groupby("product_id")["add_to_cart"].sum(),
    "buys_recent4": recent.groupby("product_id")["purchase"].sum(),
```

### 4단계: 과거 할인의 효과 추정

이미 할인을 시작한 상품에서 할인 전 4주와 후 4주의 주간 판매량·마진을 비교하고, 같은 카테고리에서 할인하지 않은 상품을 대조로 둔다.

```python
rows = []
for pid, start in markdown_start.items():
    start_week = pd.Timestamp(start).to_period("W-SUN").start_time
    t = table[table["product_id"] == pid]
    before = t[(t["week"] < start_week) & (t["week"] >= start_week - pd.Timedelta(weeks=4))]
    after = t[(t["week"] >= start_week) & (t["week"] < start_week + pd.Timedelta(weeks=4))]
    if len(before) < 4 or len(after) < 4:
        continue
    cat = products.loc[pid, "category"]
    control_ids = [q for q in products.index if products.loc[q, "category"] == cat and q not in markdown_start.index]
    ctrl = table[table["product_id"].isin(control_ids)]
    c_before = ctrl[(ctrl["week"] < start_week) & (ctrl["week"] >= start_week - pd.Timedelta(weeks=4))]["units"].sum() / len(control_ids)
    c_after = ctrl[(ctrl["week"] >= start_week) & (ctrl["week"] < start_week + pd.Timedelta(weeks=4))]["units"].sum() / len(control_ids)
    rows.append({"product_id": pid, "units_before": before["units"].sum(), "units_after": after["units"].sum(),
                 "margin_before": (before["units"] * before["margin_per_unit"]).sum(),
                 "margin_after": (after["units"] * after["margin_per_unit"]).sum(),
                 "control_change": round(c_after / max(c_before, 1) - 1, 2)})
effect = pd.DataFrame(rows).set_index("product_id")
effect["units_change"] = (effect["units_after"] / effect["units_before"].clip(lower=1) - 1).round(2)
effect["lift_vs_control"] = (effect["units_change"] - effect["control_change"]).round(2)
effect["margin_change"] = (effect["margin_after"] / effect["margin_before"].clip(lower=1) - 1).round(2)
print(effect[["units_before", "units_after", "units_change", "control_change", "lift_vs_control", "margin_change"]].describe().round(2))
print("판매량은 늘었지만 마진 총액은 줄어든 상품 수:", int(((effect["units_change"] > 0) & (effect["margin_change"] < 0)).sum()), "/", len(effect))
```

### 5단계: 후보 점수와 규칙

```python
cand = signals[signals["current_discount"] == 0].copy()          # 아직 할인하지 않은 상품만
cand["score"] = (
    (-cand["velocity_change"]).clip(lower=0) * 1.0           # 판매 둔화
    + cand["cart_abandon_rate"] * 1.0                        # 장바구니 이탈
    + (cand["competitor_weeks"] / 4) * 0.5                   # 경쟁사 세일 겹침
    + (cand["days_since_launch"] > 240) * 0.5                # 시즌 경과
).round(2)
cand["type"] = np.where(cand["cart_abandon_rate"] >= 0.6, "타임세일 후보", np.where(cand["days_since_launch"] > 240, "마크다운 후보", "관찰"))
cand = cand.join(products[["product_name", "category", "list_price", "cost_price"]])
cand["max_discount"] = ((1 - cand["cost_price"] * 1.3 / cand["list_price"]).clip(0, 0.4)).round(2)   # 원가+30% 마진 하한, 최대 40%
```

## 7. 다른 데이터로 확장하기

19장의 **M5 Forecasting**은 매장 × 상품 일별 판매량에 판매가(`sell_prices.csv`)와 행사 달력이 붙어 있어 4단계의 할인 전후 비교와 가격 탄력성 추정에 가장 맞다. **Olist**는 주문별 가격이 있어 상품별 가격 변동과 판매의 관계를 볼 수 있고, **Online Retail II**는 같은 상품의 단가가 시점에 따라 달라 마크다운 효과를 관찰할 수 있다.

```python
# skip-run: M5의 판매가 변화 주와 판매량 변화를 함께 보기
sales = pd.read_csv("sales_train_validation.csv")
prices_m5 = pd.read_csv("sell_prices.csv")            # store_id, item_id, wm_yr_wk, sell_price
cal = pd.read_csv("calendar.csv")                      # d, wm_yr_wk, event_name_1, ...
item = sales[sales["item_id"] == "HOBBIES_1_001"].melt(id_vars=["item_id", "store_id"], var_name="d", value_name="units")
item = item.merge(cal[["d", "wm_yr_wk"]], on="d").merge(prices_m5, on=["store_id", "item_id", "wm_yr_wk"])
weekly_m5 = item.groupby("wm_yr_wk").agg(units=("units", "sum"), price=("sell_price", "mean"))
print(weekly_m5.pct_change().corr())                   # 가격 변화율과 판매량 변화율의 관계
```

## 핵심 용어

- **마크다운(markdown)**: 시즌 종료 재고 처분을 위한 단계적 가격 인하. 예: 출시 240일 뒤 20% → 30%.
- **타임세일(flash sale)**: 전환 유도를 위한 짧은 기간 할인. 예: 장바구니 이탈률 높은 상품 7일 할인.
- **판매 속도(sales velocity)**: 일정 기간의 판매량 변화율. 예: 최근 4주 ÷ 이전 4주 − 1.
- **장바구니 이탈률(cart abandonment rate)**: 담기 가운데 구매로 이어지지 않은 비율.
- **대조 상품(control product)**: 같은 시기에 할인하지 않은 비슷한 상품. 효과 비교의 기준.
- **가드레일(guardrail)**: 최대 할인율·마진 하한·기간 상한처럼 자동화가 넘을 수 없는 규칙.
