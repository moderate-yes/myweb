# Image Similarity Recommendation

## 학습 목표

이미지 유사도 추천은 사진 전체가 비슷한지를 묻는 문제가 아니다. 비교할 의복 영역을 정하고, 이미지를 벡터로 바꾸며, 업무 목적에 맞는 ‘비슷함’의 기준을 평가해야 한다.

이 장을 마치면 다음을 할 수 있다.

- 이미지 파일 묶음을 (이미지 수, 높이, 너비, 채널) 배열로 읽고 바운딩 박스로 비교 대상을 잘라낸다.
- 카테고리·색상·스타일 가운데 어떤 기준으로 라벨링하느냐에 따라 "비슷함"의 정의가 달라짐을 설명한다.
- 픽셀 벡터, 색상 벡터, 라벨로 학습한 투영 벡터로 최근접 상품을 찾고 Recall@K로 비교한다.
- triplet loss의 원리(같은 라벨은 가깝게, 다른 라벨은 멀게)를 설명하고 실습의 투영과 어떻게 대응하는지 말한다.
- 외부 인기 상품 이미지로 자사 DB를 검색하는 바잉 활용 사례를 설계한다.
- 임베딩 배치·벡터 검색·추천 API로 이어지는 시스템을 그린다.


## 개념부터 시작하기

이미지 \(x\)를 임베딩 함수 \(f\)로 변환한 벡터를 \(v=f(x)\)라 하자. 두 상품 벡터 \(v_i,v_j\)의 코사인 유사도는 \(v_i^Tv_j/(\lVert v_i\rVert\lVert v_j\rVert)\)다. 값이 클수록 방향이 비슷하지만 고객이 원하는 대체 상품이라는 뜻까지 보장하지는 않는다.

색상 히스토그램이나 픽셀 축소 벡터를 기준선으로 두고 사전학습 임베딩과 비교한다. 카테고리·색상·핏 중 무엇을 정답으로 삼느냐에 따라 좋은 이웃이 달라지므로 Recall@K와 사람 검수를 함께 사용한다.

## 문제 설정: 지금 보는 상품과 비슷한 상품

자체 상품을 만드는 쇼핑몰은 한 시즌 상품이 100~200개라 유사 상품이 많지 않다. 이 서비스는 여러 브랜드를 파는 파페치·지그재그 같은 유통 쇼핑몰에서 자주 쓰인다. 같은 원리는 다른 곳에도 쓰인다. 강의자는 중국 도매상에게서 받은 수만 장의 완성품 사진 가운데 머천다이저가 일일이 골라 올리던 업체와 일하면서, 국내 인기 상품 이미지를 수집해 **그와 가장 비슷한 도매 상품을 찾아 추천**하는 기능을 만들었다. 유사도 추천은 쇼핑몰 안의 추천이자, 바잉과 트렌드 파악의 도구다.

실습 이미지는 카테고리별 실루엣과 색상만 다른 단순한 그림이다. 실제 상품 사진(모델 착용컷, 배경, 조명)은 훨씬 복잡해서 사전학습 CNN이나 CLIP 같은 모델이 필요하다. 7절의 벤치마크 데이터셋으로 넘어가면 같은 코드 구조에 모델만 바꾸면 된다.

<div class="concept-box">
  <b>개념 상자: 바운딩 박스(bounding box)</b>
  <p>이미지 안에서 비교 대상이 차지하는 직사각형 영역이다. 모델 착용 사진에서 "가디건과 비슷한 상품"을 찾고 싶은데 바지와 비슷한 상품이 나오는 일을 막으려면, 먼저 가디건 영역을 네모 박스로 지정해야 한다. 실무에서는 사람이 라벨링 도구로 박스를 그리거나 객체 탐지 모델(YOLO·DETR 계열)이 자동으로 찾는다. 비교 대상을 지정하지 않으면 엉뚱한 부위를 비교할 수 있어 이 단계가 거의 항상 동반된다.</p>
</div>

## 2. 모형과 계산 원리

| 단계 | 분석 방법 | 이 과정의 장 |
|---|---|---|
| 이미지 → 숫자 배열 | 데이터 표현(텐서) | 5장 |
| 라벨링 | 분류 문제의 정답 만들기 | 12장 |
| 유사도 학습 | 임베딩(거리 학습) | 13장 6절 + 아래 개념 상자 |
| 최근접 검색 | 벡터 거리(코사인·유클리드) | 5장 7절 |
| 평가 | Recall@K | 15장 |

<div class="concept-box">
  <b>개념 상자: triplet loss로 배우는 유사도</b>
  <p>강의의 비유는 이렇다. 라벨링한 카테고리별 사진을 바닥에 뿌리고, 기준 사진 하나를 정한 뒤 비슷해 보이는 사진은 가까이 모으고 다르다고 생각하는 사진은 멀리 둔다. 멀리 둔 사진 중 하나를 다시 기준으로 삼아 같은 일을 반복하면 비슷한 사진끼리 모이고, 바닥 끝에 x·y 좌표를 그리면 사진마다 위치가 생긴다. 새 사진이 오면 그 위치를 정해 놓으면 주변에 비슷한 사진이 몰려 있다.</p>
  <p>이 작업을 AI에게 시키는 방법이 <strong>triplet loss</strong>다. (기준 anchor, 같은 라벨 positive, 다른 라벨 negative) 세 장을 뽑아, anchor–positive 거리가 anchor–negative 거리보다 여유(margin)만큼 작아지도록 신경망의 벡터를 조정한다. DeepFashion(Liu et al., 2016) 논문이 대표적으로 이 방식으로 옷 검색 모델을 학습했다. 이 장의 실습은 신경망 대신 <em>라벨이 같은 것은 가깝게, 다른 것은 멀게</em> 투영하는 선형판별분석(LDA)을 같은 원리의 축소판으로 사용한다.</p>
</div>

### 2단계: 바운딩 박스로 비교 대상 잘라내기

실습 이미지는 배경이 거의 흰색이므로 배경과 다른 픽셀의 범위를 박스로 삼는다. 실제 사진에서는 이 부분을 객체 탐지 모델이나 사람의 라벨링이 담당한다.

```python
def crop_to_box(img, size=32, background=(250, 250, 248), tol=25):
    mask = np.abs(img.astype(int) - np.array(background)).sum(axis=2) > tol
    ys, xs = np.where(mask)
    box = tuple(int(v) for v in (xs.min(), ys.min(), xs.max() + 1, ys.max() + 1))   # (left, top, right, bottom)
    cropped = Image.fromarray(img).crop(box).resize((size, size), Image.BILINEAR)
    return np.asarray(cropped), box

crops, boxes = zip(*[crop_to_box(img) for img in images])
crops = np.stack(crops)
print("잘라낸 뒤 shape:", crops.shape)
print("P001 박스(left, top, right, bottom):", boxes[0], "/ P080 박스:", boxes[79])
```

```output
잘라낸 뒤 shape: (80, 32, 32, 3)
P001 박스(left, top, right, bottom): (13, 17, 83, 83) / P080 박스: (21, 15, 76, 84)
```

### 3단계: 라벨 기준 정하기

데이터셋의 정답을 무엇으로 두느냐에 따라 마케터의 의도를 유사도에 담을 수 있다. 카테고리를 정답으로 두면 외형이 비슷한 상품이, 색상을 정답으로 두면 비슷한 색의 상품이 추천된다. 스타일(스쿨룩·공주풍)처럼 의견이 갈리는 기준은 여러 사람의 의견을 모으거나 전문가에게 맡겨야 하므로 비용이 커진다. 그래서 색상·카테고리처럼 비교적 합의하기 쉬운 기준이 많이 쓰인다.

### 4단계: 세 가지 벡터로 최근접 상품 찾기

먼저 학습용(60장)과 질의용(20장)으로 나눈다. 질의 이미지는 "새로 들어온 상품"의 역할이다.

```python
from sklearn.model_selection import train_test_split
from sklearn.metrics.pairwise import cosine_similarity

idx_train, idx_query = train_test_split(np.arange(len(products)), test_size=20, random_state=7,
                                        stratify=labels["category"])
pixels = crops.reshape(len(crops), -1).astype(float) / 255          # 32*32*3 = 3072차원

def recall_at_k(emb, label, k=5):
    """질의 이미지마다 학습 이미지 중 상위 k개를 찾고, 질의와 같은 라벨의 비율을 평균한다."""
    sims = cosine_similarity(emb[idx_query], emb[idx_train])
    hits = []
    for qi, row in zip(idx_query, sims):
        top = idx_train[np.argsort(-row)[:k]]
        hits.append((label.iloc[top] == label.iloc[qi]).mean())
    return round(float(np.mean(hits)), 2)

print("픽셀 벡터  → 같은 카테고리 Recall@5:", recall_at_k(pixels, labels["category"]),
      "/ 같은 색상 Recall@5:", recall_at_k(pixels, labels["color"]))
```

```output
픽셀 벡터  → 같은 카테고리 Recall@5: 0.76 / 같은 색상 Recall@5: 0.53
```

픽셀 값을 그대로 쓴 벡터는 카테고리도 색상도 중간 정도로만 맞힌다. 픽셀 3,072개에는 실루엣 모양과 색이 함께 들어 있어서, 어느 쪽이 "비슷함"의 기준인지 정해지지 않은 채 두 정보가 섞여 거리를 만들기 때문이다.

이제 "라벨이 같은 것은 가깝게, 다른 것은 멀게" 투영하는 벡터를 학습 이미지로 만든다. 라벨을 카테고리로 줄 때와 색상으로 줄 때를 비교한다.

```python
from sklearn.decomposition import PCA
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.pipeline import make_pipeline

def learned_embedding(label_col, n_pca=20):
    model = make_pipeline(PCA(n_components=n_pca, random_state=0),
                          LinearDiscriminantAnalysis())
    model.fit(pixels[idx_train], labels[label_col].iloc[idx_train])  # 학습 이미지의 라벨만 사용
    return model.transform(pixels)                                   # 모든 이미지의 위치를 지정

emb_by_category = learned_embedding("category")
emb_by_color = learned_embedding("color")
print("벡터 차원:", emb_by_category.shape[1], "(카테고리 기준),", emb_by_color.shape[1], "(색상 기준)")

table = pd.DataFrame({
    "학습에 쓴 라벨": ["없음(픽셀)", "카테고리", "색상"],
    "같은 카테고리 Recall@5": [recall_at_k(pixels, labels["category"]),
                          recall_at_k(emb_by_category, labels["category"]),
                          recall_at_k(emb_by_color, labels["category"])],
    "같은 색상 Recall@5": [recall_at_k(pixels, labels["color"]),
                        recall_at_k(emb_by_category, labels["color"]),
                        recall_at_k(emb_by_color, labels["color"])],
})
print(table.to_string(index=False))
```

```output
벡터 차원: 4 (카테고리 기준), 7 (색상 기준)
학습에 쓴 라벨  같은 카테고리 Recall@5  같은 색상 Recall@5
  없음(픽셀)              0.76            0.53
    카테고리              0.95            0.26
      색상              0.41            1.00
```

같은 이미지, 같은 거리 계산인데 **학습에 쓴 라벨에 따라 "비슷한 상품"이 완전히 달라진다**. 카테고리로 학습하면 실루엣이 같은 상품이, 색상으로 학습하면 색이 같은 상품이 상위에 온다. 이것이 강의가 강조한 "데이터셋 구성 방법으로 마케터의 의도를 담는다"는 뜻이다.

### 5단계: 질의 상품의 이웃을 눈으로 확인하기

```python
import matplotlib.pyplot as plt

def neighbors(emb, qi, k=5):
    sims = cosine_similarity(emb[[qi]], emb[idx_train])[0]
    return idx_train[np.argsort(-sims)[:k]]

qi = idx_query[0]
print("질의 상품:", products.loc[qi, ["product_id", "category", "color", "subcategory"]].to_dict())
for name, emb in [("pixels", pixels), ("category-trained", emb_by_category), ("color-trained", emb_by_color)]:
    nb = neighbors(emb, qi)
    print(f"{name:17s}", products.loc[nb, "product_id"].tolist(),
          products.loc[nb, "category"].tolist(), products.loc[nb, "color"].tolist())

fig, axes = plt.subplots(3, 6, figsize=(9, 4.8))
for row, (name, emb) in enumerate([("Pixels", pixels), ("Trained on category", emb_by_category),
                                   ("Trained on color", emb_by_color)]):
    axes[row, 0].imshow(images[qi]); axes[row, 0].set_title("Query" if row == 0 else "", fontsize=9)
    axes[row, 0].set_ylabel(name, fontsize=8)
    for col, j in enumerate(neighbors(emb, qi), start=1):
        axes[row, col].imshow(images[j])
        axes[row, col].set_title(f"{products.loc[j, 'product_id']}", fontsize=8)
for ax in axes.ravel():
    ax.set_xticks([]); ax.set_yticks([])
fig.suptitle("Top-5 similar products by embedding type", fontsize=11)
fig.tight_layout()
fig.savefig("templates/01_fashion_bigdata/lectures_korean/images/app-ch22-neighbors.png", dpi=130)
```

### 6단계: 외부 인기 상품 이미지로 자사 DB 검색하기

바잉 사례를 흉내 낸다. 외부 쇼핑몰의 베스트 상품 사진은 우리 DB에 없는 새 이미지다. 여기서는 질의 이미지에 밝기 변화와 위치 이동을 주어 "다른 곳에서 찍힌 비슷한 상품"을 만든다.

```python
def external_photo(img, shift=6, brightness=1.12):
    moved = np.roll(img, shift=(shift, -shift), axis=(0, 1))          # 위치 이동
    moved[:shift, :, :] = 250; moved[:, -shift:, :] = 250              # 이동으로 빈 자리는 배경색
    return np.clip(moved.astype(float) * brightness, 0, 255).astype(np.uint8)

ext = external_photo(images[idx_query[1]])
ext_crop, _ = crop_to_box(ext)
ext_vec = ext_crop.reshape(1, -1).astype(float) / 255
model_cat = make_pipeline(PCA(n_components=20, random_state=0), LinearDiscriminantAnalysis())
model_cat.fit(pixels[idx_train], labels["category"].iloc[idx_train])
ext_emb = model_cat.transform(ext_vec)
db_emb = model_cat.transform(pixels)
sims = cosine_similarity(ext_emb, db_emb)[0]
top = np.argsort(-sims)[:5]
print("외부 이미지의 원본 상품:", products.loc[idx_query[1], "product_id"])
print(products.loc[top, ["product_id", "category", "color", "subcategory"]].assign(similarity=sims[top].round(3)))
```

## 5. 결과를 평가하는 법

- **Recall@K**: 질의와 같은 라벨의 상품이 상위 K에 든 비율. 라벨 기준(카테고리·색상·스타일)을 먼저 정해야 계산할 수 있다.
- **사람 검수**: 라벨이 같아도 고객이 보기에 비슷하지 않을 수 있다. 질의 20개에 대해 상위 5개를 담당 MD가 "비슷함/아님"으로 표시해 정밀도를 본다.
- **온라인 지표**: 서비스에 올린 뒤 "비슷한 상품" 영역의 클릭률·구매 기여를 [31장 A/B 테스트](templates/01_fashion_bigdata/lectures_korean/05_application/31_ch31_AB_테스트.md)로 확인한다.
- **차원의 저주**: 벡터 차원이 높고 상품이 적으면 거리가 모두 비슷해진다(13장). 투영 차원을 줄이거나 더 많은 학습 이미지를 쓴다.

## 7. 다른 데이터로 확장하기

19장의 **Fashion Product Images (Small)**는 상품 4.4만 개의 사진과 `styles.csv`(카테고리·색상·시즌·용도)를 제공해 이 장의 3~5단계를 실제 사진으로 반복하기에 가장 알맞다. **Fashion-MNIST**는 작지만 흑백이라 색상 실험은 못 한다. **DeepFashion**은 triplet 기반 검색 연구의 원 데이터이며 연구 목적 라이선스를 확인한다.

```python
# skip-run: Fashion Product Images (Small)에서 사전학습 CNN으로 임베딩 만들기 (코랩, GPU 권장)
import torch, torchvision
from torchvision import transforms
model = torchvision.models.resnet50(weights="IMAGENET1K_V2").eval()
model.fc = torch.nn.Identity()                       # 분류층을 떼고 2048차원 벡터를 얻는다
prep = transforms.Compose([transforms.Resize((224, 224)), transforms.ToTensor(),
                           transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])])
styles = pd.read_csv("fashion-product-images-small/styles.csv", on_bad_lines="skip").head(2000)
vecs = []
with torch.no_grad():
    for pid in styles["id"]:
        img = Image.open(f"fashion-product-images-small/images/{pid}.jpg").convert("RGB")
        vecs.append(model(prep(img).unsqueeze(0)).numpy()[0])
emb = np.stack(vecs)
# labels = styles[["articleType", "baseColour"]] 로 4단계의 recall_at_k를 그대로 적용한다
```

1. 4단계의 라벨을 `fit`(핏)으로 바꾸어 학습하고 Recall@5가 어떻게 나오는지 본다. 실루엣만 있는 실습 이미지에서 핏 정보가 얼마나 있는지 생각해 본다.
2. 5단계의 질의 상품을 `idx_query[5]`로 바꾸고 세 벡터의 이웃을 비교한다.
3. 여러분이 MD라면 어떤 라벨 기준(카테고리·색상·소재·스타일)으로 유사 상품을 정의하고 싶은지, 의견이 갈릴 때 누구에게 라벨을 맡길지 한 문단으로 쓴다.

<div class="lesson-section-box lesson-summary-box"><strong>이 장의 핵심</strong></div>

- 이미지는 (이미지 수, 높이, 너비, 채널)의 숫자 배열이며, 비교 대상을 바운딩 박스로 잘라낸 뒤 벡터로 바꾼다.
- 어떤 라벨로 학습하느냐가 "비슷함"의 정의를 정한다. 카테고리로 학습하면 실루엣이, 색상으로 학습하면 색이 같은 상품이 이웃이 된다.
- triplet loss는 같은 라벨은 가깝게, 다른 라벨은 멀게 벡터를 조정하는 학습 방법이며, 실습의 LDA 투영은 그 원리의 축소판이다.

## 핵심 용어

- **바운딩 박스(bounding box)**: 이미지에서 비교 대상이 차지하는 직사각형 영역. 예: 착용 사진에서 가디건 부분만 지정.
- **임베딩(embedding)**: 이미지를 비슷한 것끼리 가까워지도록 놓은 숫자 벡터. 예: 카테고리로 학습한 4차원 위치.
- **triplet loss**: anchor·positive·negative 세 장의 거리 관계로 임베딩을 학습하는 손실 함수. 예: DeepFashion 검색 모델.
- **코사인 유사도(cosine similarity)**: 두 벡터의 방향이 얼마나 비슷한지 나타내는 값(1이면 같은 방향). 예: 상위 5개 이웃 선택.
- **Recall@K**: 질의와 같은 라벨이 상위 K개 결과에 든 비율. 예: Recall@5 = 0.8.
- **벡터 인덱스(vector index)**: 대량의 벡터에서 가까운 것을 빠르게 찾는 자료구조·DB. 예: FAISS, Milvus.
