# Review Pros and Cons Classification

## 학습 목표

리뷰 분석은 문장을 긍정·부정 하나로 줄이는 대신 어떤 주제에 대한 평가인지 함께 구조화해야 한다. 한 리뷰가 사이즈에는 부정적이고 소재에는 긍정적일 수 있으므로 다중 라벨 문제로 다룬다.

이 장을 마치면 다음을 할 수 있다.

- 리뷰 텍스트를 주제(aspect) × 긍·부정(polarity)의 다중 라벨 분류 문제로 정의한다.
- 규칙 사전 분류와 학습 모델 분류를 만들고 작은 정답셋으로 precision·recall을 비교한다.
- 별점과 텍스트 감성이 다를 수 있음을 확인하고 어느 쪽을 언제 쓰는지 설명한다.
- 상품별·월별 장단점 요약표를 만들고 부정 급증을 알림으로 연결한다.
- 생성형 AI 분류를 같은 정답셋으로 검증하는 절차와 서비스 구성을 그린다.


## 개념부터 시작하기

리뷰 (d)를 TF–IDF 벡터 (x_d)로 바꾸고, 주제 (a)마다 (y_{d,a}\in\{0,1\})를 예측한다. 극성은 주제별로 따로 기록해 `(사이즈, 부정)`처럼 표현한다. 규칙 사전은 가장 단순하고 설명 가능한 기준선이다.

모델은 Precision·Recall·F1을 주제별로 평가하고, 빈도가 적은 주제의 평균에 가려지지 않게 표본 수를 함께 제시한다. 생성형 AI를 사용해도 같은 정답셋과 근거 구절로 비교하며 원문에 없는 요약을 허용하지 않는다.

## 문제 설정: 별점 4점 리뷰에 숨은 "사이즈가 작아요"

별점만 보면 평균 4.2점인 상품도 리뷰 본문에는 "사이즈가 작아요"가 반복될 수 있다. 별점은 전체 만족을, 본문은 구체적인 이유를 담는다. 리뷰 도구는 이 이유를 사이즈·소재·배송 같은 주제로 나누어 상품 페이지에 "사이즈: 작아요 32%"처럼 보여주고, 안다르처럼 키·몸무게와 결합해 사이즈 제안까지 확장한다([37장](templates/01_fashion_bigdata/lectures_korean/05_application/37_ch37_리뷰_기반_콘텐츠.md)).

### 2단계: 토큰화와 벡터, 시간 기준 분리

```python
from kiwipiepy import Kiwi
from sklearn.feature_extraction.text import TfidfVectorizer

kiwi = Kiwi()
for w in ["정사이즈", "핏", "기장", "두께감", "보풀", "촉감", "색감", "세일가"]:
    kiwi.add_user_word(w, "NNG")

def tokens(text):
    return [t.form for t in kiwi.tokenize(str(text)) if t.tag[:2] in ("NN", "VA", "VV", "MA", "XR")]

reviews["tokens"] = reviews["text"].apply(tokens)
print(reviews.loc[0, "text"], "→", reviews.loc[0, "tokens"])

reviews = reviews.sort_values("created_at").reset_index(drop=True)
split = int(len(reviews) * 0.7)
train, test = reviews.iloc[:split], reviews.iloc[split:]
vec = TfidfVectorizer(analyzer=lambda toks: toks, min_df=2)
X_train = vec.fit_transform(train["tokens"])
X_test = vec.transform(test["tokens"])
print("학습", X_train.shape, "/ 평가", X_test.shape)
```

### 3단계: 규칙 사전 분류

가장 단순한 방법은 주제 단어 사전과 극성 단어 사전이다. 도구 없이도 만들 수 있고, 모델의 기준선이 된다.

```python
ASPECT_WORDS = {
    "size": ["사이즈", "정사이즈", "치수", "기장", "핏", "크", "작"],
    "material": ["소재", "원단", "촉감", "두께감", "보풀", "비치"],
    "delivery": ["배송", "포장", "박스"],
    "color": ["색상", "색감", "색", "화면", "사진"],
    "price": ["가격", "세일가", "가성비"],
}
NEG_WORDS = {"작", "크", "길", "얇", "비치", "보풀", "뻣뻣", "늦", "걸리", "찌그러지", "어둡", "다르", "아쉽", "낫"}
POS_WORDS = {"맞", "예쁘", "부드럽", "적당", "고급", "빠르", "꼼꼼", "똑같", "만족", "잘"}

def rule_labels(toks):
    out = set()
    for aspect, words in ASPECT_WORDS.items():
        if any(any(t.startswith(w) for w in words) for t in toks):
            neg = any(any(t.startswith(w) for w in NEG_WORDS) for t in toks)
            pos = any(any(t.startswith(w) for w in POS_WORDS) for t in toks)
            out.add(f"{aspect}:{'neg' if neg and not pos else 'pos'}")
    return out

test = test.assign(rule=test["tokens"].apply(rule_labels), truth=test["aspect_labels"].str.split(";").apply(set))
print(test[["text", "truth", "rule"]].head(4).to_string(index=False))
```

### 4단계: 모델 분류 — 주제마다 분류기 하나

```python
from sklearn.linear_model import LogisticRegression

ASPECTS = list(ASPECT_WORDS)
def has(labels, key):
    return labels.str.split(";").apply(lambda ls: any(l.startswith(key) for l in ls)).astype(int)

pred = pd.DataFrame(index=test.index)
for aspect in ASPECTS:
    y_mention = has(train["aspect_labels"], aspect + ":")
    clf_mention = LogisticRegression(max_iter=1000, C=3).fit(X_train, y_mention)
    pred[f"{aspect}_mention"] = clf_mention.predict(X_test)
    # 극성 모델은 그 주제를 언급한 학습 리뷰만으로 학습한다
    mask = y_mention == 1
    y_neg = has(train.loc[mask, "aspect_labels"], aspect + ":neg")
    clf_pol = LogisticRegression(max_iter=1000, C=3).fit(X_train[mask.to_numpy()], y_neg)
    pred[f"{aspect}_neg"] = clf_pol.predict(X_test)

def model_labels(row):
    return {f"{a}:{'neg' if row[f'{a}_neg'] else 'pos'}" for a in ASPECTS if row[f"{a}_mention"]}

test = test.assign(model=pred.apply(model_labels, axis=1))
print(test[["text", "truth", "model"]].head(4).to_string(index=False))
```

### 5단계: 정답셋으로 평가

```python
def prf(pred_col):
    rows = []
    for aspect in ASPECTS:
        for pol in ["pos", "neg"]:
            key = f"{aspect}:{pol}"
            tp = sum(key in p and key in t for p, t in zip(test[pred_col], test["truth"]))
            fp = sum(key in p and key not in t for p, t in zip(test[pred_col], test["truth"]))
            fn = sum(key not in p and key in t for p, t in zip(test[pred_col], test["truth"]))
            rows.append({"label": key, "support": tp + fn,
                         "precision": tp / (tp + fp) if tp + fp else 0, "recall": tp / (tp + fn) if tp + fn else 0})
    return pd.DataFrame(rows).set_index("label")

compare = prf("rule").join(prf("model").drop(columns="support"), lsuffix="_rule", rsuffix="_model").round(2)
print(compare[["support", "precision_rule", "recall_rule", "precision_model", "recall_model"]])
print("평균 precision/recall — 규칙:", compare[["precision_rule", "recall_rule"]].mean().round(2).tolist(),
      "/ 모델:", compare[["precision_model", "recall_model"]].mean().round(2).tolist())
```

### 7단계: 상품별 장단점 요약과 부정 급증

```python
all_pred = pd.DataFrame(index=reviews.index)
X_all = vec.transform(reviews["tokens"])
for aspect in ASPECTS:
    y_mention = has(reviews["aspect_labels"], aspect + ":")          # 운영에서는 4단계의 모델 예측을 쓴다
    all_pred[f"{aspect}_neg"] = has(reviews["aspect_labels"], aspect + ":neg")
    all_pred[f"{aspect}_pos"] = y_mention - all_pred[f"{aspect}_neg"]

summary = all_pred.groupby(reviews["product_id"]).sum()
summary["reviews"] = reviews.groupby("product_id").size()
summary["size_neg_rate"] = (summary["size_neg"] / summary["reviews"]).round(2)

      .join(products.set_index("product_id")[["product_name", "fit"]]))

monthly = all_pred.groupby(reviews["created_at"].dt.to_period("M"))[["size_neg", "delivery_neg", "material_neg"]].sum()
```

## 5. 결과를 평가하는 법

- **분류 품질**: 주제별·극성별 precision·recall(5단계). 지원 건수가 적은 라벨은 신뢰 구간이 넓다(15장 8절).

- **업무 가치**: 요약표를 본 MD가 실제로 상품 정보를 수정했는지, 수정 뒤 사이즈 부정 비율이 줄었는지 추적한다.

## 핵심 용어

- **주제 기반 감성 분석(aspect-based sentiment analysis)**: 리뷰를 주제별 언급과 극성으로 분류하는 방법. 예: size:neg, delivery:pos.
- **다중 라벨(multi-label)**: 한 문서가 여러 라벨을 동시에 가질 수 있는 분류 문제.
- **정답셋(gold set)**: 사람이 라벨링한 평가용 데이터. 예: 리뷰 300건의 주제·극성 라벨.
- **TF-IDF**: 단어 빈도에 문서 빈도의 역수를 곱해 흔한 단어의 가중치를 낮춘 벡터.
- **극성(polarity)**: 긍정·부정 방향. 예: "얇고 비쳐요"는 material:neg.
- **텍스트 정형화(text structuring)**: 자유 텍스트를 표의 컬럼(주제·극성·근거)으로 바꾸는 작업.
