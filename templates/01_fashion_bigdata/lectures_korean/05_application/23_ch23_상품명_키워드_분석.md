# Product Name Keyword Analysis

## 학습 목표

상품명 키워드 분석은 단어를 많이 세는 데서 끝나지 않는다. 텍스트를 같은 규칙으로 토큰화하고, 전체 빈도와 최근 변화량을 분리해 고객 언어와 상품 구성의 변화를 읽는다.

이 장을 마치면 다음을 할 수 있다.

- 베스트 페이지 상품명을 키워드 후보의 원천으로 쓰는 가정과 그 한계를 설명한다.
- 불용어 제거, 형태소 분석(명사 추출), 토큰화의 차이를 설명하고 도메인 사전으로 분석기 오류를 고친다.
- 워드 카운트와 두 단어 조합 빈도로 키워드·키워드 조합 후보를 만든다.
- 최근 데이터와 과거 데이터의 워드 카운트를 비교해 상승 키워드를 찾는다.
- 키워드 후보를 검색 광고 도구(키워드 플래너·검색광고)와 상품명 작성에 연결하는 시스템을 그린다.


## 개념부터 시작하기

상품명 집합에서 단어 (w)의 빈도 (c(w))와 문서 빈도 (df(w))를 구분한다. 반복 장식어가 상위를 차지하면 불용어를 제거하고, 최근 비율 (p_{new}(w))와 과거 비율 (p_{old}(w))의 차이 또는 비를 사용해 상승 단어를 찾는다.

단순 기준선은 원문 문자열의 공백 분리 빈도다. 형태소 분석과 복합어 결합은 기준선보다 사람이 읽기 좋은 결과를 만드는지 확인한다. 빈도는 수요가 아니라 판매자가 사용한 언어의 빈도이므로 검색·주문 데이터와 연결하기 전에는 시장 선호로 단정하지 않는다.

## 문제 설정: 바지 관련 키워드는 열 개쯤 생각나면 끝이다

네이버 검색 광고를 집행하려는 운영자는 딜레마에 빠진다. "바지", "자켓"처럼 누구나 쓸 단어는 이미 선점한 쇼핑몰이 많아 입찰가가 높고, "벨트가 필요 없는 헐렁한 바지"처럼 경쟁이 약한 키워드는 아무도 검색하지 않는다. 게다가 주름바지·폭넓은 바지·조거팬츠… 열 개쯤 떠올리면 더는 생각나지 않는다. 그래서 **다른 쇼핑몰이 쓰는 상품명**에서 도움을 받는다. 다른 운영자들도 검색이 잘 되고 트렌디한 이름을 지으려 애쓰고, 베스트 상품의 이름을 모으면 그중에서도 잘 팔리는 상품의 이름을 모을 수 있다. "최근 인기 상품 이름에는 검색률이 높은 단어를 포함하려는 경향이 있다"는 가정이 이 분석의 출발점이다.

## 1. 데이터를 표로 표현하기

| 데이터 | 파일 | 역할 | 데이터 특징 |
|---|---|---|---|
| 최근 베스트 상품명 | `product_names_recent.csv` | 키워드 후보의 원천 | 텍스트(문서 200개), 순위, 가격 문자열 |

실무에서는 리스틀리 같은 수집 도구로 공개 상품 랭킹을 표로 정리할 수 있다. 이 장의 실습 데이터는 그와 같은 구조를 가진 가상 상품명이다. 실제 데이터를 수집할 때는 [19장 8절](templates/01_fashion_bigdata/lectures_korean/05_application/19_ch19_도구와_벤치마크_데이터셋.md)의 약관·robots.txt·개인정보 확인을 먼저 한다.

텍스트 데이터는 **문서 × 문장 × 단어**의 3차원이 일반적이지만(5장), 상품명은 한 문서가 한 문장이라 문서 × 단어 2차원으로 충분하다. 가격은 `"49,000원"` 같은 문자열이므로 숫자로 바꿔야 계산할 수 있다.

## 2. 모형과 계산 원리

웹·앱의 텍스트에서 반복되는 의도와 패턴을 찾는 과정을 **텍스트 마이닝**이라 한다. 가장 직관적인 출발점은 "많이 쓰는 단어가 중요한 단어일 수 있다"고 보고 등장 빈도를 세는 것이다.

| 단계 | 분석 방법 | 이 과정의 장 |
|---|---|---|
| 상품명 → 토큰 | 텍스트 표현(토큰화) | 5장 2절 |
| 워드 카운트 | 특성화(빈도) | 10장 |
| 두 단어 조합 | 빈발 패턴(공출현) | 11장 |
| 최근 vs 과거 비교 | 차별화(두 집단 비교) | 10장 |

전처리 세 가지의 뜻을 강의 정의대로 고정한다.

- **불용어 제거**: 개인의 판단에 따라 중요하지 않다고 보는 단어·기호를 제거한다. 예: `[`, `(`, 브랜드 태그, "배송".
- **형태소 분석**: 단어의 원형을 찾고 품사를 알려주는 분석. 예: "티셔츠의" → "티셔츠(명사)".
- **토큰화**: 문장·문단을 분석의 최소 단위로 자르는 과정. 여기서는 상품명을 단어 단위로 자른다.

### 2단계: 불용어 제거·형태소 분석·토큰화

한국어 명사 추출에는 KoNLPy의 Okt나 Kiwi 같은 형태소 분석기를 쓸 수 있다. 여기서는 자바 설치 없이 `pip`만으로 설치되는 **Kiwi**를 사용한다. 도구는 달라도 상품명에서 분석 단위를 추출한다는 목적은 같다.

```python
from kiwipiepy import Kiwi

kiwi = Kiwi()
sample = "[노르딕] 카키 와이드 린넨 반팔 블라우스 (3COLOR)"
print([(t.form, t.tag) for t in kiwi.tokenize(sample)])
```

```output
[('[', 'SSO'), ('노르딕', 'NNP'), (']', 'SSC'), ('카키', 'NNG'), ('와이드', 'NNG'), ('린', 'NNP'), ('네', 'XSN'), ('ᆫ', 'JX'), ('반팔', 'NNG'), ('블라우스', 'NNG'), ('(', 'SSO'), ('3', 'SN'), ('COLOR', 'SL'), (')', 'SSC')]
```

두 가지가 보인다. `[`, `]`, `(`, `)`, `3`, `COLOR`는 기호·숫자·외국어 품사로 나오므로 명사만 남기면 자연히 빠진다. 그런데 "린넨"이 "린 + 네 + ㄴ"으로 잘못 쪼개졌다. 형태소 분석기는 일반 문장으로 학습되어 패션 용어를 모른다. 강의도 Okt가 "크루넥"을 "크루", "넥"으로 나눈다고 했다. **도메인 사전**을 추가해 고친다.

```python
for word in ["린넨", "시어서커", "발레코어", "바라클라바", "하객룩", "오버핏", "슬림핏", "루즈핏", "레귤러핏", "와이드", "세미와이드", "크롭", "롱"]:
    kiwi.add_user_word(word, "NNG")
for brand in ["에브리데이", "코튼하우스", "무드라인"]:            # 브랜드명도 한 단어로 묶는다
    kiwi.add_user_word(brand, "NNP")

STOPWORDS = {"세트", "컬러", "상품", "배송"}          # 분석 목적상 중요하지 않다고 판단한 단어

def nouns(text):
    tokens = [t.form for t in kiwi.tokenize(str(text)) if t.tag in ("NNG", "NNP")]
    return [t for t in tokens if t not in STOPWORDS and len(t) > 1]

print(nouns(sample))
recent["tokens"] = recent["product_name"].apply(nouns)
past["tokens"] = past["product_name"].apply(nouns)
print(recent[["product_name", "tokens"]].head(4).to_string(index=False))
```

```output

           product_name                       tokens
        핑크 오버핏 데일리 블라우스         [핑크, 오버핏, 데일리, 블라우스]
[노르딕] 카키 와이드 린넨 반팔 블라우스 [노르딕, 카키, 와이드, 린넨, 반팔, 블라우스]
              롱 린넨 블라우스                   [린넨, 블라우스]
             와이드 세트 티셔츠                   [와이드, 티셔츠]
```

브랜드 태그(`[노르딕]`)의 브랜드명은 명사로 남는다. 키워드 광고 관점에서 타사 브랜드명은 쓸 수 없으므로 아래 워드 카운트에서 브랜드 목록도 불용어로 뺀다. 이런 판단이 곧 "개인의 판단에 따른 불용어 제거"다.

### 3단계: 워드 카운트와 막대그래프

```python
BRANDS = {"무드라인", "코튼하우스", "에브리데이", "노르딕", "블랑", "세컨드", "루트", "포레스트"}

def word_count(df):
    counter = Counter()
    for tokens in df["tokens"]:
        counter.update(t for t in tokens if t not in BRANDS)
    return counter

count_recent = word_count(recent)
count_past = word_count(past)
print("최근 상위 15:", count_recent.most_common(15))
print("과거 상위 15:", count_past.most_common(15))
```

운영자는 이 표의 상위 단어를 검색 광고 키워드 후보로 삼을 수 있다. 한 걸음 더 나가 "블랙코트", "와이드코트", "오버팬츠"처럼 **빈도가 높은 단어의 조합**도 후보로 만들 수 있다. 상품명 안에서 나란히 나온 두 단어 조합을 세면 된다.

```python
def bigram_count(df):
    counter = Counter()
    for tokens in df["tokens"]:
        clean = [t for t in tokens if t not in BRANDS]
        counter.update(zip(clean, clean[1:]))
    return counter

print(bigram_count(recent).most_common(10))
```

### 4단계: 최근 데이터와 과거 데이터의 워드 카운트 비교

단순 카운트만 보면 누구나 쓰는 단어(니트·팬츠)를 고르게 된다. 강의의 해법은 최근 데이터에서 과거 데이터와 겹치는 단어를 제외하고 남은 단어의 카운트를 보는 것이다. 그러면 상대적으로 최근 상승하는 키워드가 나온다.

```python
only_recent = {w: c for w, c in count_recent.items() if w not in count_past}
```

```python
n_recent, n_past = len(recent), len(past)

for w in set(count_recent) | set(count_past):
    r, p = count_recent.get(w, 0), count_past.get(w, 0)
    rows.append({"token": w, "recent_share_%": round(100 * r / n_recent, 1), "past_share_%": round(100 * p / n_past, 1)})
compare = pd.DataFrame(rows)
compare["change_pp"] = compare["recent_share_%"] - compare["past_share_%"]
compare = compare[(compare["recent_share_%"] >= 3) | (compare["past_share_%"] >= 3)]
print("상승 키워드:\n", compare.sort_values("change_pp", ascending=False).head(8).to_string(index=False))
print("하락 키워드:\n", compare.sort_values("change_pp").head(5).to_string(index=False))
```

## 5. 결과를 평가하는 법

- **원문 대조**: 상위 토큰 10개에 대해 원래 상품명 3개씩을 뽑아 분석기가 단어를 잘못 자르지 않았는지 확인한다. 도메인 사전을 늘린 뒤 다시 센다.
- **검색량·경쟁도**: 상품명 빈도는 "판매자가 쓰는 단어"이지 "고객이 검색하는 단어"가 아니다. 후보 키워드를 구글 키워드 플래너·네이버 검색광고의 검색량과 입찰가로 확인한다([26장](templates/01_fashion_bigdata/lectures_korean/05_application/26_ch26_시장_데이터_융합_추천.md)).
- **표본 조건**: 최근·과거 표본이 같은 페이지, 같은 순위 범위, 같은 카테고리인지 확인한다. 조건이 다르면 비교 결과는 트렌드가 아니라 수집 차이다.
- **성과**: 광고를 집행한 뒤 키워드별 클릭률·전환율로 평가한다([41장](templates/01_fashion_bigdata/lectures_korean/05_application/41_ch41_콘텐츠와_성과지표.md)).

## 핵심 용어

- **키워드 분석(keyword analysis)**: 텍스트에서 자주 쓰이는 단어를 찾아 검색 광고·상품명에 활용하는 분석. 예: 베스트 상품명의 상위 토큰.
- **불용어(stopword)**: 분석 목적상 제외하기로 정한 단어·기호. 예: 괄호, 브랜드 태그, "배송".
- **형태소 분석(morphological analysis)**: 단어의 원형과 품사를 찾는 분석. 예: "티셔츠의" → 티셔츠(명사).
- **토큰화(tokenization)**: 문장을 분석 단위로 자르는 과정. 예: 상품명을 단어 단위로.
- **도메인 사전(domain dictionary)**: 분석기가 모르는 분야 용어를 등록한 목록. 예: 린넨, 발레코어.
- **워드 카운트(word count)**: 토큰별 등장 횟수. 예: "니트" 142회.
- **상승 키워드(rising keyword)**: 과거 대비 최근 비중이 커진 단어. 예: 최근에만 나타난 "바라클라바".
