# HTML·CSS Basic Course Guide for Data Analysts

> **이 과정의 목표**
> 홈페이지를 새로 만들기 위한 공부가 아니라, 데이터 분석 결과가 담긴 기존 웹 문서를 읽고 필요한 태그·표·그림·링크·스타일을 안전하게 수정하는 최소 역량을 기른다.

## 이 과정이 필요한 이유

데이터 분석가는 대시보드 설명, 실험 결과 페이지, 사내 위키, 보고서 템플릿과 강의 자료를 수정할 때 HTML과 CSS를 마주친다. 이때 완성된 사이트를 설계할 수준의 지식은 필요하지 않지만, 제목과 표의 구조를 망가뜨리지 않고 원하는 부분만 찾고 고치려면 **내용을 나타내는 HTML**과 **보이는 방식을 정하는 CSS**의 차이를 알아야 한다.

생성형 AI가 코드를 작성해 주더라도 어느 파일과 어느 선택자를 바꿔야 하는지, 수정 범위가 다른 화면까지 번지지 않는지, 표와 이미지가 의미 있게 읽히는지는 사람이 확인해야 한다.

## 대상과 선수 지식

- Python Basic을 학습 중이거나 데이터 분석 결과를 웹 문서에 정리하려는 입문자
- 브라우저와 텍스트 파일을 사용할 수 있으면 시작 가능
- 프로그래밍 경험과 홈페이지 제작 경험은 필요하지 않음

## 과정 구성

| 1장 | 화면의 글자와 색은 어느 코드에서 오는가? | 브라우저 검사 도구, HTML·CSS·DOM, 원본과 화면의 차이 |
| 2장 | 내용을 어떤 태그로 묶어야 의미가 분명한가? | 요소·태그·속성, 제목·문단·목록·링크, 중첩과 시맨틱 구조 |
| 3장 | 분석 결과를 표와 그림으로 어떻게 전달하는가? | `table`, `caption`, `figure`, `figcaption`, `img`, `alt`, `details` |
| 4장 | 원하는 부분만 어떻게 찾아 스타일을 바꾸는가? | 선택자, class, cascade, specificity, box model, 반응형 기본 |

## 학습 방법

각 장에서는 완성된 웹페이지를 처음부터 만들지 않는다. 짧은 분석 결과 조각을 읽고 다음 순서로 수정한다.

1. 브라우저 검사 도구에서 바꾸려는 요소를 찾는다.
2. HTML이 내용과 의미를, CSS가 모양을 담당하는지 구분한다.
3. 전역 태그보다 재사용 가능한 class를 붙여 수정 범위를 좁힌다.
4. 데스크톱과 좁은 화면에서 표·그림·글자가 잘리는지 확인한다.
5. 수정 전후를 비교하고 되돌릴 수 있도록 변경 내용을 기록한다.

## 다른 과정과의 관계

- **Python Basic**에서 만든 표와 그래프를 웹 문서에 설명과 함께 배치할 때 활용한다.
- **패션 데이터 분석과 AI**에서 분석 결과, 출처 링크와 시각자료를 정리할 때 활용한다.
- 기존의 Flask 중심 웹 제작 자료는 별도의 개발 참고 문서인 `docs/web_publishing/`에 계속 보관한다.

## 과정 완료 기준

5장에서 제공하는 분석 결과 조각을 다음 조건에 맞게 수정한다.

- 제목 계층이 순서대로 이어진다.
- 표에 제목과 열 머리글이 있다.
- 그래프에 대체 텍스트와 캡션이 있다.
- 링크만 보고도 목적지를 예상할 수 있다.
- 하나의 class로 필요한 영역만 스타일링한다.
- 좁은 화면에서도 가로 넘침과 잘림을 점검한다.

## 범위에 관한 주의

이 과정은 웹사이트 제작 과정이 아니다. JavaScript 프로그래밍, 백엔드, 데이터베이스, 로그인, Flask·React, 서버 운영과 배포는 다루지 않는다. 인라인 스타일을 외우거나 모든 태그를 암기하는 것도 목표가 아니다. 필요한 요소를 공식 문서에서 찾아 적용하고, **작게 수정한 뒤 화면과 의미를 함께 검증하는 능력**이 목표다.
