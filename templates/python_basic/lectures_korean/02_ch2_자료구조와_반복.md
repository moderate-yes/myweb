# 리스트와 딕셔너리, 반복과 조건

## 학습 목표

- 리스트·딕셔너리의 차이와 쓰임을 구분하고 튜플은 읽을 수 있다.
- 인덱싱과 슬라이싱으로 원하는 값을 꺼낸다.
- `for` 반복문으로 여러 값을 한 번에 처리한다.
- `if`/`elif`/`else`로 조건에 따라 다른 계산을 한다.

> **이 장의 중심 질문**<br>
> 값 100개를 하나의 이름으로 묶고, 같은 계산을 100번 반복하려면 어떻게 쓸까?

## 핵심 용어

- **리스트(list)**: 순서가 있는 값의 모음. `[ ]`로 만든다.
- **딕셔너리(dict)**: 키와 값의 쌍으로 이루어진 모음. `{ }`로 만든다.
- **튜플(tuple)**: 만든 뒤 바꿀 수 없는 값의 모음. `( )`로 만든다.
- **인덱스(index)**: 리스트에서 값의 위치. 0부터 센다.
- **반복문(loop)**: 같은 코드를 모음의 각 값에 대해 실행하는 구조.

## 1. 리스트: 순서가 있는 값의 모음

```python
prices = [59000, 129000, 229000, 39000]
print(prices[0])     # 59000   첫 번째
print(prices[-1])    # 39000   마지막
print(len(prices))   # 4       개수
```

인덱스는 **0부터** 센다. 첫 값은 `prices[0]`, 두 번째는 `prices[1]`이다. 음수는 뒤에서부터 센다.

슬라이싱은 범위를 잘라낸다. 끝 번호는 포함하지 않는다.

```python
print(prices[0:2])   # [59000, 129000]
print(prices[2:])    # [229000, 39000]
```

값을 더하거나 바꿀 수 있다.

```python
prices.append(99000)   # 맨 뒤에 추가
prices[1] = 120000     # 두 번째 값 교체
```

## 2. 딕셔너리: 이름표가 붙은 값

리스트는 위치로 값을 찾지만, 딕셔너리는 **키**로 찾는다. 한 상품의 여러 속성을 묶을 때 유용하다.

```python
product = {
    "product_id": "P501",
    "category": "Coat",
    "color": "Navy",
    "list_price": 229000,
}
print(product["category"])     # Coat
product["list_price"] = 199000 # 값 수정
product["season"] = "FW"       # 새 키 추가
```

없는 키를 대괄호로 찾으면 `KeyError`가 난다. `get`은 없을 때 기본값을 준다.

```python
print(product.get("fit", "unknown"))   # unknown
```

<details>
<summary><strong>선택 참고: 튜플은 바뀌지 않는 묶음</strong></summary>

튜플은 리스트와 비슷하지만 만든 뒤 수정할 수 없다. 좌표나 Shape처럼 "고정된 한 쌍"을 나타낼 때 쓴다. 5장의 NumPy 배열 Shape가 튜플이다.

```python
shape = (100, 3)
print(shape[0])   # 100
shape[0] = 200    # TypeError: 튜플은 수정할 수 없다
```

튜플 문법을 외울 필요는 없다. 라이브러리의 Shape나 여러 반환값에서 `(100, 3)`을 보았을 때 수정할 수 없는 순서 묶음임을 읽으면 충분하다.

## 4. for 반복문: 모음의 각 값 처리하기

```python
prices = [59000, 129000, 229000, 39000]
for p in prices:
    print(p * 1.1)   # 10% 인상가를 하나씩 출력
```

반복하면서 결과를 새 리스트에 모으는 패턴이 가장 많이 쓰인다.

```python
raised = []
for p in prices:
    raised.append(round(p * 1.1))
print(raised)   # [64900, 141900, 251900, 42900]
```

딕셔너리를 반복하면 키가 나온다. `.items()`로 키와 값을 함께 받는다.

```python
for key, value in product.items():
    print(key, "->", value)
```

## 5. if 조건문: 상황에 따라 다르게

```python
stock = 3
if stock == 0:
    status = "품절"
elif stock < 5:
    status = "재고 부족"
else:
    status = "정상"
print(status)   # 재고 부족
```

들여쓰기(보통 공백 4칸)가 문법의 일부다. `if` 아래 줄이 들여쓰기로 묶여 하나의 블록이 된다. 들여쓰기가 어긋나면 `IndentationError`가 난다.

반복문과 조건문을 합치면 "조건에 맞는 값만 고르기"가 된다. 이 논리가 4장 pandas 필터의 바탕이다.

```python
prices = [59000, 129000, 229000, 39000]
expensive = []
for p in prices:
    if p >= 100000:
        expensive.append(p)
print(expensive)   # [129000, 229000]
```

## 6. 문제 발생: 원본을 바꾸는 실수

리스트를 다른 이름에 넣어도 **같은 리스트를 가리킬 뿐** 복사되지 않는다.

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)   # [1, 2, 3, 4]  a도 바뀐다
```

복사가 필요하면 `a.copy()` 또는 `a[:]`를 쓴다. 데이터 분석에서 "원본은 두고 가공본만 만든다"는 원칙이 여기서 시작된다.

## 7. 생성형 AI가 만든 반복문 검토하기

AI가 만든 코드도 리스트의 원본을 바꾸거나, 없는 딕셔너리 키를 가정하거나, 빈 목록에서 실패할 수 있다. 코드를 받을 때 다음 세 입력을 함께 시험한다.

| 시험 입력 | 확인할 오류 |
|---|---|
| 정상 상품 2~3개 | 기대한 값과 순서가 나오는가? |
| 키 하나가 빠진 상품 | `KeyError`가 나는가, 누락을 명시적으로 처리하는가? |
| 빈 리스트 | 0·빈 목록·오류 중 어떤 결과가 업무 정의에 맞는가? |

반복문을 직접 외워 쓰는 속도보다 각 반복이 무엇을 읽고 무엇을 바꾸는지 설명하는 능력이 중요하다.

## 짧은 활동

다음 리스트로 코랩에서 작업한다.

```python
orders = [
    {"product": "P501", "qty": 2, "price": 229000},
    {"product": "P320", "qty": 1, "price": 39000},
    {"product": "P501", "qty": 3, "price": 229000},
]
```

1. `for` 반복으로 각 주문의 금액(`qty * price`)을 출력한다.
2. 전체 매출 합계를 구한다.
3. `product`가 `"P501"`인 주문의 수량만 더한다.
4. 3번을 딕셔너리 `{상품: 수량합}` 형태로 확장해 본다.

## 이 장의 핵심

- 리스트는 위치(인덱스 0부터)로, 딕셔너리는 키로 값을 찾는다.
- 튜플은 수정할 수 없는 묶음이며 Shape 같은 고정 쌍에 쓴다.
- `for`는 모음의 각 값을 처리하고, 결과를 새 리스트에 모으는 패턴이 흔하다.
- `if`/`elif`/`else`와 들여쓰기로 조건에 따라 다른 코드를 실행한다.
- 리스트를 다른 이름에 넣어도 복사되지 않으므로 가공 전 `copy()`를 고려한다.

## 학습 점검

1. `prices = [10, 20, 30]`일 때 `prices[-1]`과 `prices[1:]`은 각각 무엇인가?
2. 딕셔너리에서 없는 키를 `[ ]`로 찾을 때와 `.get()`으로 찾을 때의 차이는?
3. `b = a`로 리스트를 넘긴 뒤 `b`를 수정하면 `a`는 어떻게 되는가? 이유는?

<details><summary>정답과 해설 보기</summary>

1. `prices[-1]`은 `30`(마지막 값), `prices[1:]`은 `[20, 30]`(인덱스 1부터 끝까지)이다.
2. `[ ]`는 `KeyError`를 일으키고, `.get()`은 `None` 또는 지정한 기본값을 돌려준다.
3. `a`도 함께 바뀐다. `b = a`는 리스트를 복사하지 않고 같은 객체를 가리키게 하기 때문이다.
