# Python Basic 과정 안내

> **이 과정의 목표**
> 분석 도구를 배우기 전에, 코드를 읽고 작은 데이터를 직접 다루는 최소한의 파이썬 감각을 익힌다.

## 대상과 선수 지식

Data Literacy를 마쳤거나 표의 행과 열, 비율과 평균을 읽을 수 있는 학습자를 위한 입문 과정이다. 코딩 경험이 전혀 없어도 시작할 수 있다. 이 과정은 **Consumer Data Utilization 5장의 코랩 실습**과 **AI Math·AI Basic의 NumPy 확인 실습**에 필요한 최소 기반을 만든다.

## 학습 방법

각 장의 코드는 반드시 코랩 또는 주피터에서 직접 실행한다. 순서는 다음을 권장한다.

1. 코드를 읽고 결과를 먼저 예측한다.
2. 실행해 예측과 비교한다.
3. 숫자나 조건을 하나 바꿔 결과가 어느 방향으로 변하는지 확인한다.
4. 오류 메시지가 나오면 마지막 줄부터 읽고, 어떤 값이 문제인지 찾는다.

## 과정 완료 기준

5장에서 공통 실습 데이터(`products.csv`, `orders.csv`)를 읽어 다음을 한 장짜리 노트로 정리한다.

- 두 파일의 행 수, 컬럼, 결측치
- `product_id`로 두 표를 연결한 결과의 행 수
- 카테고리별 주문 건수 표 하나와 막대그래프 하나
- 코드가 사용한 제외 규칙(취소·반품·결측)과 기준 기간

## 범위에 관한 주의

이 과정은 파이썬 언어를 완전히 가르치지 않는다. 클래스, 데코레이터, 비동기, 패키지 배포처럼 입문 이후의 주제는 다루지 않는다. 목표는 **다음 과정의 코드를 읽고 수정할 수 있는 상태**에 도달하는 것이다.
