## 학습 목표

파이썬은 별도 설치 없이 브라우저의 코랩에서 바로 실행할 수 있다. 이 장은 코드가 어디서 실행되고 변수가 값을 어떻게 기억하는지부터 시작해, 이후 장에서 쓸 실행 환경을 준비한다.

이 장을 마치면 다음을 할 수 있다.

- 코랩에서 새 노트를 만들고 셀을 실행한다.
- 변수에 값을 저장하고 다시 사용한다.
- 정수·실수·문자열·불리언 네 가지 기본 자료형을 구분한다.
- `print`와 오류 메시지를 읽는 기본 방법을 익힌다.

## 1. 질문: 코드는 어디서 실행되는가?

파이썬 코드를 실행하려면 코드를 해석해 계산하는 환경이 필요하다. 이 과정에서는 [구글 코랩](https://colab.research.google.com/)을 사용한다. 코랩은 브라우저에서 열리는 노트에 코드를 쓰고, 구글이 관리하는 원격 컴퓨터가 그 코드를 실행한다. 별도 설치가 없고, pandas·NumPy·matplotlib 같은 분석 패키지가 대부분 미리 들어 있다.

주의할 점이 하나 있다. 코랩의 실행 환경(런타임)은 임시다. 일정 시간 쓰지 않으면 연결이 끊기고, 그때까지 변수에 저장한 값도 사라진다. 노트 파일 자체는 구글 드라이브에 남지만, 계산 결과는 다시 실행해야 한다.

## 2. 가장 단순한 예: 값을 이름에 저장하기

새 셀에 다음을 입력하고 실행한다.

```python
price = 229000
quantity = 3
total = price * quantity
print(total)
```

실행하면 `687000`이 출력된다. 여기서 `price`, `quantity`, `total`은 **변수**다. `=`는 "같다"가 아니라 **오른쪽 값을 계산해 왼쪽 이름에 저장하라**는 뜻이다.

변수는 나중에 값을 바꿀 수 있다.

```python
quantity = 5
total = price * quantity
print(total)   # 1145000
```

`#` 뒤의 글자는 **주석**이며 실행되지 않는다. 코드가 무엇을 하는지 사람에게 설명할 때 쓴다.

## 3. 네 가지 기본 자료형

| 자료형 | 예 | 설명 |
|---|---|---|
| 정수 `int` | `3`, `-10`, `229000` | 소수점이 없는 수 |
| 실수 `float` | `3.14`, `0.5`, `1.0` | 소수점이 있는 수 |
| 문자열 `str` | `"코트"`, `'Navy'` | 따옴표로 감싼 글자 |
| 불리언 `bool` | `True`, `False` | 참과 거짓 |

값의 자료형은 `type()`으로 확인한다.

```python
print(type(229000))     # <class 'int'>
print(type(0.5))        # <class 'float'>
print(type("코트"))      # <class 'str'>
print(type(3 > 2))      # <class 'bool'>
```

자료형이 중요한 이유는 **가능한 연산이 다르기 때문**이다. 문자열끼리 `+`는 이어 붙이기이고, 숫자끼리 `+`는 더하기다. 서로 다른 종류를 섞으면 오류가 난다.

```python
name = "P501 "
label = name + "Navy Coat"   # 'P501 Navy Coat'
count = "3" + 5              # TypeError: 문자열과 정수는 더할 수 없다
```

문자열로 들어온 숫자는 `int()`나 `float()`로 바꿔야 계산할 수 있다. 5장에서 다룰 실제 데이터에서 가격이 `"229,000원"`처럼 문자열로 들어오는 경우가 많다.

```python
raw = "229000"
print(int(raw) * 2)   # 458000
```

## 4. 자주 쓰는 연산자

```python
print(7 + 2)    # 9
print(7 - 2)    # 5
print(7 * 2)    # 14
print(7 / 2)    # 3.5   나눗셈은 항상 실수
print(7 // 2)   # 3     몫
print(7 % 2)    # 1     나머지
print(2 ** 10)  # 1024  거듭제곱
```

비교 연산자는 항상 불리언을 만든다. 이 값이 2장의 조건문과 4장의 데이터 필터에서 그대로 쓰인다.

```python
stock = 4
print(stock > 0)     # True
print(stock == 10)   # False   같은지 비교는 == (= 아님)
print(stock != 10)   # True
```

## 5. 문제 발생: 오류 메시지 읽기

초보자는 빨간 오류 화면을 보면 멈추기 쉽다. 그러나 오류는 대부분 **어디서, 무엇이 잘못됐는지**를 마지막 줄에 적어 준다.

```python
total = price * qty
# NameError: name 'qty' is not defined
```

`NameError`는 "그런 이름의 변수가 없다"는 뜻이다. 여기서는 `quantity`를 `qty`로 잘못 썼다. 자주 만나는 오류는 다음과 같다.

| 오류 이름 | 흔한 원인 |
|---|---|
| `NameError` | 정의하지 않은 변수를 사용 |
| `TypeError` | 서로 다른 자료형을 잘못 연산 |
| `SyntaxError` | 괄호·따옴표가 닫히지 않음 |
| `IndentationError` | 들여쓰기가 어긋남 |

## 6. 생성형 AI를 사용할 때도 실행 환경은 사람이 확인한다

AI가 올바른 파이썬 코드를 제안해도 현재 노트북에 파일·변수·패키지가 없으면 실행되지 않는다. 코드를 받기 전에 `사용할 입력`, `현재 정의된 변수`, `설치된 패키지`, `기대 출력`을 함께 알려주고, 받은 뒤에는 첫 셀부터 실행 순서를 확인한다. 비밀번호·API 키·실제 고객정보는 프롬프트나 공개 노트북에 넣지 않는다.

3. `"3" + 5`가 오류인 이유와 해결 방법은 무엇인가?

<details><summary>정답과 해설 보기</summary>

1. `=`는 오른쪽 값을 계산해 왼쪽 이름에 저장한다. `==`는 두 값이 같은지 비교해 불리언을 만든다.
2. `7 / 2`는 `3.5`(실수), `7 // 2`는 `3`(정수)이다. `/`는 항상 실수를 반환한다.

## 핵심 용어

- **셀(cell)**: 코랩 노트에서 코드나 설명을 담아 한 번에 실행하는 단위.
- **변수(variable)**: 값에 붙인 이름. 이름으로 값을 다시 꺼내 쓸 수 있다.
- **자료형(type)**: 값의 종류. 계산 방식과 가능한 연산을 결정한다.
- **문자열(string)**: 따옴표로 감싼 글자 데이터.
- **불리언(boolean)**: 참(`True`) 또는 거짓(`False`) 두 값만 갖는 자료형.
