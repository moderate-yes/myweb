## 1. 함수: 계산에 이름 붙이기

2장에서 "가격에 10%를 더하는" 계산을 여러 번 반복했다. 함수로 만들면 한 번만 정의한다.

```python
def raise_price(price, rate=0.1):
    return round(price * (1 + rate))

print(raise_price(59000))        # 64900
print(raise_price(59000, 0.2))   # 70800
```

- `def`로 함수를 정의한다.
- `price`, `rate`는 **매개변수**다. `rate=0.1`은 값을 주지 않으면 쓰는 기본값이다.
- `return`은 결과를 돌려주고 함수를 끝낸다. `return`이 없으면 `None`을 돌려준다.

함수 안에서 만든 변수는 함수 밖에서 보이지 않는다. 함수는 **입력(인자)과 출력(반환값)으로만 바깥과 소통**한다고 생각하면 된다.

## 2. 여러 값을 처리하는 함수

```python
def total_revenue(orders):
    total = 0
    for order in orders:
        total += order["qty"] * order["price"]
    return total

orders = [
    {"qty": 2, "price": 229000},
    {"qty": 1, "price": 39000},
]
print(total_revenue(orders))   # 497000
```

이렇게 "표 같은 데이터를 받아 하나의 숫자를 돌려주는" 함수가 분석 코드의 기본 단위다. 4장의 pandas는 이런 함수를 미리 만들어 둔 도구다.

## 4. 파일 읽기: 먼저 pandas로 표 전체를 확인한다

분석 입문에서는 CSV를 직접 한 줄씩 처리하기보다 `pandas.read_csv`로 표 전체를 불러오고 행 수·컬럼·자료형을 확인하는 방법을 우선한다.

```python
import pandas as pd

products = pd.read_csv("products.csv")
print(products.shape)
print(products.dtypes)
print(products.head())
```

<details>
<summary><strong>선택 참고: 표준 라이브러리로 CSV를 한 줄씩 읽기</strong></summary>

실습 데이터는 대부분 CSV(쉼표로 구분된 표) 파일이다. 표준 라이브러리 `csv`로 읽는 방법은 다음과 같다.

```python
import csv

with open("products.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["product_id"], row["list_price"])
```

- `with open(...)`은 파일을 열고, 블록이 끝나면 자동으로 닫는다.
- `csv.DictReader`는 각 줄을 **딕셔너리**로 준다. 키는 첫 줄(헤더)의 컬럼 이름이다.
- CSV의 모든 값은 **문자열**로 읽힌다. `list_price`로 계산하려면 `int(row["list_price"])`가 필요하다.

이 저수준 방식은 매우 큰 파일을 순차 처리하거나 외부 라이브러리를 사용할 수 없는 상황에서 유용하다. 일반 분석에서는 4장의 `pandas.read_csv`를 사용한다. 어느 방식이든 파일에서 읽은 값의 자료형을 확인해야 한다.

## 5. 예외 처리: 깨진 값 안전하게 넘기기

데이터에는 빈칸이나 `"미정"` 같은 값이 섞인다. 그대로 `int()`하면 전체가 멈춘다.

```python
def to_int(text):
    try:
        return int(text)
    except (ValueError, TypeError):
        return None

print(to_int("229000"))   # 229000
print(to_int(""))         # None
print(to_int("미정"))      # None
```

`try` 블록에서 오류가 나면 실행이 `except` 블록으로 넘어간다. 전체를 멈추지 않고 "이 값은 처리 불가"로 표시하고 계속 진행할 수 있다.

## 6. 문제 발생: 함수가 조용히 아무것도 안 돌려줄 때

```python
def raise_price(price, rate=0.1):
    round(price * (1 + rate))   # return 을 빠뜨림

result = raise_price(59000)
print(result)   # None
```

`return`이 없으면 함수는 `None`을 돌려준다. 이후 `None`으로 계산하면 `TypeError`가 난다. "계산은 되는데 결과가 `None`"이면 `return`을 확인한다.

## 7. 생성형 AI가 만든 함수는 예제로 계약을 확인한다

함수 요청에는 설명만 주지 말고 입력과 기대 출력을 함께 준다.

| 사례 | 입력 | 기대 결과 |
|---|---|---|
| 정상 | 가격 `[10000, 20000]` | 평균 `15000` |
| 결측 포함 | `[10000, None]` | 결측 제외 또는 오류 중 사전 정의한 방식 |
| 빈 입력 | `[]` | `None`, `0`, 오류 중 업무에 맞는 방식 |
| 잘못된 형식 | `["미정", 10000]` | 잘못된 값과 처리 규칙을 명시 |

AI가 함수 설명과 코드를 함께 만들었더라도 둘 다 같은 잘못된 가정을 공유할 수 있다. 실행 결과를 사람이 작성한 작은 기대값과 비교해야 한다.

## 이 장의 핵심

- 함수는 `def`로 정의하고 `return`으로 결과를 돌려준다. `return`이 없으면 `None`이다.

## 핵심 용어

- **함수(function)**: 입력을 받아 계산하고 결과를 돌려주는 이름 붙은 코드 묶음.
- **인자(argument)**: 함수를 부를 때 전달하는 값.
- **반환값(return value)**: 함수가 계산을 끝내고 돌려주는 결과.
- **모듈(module)**: 함수와 값을 모아 둔 파일. `import`로 불러온다.
- **예외(exception)**: 실행 중 발생하는 오류. `try`/`except`로 붙잡을 수 있다.
