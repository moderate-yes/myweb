# Flask로 수익형 강의 웹사이트 만들기 1: 기획과 개발 환경

이 시리즈에서는 Python 웹 프레임워크 **Flask**를 사용해 마크다운 기반 강의 사이트를 직접 만든다. 단순히 완성 코드를 복사하는 대신, 한 단계씩 기능을 추가하며 웹 개발의 기본 구조를 익히는 것이 목표다.

완성할 사이트에는 다음 기능이 들어간다.

- 상단 내비게이션
- 마크다운 강의 목록과 본문
- 후원 문의 영역
- Google AdSense 또는 쿠팡 파트너스 광고 영역
- 비밀번호로 보호되는 포트폴리오
- 모바일에서도 읽을 수 있는 반응형 화면

> 수익은 방문자에게 유용한 콘텐츠가 충분히 쌓인 뒤 따라오는 결과다. 광고 배치보다 먼저 읽을 가치가 있는 강의를 만드는 데 집중하자.

## Flask를 선택한 이유

Flask는 필요한 기능을 직접 조합하는 가벼운 Python 웹 프레임워크다. 자동으로 처리되는 부분이 비교적 적어서 라우팅, 템플릿, 정적 파일과 세션이 어떻게 연결되는지 배우기 좋다.

이 프로젝트에서는 다음 개념을 익힌다.

1. URL과 Python 함수를 연결하는 라우팅
2. HTML을 재사용하는 Jinja 템플릿
3. CSS와 이미지 같은 정적 파일
4. 마크다운을 HTML로 변환하는 과정
5. 로그인 상태를 기억하는 세션

## 프로젝트 폴더 만들기

먼저 다음과 같은 구조로 시작한다.

```text
app/
├─ app.py
├─ templates/
│  ├─ main.html
│  └─ lectures/
└─ static/
   ├─ css/
   └─ image/
```

Flask는 기본적으로 `templates` 폴더에서 HTML을 찾고, `static` 폴더에서 CSS와 이미지를 제공한다. 강의 원고는 `templates/lectures` 아래에 마크다운 파일로 보관한다.

## 필요한 패키지 설치

가상환경을 만든 뒤 Flask와 Markdown을 설치한다.

```bash
python -m venv .venv
```

Windows PowerShell에서는 다음 명령으로 가상환경을 활성화한다.

```powershell
.\.venv\Scripts\Activate.ps1
pip install flask markdown
```

패키지 버전을 기록해 두면 다른 컴퓨터에서도 같은 환경을 만들기 쉽다.

```bash
pip freeze > requirements.txt
```

## 가장 작은 Flask 앱

`app.py`에 다음 코드를 작성한다.

```python
from flask import Flask

app = Flask(__name__)


@app.route('/')
def home():
    return '<h1>Hello, Flask!</h1>'


if __name__ == '__main__':
    app.run(debug=True, port=5000)
```

`@app.route('/')`는 브라우저가 메인 주소를 요청했을 때 `home()` 함수를 실행하라는 뜻이다. 개발 중에만 `debug=True`를 사용하고, 공개 서버에서는 디버그 모드를 꺼야 한다.

실행 후 브라우저에서 `http://127.0.0.1:5000`을 열어 첫 화면을 확인한다.

## 수익 모델을 먼저 설계하기

강의 사이트에서 고려할 수 있는 수익 경로는 크게 세 가지다.

- **디스플레이 광고**: 본문을 방해하지 않는 영역에 광고를 배치한다.
- **제휴 마케팅**: 강의와 관련 있는 상품이나 서비스를 소개하고 제휴 링크를 사용한다.
- **직접 후원**: 사이트의 취지에 공감하는 독자나 기업으로부터 후원을 받는다.

광고와 제휴 링크는 반드시 독자가 광고임을 알 수 있게 표시해야 한다. 서비스에 적용하기 전에는 각 광고 플랫폼의 최신 운영 정책과 관련 법규도 확인한다.
