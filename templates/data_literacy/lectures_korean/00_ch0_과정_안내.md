# Data Literacy 과정 안내

> **이 과정의 목표**  
> 데이터를 많이 모으는 법보다, 어떤 질문에 어떤 증거가 필요한지 판단하는 힘을 기른다.

## 대상 학습자

- 패션·디자인·기획 분야에서 데이터를 처음 배우는 사람
- 분석 결과를 직접 만들거나 데이터 직무와 협업해야 하는 사람
- AI와 자동화를 배우기 전에 데이터의 생성·편향·한계를 이해하고 싶은 사람

별도의 코딩 경험은 필요하지 않다. 표의 행과 열, 비율과 평균을 읽을 수 있으면 시작할 수 있다.

## 이 과정에서 할 수 있게 되는 것

- 데이터의 활용 가치와 관리 비용을 함께 설명한다.
- 상품·고객·주문을 식별자와 표 구조로 연결한다.
- 모호한 비즈니스 질문을 측정 가능한 질문으로 바꾼다.
- 집단 비교, 확률, 상관과 인과를 구분한다.
- 지표·자동화·AI 결과가 말할 수 있는 범위를 판단한다.

## 12개 장의 구조

| 모듈 | 장 | 핵심 질문 |
|---|---|---|
| 데이터 기반 | 1~4장 | 데이터는 어떤 가치와 구조를 가지며 어떻게 질문하는가? |
| 증거와 판단 | 5~7장 | 집단 차이·인과·불확실성을 어떻게 해석하는가? |
| 콘텐츠와 운영 | 8~10장 | 콘텐츠·UGC·자동화를 어떤 지표로 운영하는가? |
| AI 이해 | 11~12장 | AI의 학습과 생성 결과를 어디까지 신뢰할 수 있는가? |

- 모델의 학습 원리를 이해하려면 **AI Basic**으로, 수식을 깊게 보려면 **AI Math**를 동반 과정으로 사용한다.

## 학습 방법

각 장에서 `질문 → 단순 사례 → 데이터 또는 수식 → 한계 → 판단` 순서를 따른다. 기업 사례의 숫자보다 어떤 근거로 결론을 내렸는지를 설명할 수 있어야 한다.

## 과정 완료 기준

마지막에는 하나의 패션 의사결정을 골라 다음을 한 장으로 정리한다.

1. 결정할 질문과 분석 단위
2. 필요한 데이터와 수집 목적
3. 사용할 지표와 비교 기준
4. 가능한 대안 설명과 편향
5. 실험 또는 추가 검증 방법
6. 사람이 최종 판단해야 하는 범위
