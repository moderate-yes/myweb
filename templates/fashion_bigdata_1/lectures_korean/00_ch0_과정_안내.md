# 패션 빅데이터 1 과정 안내

> **데이터와 증거의 기초**  
> 패션 비즈니스에서 데이터가 어떻게 만들어지고 표현되며, 어떤 근거로 의사결정을 내려야 하는지 배운다.

## 과정의 위치

기존 Data Literacy와 Consumer Data Utilization의 개념 부분을 하나의 흐름으로 통합했다. 같은 개념을 두 과정에서 반복하지 않고, 빅데이터의 정의에서 데이터 구조·분석 질문·불확실성·인과·책임으로 이어지게 구성했다.

코딩 경험은 필수가 아니다. 표의 행과 열, 평균과 비율을 읽을 수 있으면 시작할 수 있다. 직접 데이터를 정제하고 분석하려면 이 과정을 마친 뒤 [패션 빅데이터 2](templates/fashion_bigdata_2/lectures_korean/00_ch0_과정_안내.md)로 이어간다.

## 11개 장의 순서

| 장 | 주제 | 중심 질문 |
|---:|---|---|
| 1 | 빅데이터·모집단·전수 기록 | 기록 전체는 현실의 전체와 같은가? |
| 2 | 온라인 소비자·운영·분석 데이터 | 운영 기록은 어떻게 분석 근거가 되는가? |
| 3 | 식별자와 마스터 데이터 | 상품과 고객을 어떻게 일관되게 기억하는가? |
| 4 | 의미·척도·dtype·Shape | 같은 값도 왜 다른 계산을 요구하는가? |
| 5 | 멀티모달 데이터와 Vector | 텍스트·이미지·영상·음성을 어떻게 숫자로 표현하는가? |
| 6 | Table·JSON·Network | 활용 목적에 맞는 데이터 구조는 무엇인가? |
| 7 | 질문·SQL·워크플로우·분석 갈래 | 비즈니스 질문을 어떻게 실행 가능한 분석으로 바꾸는가? |
| 8 | 집단 비교 | 평균과 비율을 어떻게 공정하게 비교하는가? |
| 9 | 관계와 인과 | 함께 움직이는 것과 원인을 어떻게 구분하는가? |
| 10 | 확률과 불확실성 | 불완전한 정보에서 어떻게 판단하는가? |
| 11 | 데이터의 한계와 증거 | 데이터가 말하지 못하는 범위는 어디인가? |

## 학습 원칙

- 데이터가 많다는 이유로 대표성·정확성·인과가 자동으로 확보된다고 가정하지 않는다.
- 값의 의미, 관측 범위, 제외 규칙과 비교 기준을 먼저 확인한다.
- 생성형 AI가 만든 설명과 코드도 원자료·공식 출처·작은 반례로 검증한다.
- 각 장의 패션 사례를 자신의 상품·고객·채널 의사결정에 다시 적용한다.

## 완료 기준

하나의 패션 의사결정을 골라 질문, 데이터의 생성 목적, 분석 단위, 비교 기준, 가능한 편향과 추가 검증 방법을 한 장으로 설명할 수 있으면 이 과정을 완료한 것이다.
