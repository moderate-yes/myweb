# Web Publishing with Flask 과정 안내

> **이 과정의 목표**  
> Markdown 강의 원고를 읽어 보여주는 작은 Flask 웹사이트를 만들고, 보안·테스트·배포 전 점검까지 수행한다.

## 대상과 선수 지식

Python의 변수와 함수 문법을 조금이라도 본 학습자를 대상으로 한다. Data Literacy 과정과는 독립적으로 수강할 수 있다.

## 완성할 결과

| 장 | 구현 결과 |
|---|---|
| 1장 | 가상환경과 가장 작은 Flask 앱 |
| 2장 | 라우팅·공통 템플릿·내비게이션 |
| 3장 | Markdown 강의 목록과 본문 렌더링 |
| 4장 | 본문을 방해하지 않는 후원·광고 영역 |
| 5장 | 환경변수·인증 상태·테스트·배포 체크리스트 |

## 중요한 범위

이 과정은 Flask 기반 예제 프로젝트다. 현재 이 강의 사이트가 사용하는 정적 JavaScript/S3 구조를 그대로 복제하는 과정은 아니다. 예제 코드를 공개 서비스에 적용할 때는 사용하는 배포 플랫폼과 Flask의 최신 공식 문서를 다시 확인한다.

## 과정 완료 기준

- 등록된 Markdown 강의가 메뉴에 자동 표시된다.
- 존재하지 않는 경로로 서버 파일을 읽을 수 없다.
- 비밀 값이 저장소에 들어가지 않는다.
- 공개 페이지와 보호 페이지 테스트가 통과한다.
- 모바일 화면에서 본문이 우선 표시된다.
